        ></path>
      </svg>
    </button></h3><p>Milvus 支持四种消息队列（MQ）：rocksmq（基于 RockDB）、Pulsar、Kafka 和 Woodpecker。</p>
<p>您可以通过设置 mq.type 字段来更改消息队列。</p>
<p>如果您未将 mq.type 字段设置为默认值，则当在此文件中配置多个消息队列时，需注意启用优先级。</p>
<ol>
<li><p>独立（本地）模式：rocksmq（默认） &gt; Pulsar &gt; Kafka</p></li>
<li><p>集群模式：Pulsar（默认）&gt; Kafka（集群模式下不支持 rocksmq）</p></li>
<li><p>通过将 mq.type 设置为 woodpecker，Woodpecker 可在独立和集群模式下使用。</p></li>
</ol>
<p>有关本节中各参数的详细说明，请参阅<a href="/docs/zh/configure_mq.md">“与消息队列相关的配置”</a>。</p>
