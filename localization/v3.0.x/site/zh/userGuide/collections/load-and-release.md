<p>如果您选择加载特定字段，请注意：只有包含在 `<code translate="no">load_fields</code> ` 中的字段才能在搜索和查询中用作过滤条件和输出字段。您应始终在 `<code translate="no">load_fields</code>` 中包含主字段的名称以及至少一个向量字段。</p>
<p>您还可以使用<code translate="no">skip_load_dynamic_field</code> 来确定是否加载 Dynamic Field。 Dynamic Field 是一个名为<strong>$meta</strong>的保留 JSON 字段，它以键值对的形式保存所有未在 Schema 中定义的字段及其值。加载 Dynamic Field 时，该字段中的所有键都会被加载，并可用于过滤和输出。如果 Dynamic Field 中的所有键均不参与元数据过滤和输出，请将<code translate="no">skip_load_dynamic_field</code> 设置为<code translate="no">True</code> 。</p>
<p>若要在Collection加载完成后加载更多字段，您需要先释放该Collection，以避免因索引变更而引发的潜在错误。</p>
