      </svg>
    </button></h2><p>在执行范围搜索请求时，Milvus 会以 ANN 搜索结果中与查询向量最相似的向量为中心，以搜索请求中指定的<strong>半径</strong>作为外圈半径，以<strong>range_filter</strong>作为内圈半径，从而绘制两个同心圆。 所有相似度得分落在由这两个同心圆形成的环形区域内的向量都将被返回。在此<strong>，range_filter</strong>可设置为<strong>0</strong>，表示将返回所有在指定相似度得分（半径）范围内的实体。</p>
<p><span class="img-wrapper">
  
   <img translate="no" src="https://milvus-docs.s3.us-west-2.amazonaws.com/assets/range-search.png" alt="Range Search" class="doc-image" id="range-search" /> 
   <span>范围搜索</span>
  
 </span></p>
<p>上图显示，范围搜索请求包含两个参数：<strong>radius</strong>和<strong>range_filter</strong>。收到范围搜索请求后，Milvus 会执行以下操作：</p>
<ul>
<li><p>使用指定的度量类型（<strong>COSINE</strong>）查找与查询向量最相似的所有向量Embeddings。</p></li>
<li><p>筛选出与查询向量<strong>距离</strong>或<strong>相似度分数</strong>落在<strong>radius</strong>和<strong>range_filter</strong>参数指定范围内的向量嵌入。</p></li>
<li><p>从过滤后的结果中返回<strong>排名前 K 的</strong>实体。</p></li>
</ul>
<p><strong>radius</strong>和<strong>range_filter</strong>的设置方式因搜索的度量类型而异。下表列出了不同度量类型下设置这两个参数的要求。</p>
<table>
   <tr>
     <th><p>度量类型</p></th>
     <th><p>符号说明</p></th>
     <th><p>设置 radius 和 range_filter 的要求</p></th>
   </tr>
   <tr>
     <td><p><code translate="no">L2</code></p></td>
     <td><p>L2 距离越小，相似度越高。</p></td>
     <td><p>若要忽略最相似的向量Embeddings，请确保</p><p><code translate="no">range_filter</code> &lt;= 距离 &lt;<code translate="no">radius</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">IP</code></p></td>
     <td><p>IP 距离越大，相似度越高。</p></td>
     <td><p>若要忽略最相似的向量Embeddings，请确保</p><p><code translate="no">radius</code> &lt; 距离 &lt;=<code translate="no">range_filter</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">COSINE</code></p></td>
     <td><p>COSINE 距离越大，相似度越高。</p></td>
     <td><p>若要忽略最相似的向量Embeddings，请确保</p><p><code translate="no">radius</code> &lt; 距离 &lt;=<code translate="no">range_filter</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">JACCARD</code></p></td>
     <td><p>贾卡德距离越小，相似度越高。</p></td>
     <td><p>若要忽略最相似的向量Embeddings，请确保</p><p><code translate="no">range_filter</code> &lt;= 距离 &lt;<code translate="no">radius</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">HAMMING</code></p></td>
     <td><p>哈明距离越小，相似度越高。</p></td>
     <td><p>若要忽略最相似的向量Embeddings，请确保</p><p><code translate="no">range_filter</code> &lt;= 距离 &lt;<code translate="no">radius</code></p></td>
   </tr>
</table>
