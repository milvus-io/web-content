<div class="alert note">
<p>过滤表达式左侧的字面量可以是 Collection 字段名（例如下文示例中的<code translate="no">status</code> 、<code translate="no">color</code> 等），也可以是 StructArray 子字段在特定元素索引处的名称，例如<code translate="no">filter = 'struct[0][subfield] &gt; 10'</code> 。</p>
<p>有关 StructArray 字段中标量过滤的详细信息，请参阅<a href="/docs/zh/struct-array-operators.md">StructArray 操作符</a>。</p>
</div>

<h2 id="IS-NULL-and-IS-NOT-NULL-operators" class="common-anchor-header">IS NULL 和 IS NOT NULL 操作符<button data-href="#IS-NULL-and-IS-NOT-NULL-operators" class="anchor-icon" translate="no">
      <svg translate="no"
        aria-hidden="true"
        focusable="false"
        height="20"
        version="1.1"
        viewBox="0 0 16 16"
        width="16"
      >
        <path
          fill="#0092E4"
          fill-rule="evenodd"
          d="M4 9h1v1H4c-1.5 0-3-1.69-3-3.5S2.55 3 4 3h4c1.45 0 3 1.69 3 3.5 0 1.41-.91 2.72-2 3.25V8.59c.58-.45 1-1.27 1-2.09C10 5.22 8.98 4 8 4H4c-.98 0-2 1.22-2 2.5S3 9 4 9zm9-3h-1v1h1c1 0 2 1.22 2 2.5S13.98 12 13 12H9c-.98 0-2-1.22-2-2.5 0-.83.42-1.64 1-2.09V6.25c-1.09.53-2 1.84-2 3.25C6 11.31 7.55 13 9 13h4c1.45 0 3-1.69 3-3.5S14.5 6 13 6z"
        ></path>
      </svg>
    </button></h2><p>使用<code translate="no">IS NULL</code> 和<code translate="no">IS NOT NULL</code> 来查找字段值缺失或可用的实体。例如，您可以查找没有分类的产品，或其Embeddings已准备好供搜索的实体。这两个操作符均适用于受支持的标量和向量字段，且含义相同：</p>
<table>
<thead>
<tr><th>操作符</th><th>匹配条件</th></tr>
</thead>
<tbody>
<tr><td><code translate="no">&lt;field&gt; IS NULL</code></td><td>指定字段值为 NULL 的实体</td></tr>
<tr><td><code translate="no">&lt;field&gt; IS NOT NULL</code></td><td>指定字段值为非NULL的实体</td></tr>
</tbody>
</table>
<p>支持的标量字段包括布尔型、数值型、<code translate="no">VARCHAR</code> 、<code translate="no">JSON</code> 以及<code translate="no">ARRAY</code> 字段。这些操作符不支持<a href="/docs/zh/text.md">TEXT 字段</a>。</p>
<p>从 Milvus 3.0.3 开始，这些操作符还支持普通向量字段：<code translate="no">FLOAT_VECTOR</code> 、<code translate="no">BINARY_VECTOR</code> 、<code translate="no">FLOAT16_VECTOR</code> 、<code translate="no">BFLOAT16_VECTOR</code> 、<code translate="no">SPARSE_FLOAT_VECTOR</code> 和<code translate="no">INT8_VECTOR</code> 。</p>
<p>这些操作符不区分大小写：<code translate="no">IS NULL</code> 和<code translate="no">is null</code> 是等效的，<code translate="no">IS NOT NULL</code> 和<code translate="no">is not null</code> 也是等效的。</p>

<p>Milvus 并未对过滤条件中的匹配值列表长度设置限制。但是，过长的列表会显著影响查询性能。
如果您的过滤条件包含冗长的匹配值列表或包含多个元素的复杂表达式，建议使用<a href="/docs/zh/filtering-templating.md">过滤器模板功能</a>来提升查询性能。</p>
