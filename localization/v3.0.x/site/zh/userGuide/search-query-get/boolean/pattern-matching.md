    </button></h1><p>使用<code translate="no">LIKE</code> 进行通配符匹配，使用<code translate="no">=~</code> 或<code translate="no">!~</code> 进行<a href="https://github.com/google/re2/wiki/syntax">RE2</a>正则表达式匹配。这些标量过滤器可在<code translate="no">query</code> 、<code translate="no">search</code> 以及混合搜索中匹配字符串结构，例如错误代码、前缀、电子邮件域名或 URL 路径。</p>
<div class="alert note">
<p>这些过滤器匹配字符串值。它们不会更改分析器的令牌，也不会启用基于令牌的<code translate="no">TEXT_MATCH</code> 和<code translate="no">PHRASE_MATCH</code> 。有关这些机制，请参阅<a href="/docs/zh/regex-filter.md">“正则表达式分析器过滤器</a>”和<a href="/docs/zh/keyword-match.md">“文本匹配”</a>。</p>
</div>
