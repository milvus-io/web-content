    </button></h1><p>短语匹配可让您搜索包含查询词作为精确短语的文档。默认情况下，这些词必须按相同顺序出现，并且彼此紧邻。 例如，查询<strong>“robotics machine learning”</strong>将匹配诸如<em>“…典型的机器人学机器学习模型…”之类的</em>文本，其中<strong>“robotics”</strong>、<strong>“machine”</strong>和<strong>“learning”</strong>这三个词按顺序出现，且之间没有其他词语。</p>
<p>然而，在实际应用中，严格的短语匹配可能过于僵化。您可能希望匹配<em>诸如“…在机器人学中广泛采用的机器学习模型…”</em>之类的文本<em>。</em>在此情况下，虽然包含相同的关键词，但它们并非紧邻或按原始顺序出现。为解决此问题，短语匹配支持<code translate="no">slop</code> 参数，从而增加了灵活性。<code translate="no">slop</code> 的数值定义了短语中各术语之间允许的位置偏移量。例如，当<code translate="no">slop</code> 设为1时，查询<strong>“machine learning”</strong>可以匹配<em>“…machine deep learning…”</em>这样的文本，其中一个词（<strong>“deep”</strong>）将原始术语分隔开来。</p>

    </button></h2><p>短语匹配功能由<a href="https://github.com/quickwit-oss/tantivy">Tantivy</a>搜索引擎库提供支持，其工作原理是分析文档中单词的位置信息。下图说明了该过程：</p>
<p><span class="img-wrapper">
  
   <img translate="no" src="https://milvus-docs.s3.us-west-2.amazonaws.com/assets/phrase-match-workflow.png" alt="Phrase Match Workflow" class="doc-image" id="phrase-match-workflow" /> 
   <span>短语匹配工作流</span>
  
 </span></p>
<ol>
<li><p><strong>文档分词</strong>：将文档导入 Milvus 时，系统会使用分析器将文本拆分为词元（单个单词或术语），并为每个词元记录位置信息。 例如，<strong>doc_1</strong>被分词为<strong>[“machine”（pos=0），“learning”（pos=1），“boosts”（pos=2），“efficiency”（pos=3）]</strong>。有关分析器的更多信息，请参阅《<a href="/docs/zh/analyzer-overview.md">分析器概述》</a>。</p></li>
<li><p><strong>倒排索引的创建</strong>：Milvus 会构建一个倒排索引，将每个词元映射到其出现的文档以及该词元在这些文档中的位置。</p></li>
<li><p><strong>短语匹配</strong>：当执行短语查询时，Milvus 会在倒排索引中查找每个词元，并检查其位置，以确定它们是否以正确的顺序和接近度出现。<code translate="no">slop</code> 参数控制匹配词元之间允许的最大位置差：</p>
<ul>
<li><p><strong>slop = 0</strong>表示词元必须<strong>按完全相同的顺序</strong>出现<strong>且紧邻</strong>（即中间没有多余的词）。</p>
<ul>
<li>在示例中，只有<strong>doc_1</strong>（<strong>pos=0</strong> 处的<strong>“machine</strong>”，<strong>pos=1</strong> 处的<strong>“learning”</strong>）完全匹配。</li>
</ul></li>
<li><p><strong>slop = 2</strong>允许匹配令牌之间最多存在两个位置的灵活性或重新排列。</p>
<ul>
<li><p>这允许顺序颠倒（<strong>“learning machine”</strong>）或在标记之间存在微小间隙。</p></li>
<li><p>因此，<strong>doc_1</strong>、<strong>doc_2</strong>（<strong>位置 0</strong><strong>为“learning</strong>”，位置<strong>1</strong> <strong>为“machine”</strong>）和<strong>doc_3</strong>（<strong>位置 1</strong><strong>为“learning</strong>”，位置<strong>2</strong> <strong>为“machine”</strong>）均匹配。</p></li>
</ul></li>
</ul></li>
</ol>

<p>默认情况下，Milvus 使用标准分析器，该分析器基于空格和标点符号对文本进行分词，移除长度超过 40 个字符的词素，并将文本转换为小写。默认使用时无需额外参数。详情请参阅<a href="/docs/zh/standard-analyzer.md">标准分析器</a>。</p>

<li><p><code translate="no">2</code>：允许更大的灵活性，包括术语顺序颠倒或中间最多两个词元。示例：过滤条件<strong>“machine learning”</strong>将匹配<strong>“learning machine”</strong>（术语顺序颠倒）<strong>或“machine quickly boosts learning”</strong>（<strong>“machine”</strong>和<strong>“learning”</strong>之间有两个词元）。</p></li>

    </button></h3><p>在搜索操作中，<strong>PHRASE_MATCH</strong>用于在应用向量相似度排序之前对文档进行过滤。这种两步法首先通过文本匹配缩小候选集范围，然后基于向量 Embeddings 对这些候选结果进行重新排序。</p>
