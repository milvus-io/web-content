        ></path>
      </svg>
    </button></h2><p>在电子商务平台上，用户可以输入关键词来检索与之匹配的产品。当用户查看产品详情页时，平台还会在页面底部显示一份相似产品列表，供用户进行比较。</p>
<p>这些推荐商品会根据其与关键词或当前商品的相似度进行排序。为了实现这一点，平台开发人员需要在实际相似度搜索之前，从 Milvus 中检索关键词或当前商品的向量表示，这增加了平台与 Milvus 之间的往返次数，并导致大量高维浮点数通过网络传输。</p>
<p>为简化应用程序与 Milvus 之间的交互逻辑、减少往返次数，并避免在网络上传输大量高维浮点数值，建议考虑使用主键搜索。</p>
<p>在主键搜索中，您无需提供任何查询向量。取而代之的是，系统会要求您提供包含查询向量的实体的主键（<code translate="no">ids</code> ）。</p>

    </button></h2><ul>
<li><p>使用主键的搜索适用于所有向量数据类型，但 BM25 函数中由 VarChar 字段派生的稀疏向量字段除外。</p></li>
<li><p>在过滤、范围和分组搜索中，您可以使用主键代替查询向量，并可选择启用分页功能。但此功能不适用于混合搜索和搜索迭代器。</p></li>
<li><p>对于涉及嵌入列表的相似度搜索，您仍需检索查询向量，将其排列成嵌入列表，然后执行搜索。</p></li>
<li><p>在 RESTful API 中，您无法使用主键代替查询向量。</p></li>
<li><p>对于任何不存在的或格式不正确的主键，Milvus 都会提示错误。</p></li>
<li><p>主键和查询向量互斥。同时提供两者也会导致错误。</p></li>
</ul>
