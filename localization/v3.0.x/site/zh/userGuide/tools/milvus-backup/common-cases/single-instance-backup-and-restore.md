<p>假设我们有一个 Milvus 实例<code translate="no">milvus_A</code> ，该实例使用名为<code translate="no">bucket_A</code> 的存储桶来存储数据。在此示例中，我们的目标是完成
以下任务：</p>
<ol>
<li><p>为<code translate="no">bucket_A</code> 中的 Collection coll 创建备份（<code translate="no">my_backup</code> ）。</p></li>
<li><p>从备份中还原数据，并将还原后的Collection命名为<code translate="no">coll_bak</code> 。</p></li>
</ol>

        ></path>
      </svg>
    </button></h2><p>创建备份后，您可以使用以下命令
从备份中恢复数据：</p>
<pre><code translate="no" class="language-shell">./milvus-backup restore -c coll -n my_backup -s _bak --config configs/backup.yaml
<button class="copy-code-btn"></button></code></pre>
<p>该命令将从备份中恢复数据，并在<code translate="no">milvus_A</code> 中创建一个名为
coll_bak 的新Collection，使用实例配置的存储根目录<code translate="no">bucket_A/files</code> 。</p>
<p>在 Backup 0.5.16 版本中，已弃用的<code translate="no">-c</code> 选项会在应用<code translate="no">_bak</code> 之前，从备份中选择 Collection 名称。0.6.0 版本中的替代选项<code translate="no">--filter</code> 则使用目标名称；请参阅<a href="/docs/zh/milvus_backup_upgrade.md#Update-CLI-commands">“更新 CLI 命令”</a>。</p>
<p>还原后，请确认<code translate="no">coll_bak</code> 是否存在，如有必要请创建相应的向量索引，并将其实体数量、代表值和搜索结果与备份前捕获的基线进行对比。仅凭命令执行成功并不能验证数据是否正确。</p>
