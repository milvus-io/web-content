<p>假设我们有两个 Milvus 实例：<code translate="no">milvus_A</code> 和<code translate="no">milvus_B</code> ，它们都
使用默认的 MinIO 存储引擎作为对象存储。这些
实例在同一
对象存储中使用不同的存储桶 bucket_A 和<code translate="no">bucket_B</code> 。在此示例中，我们的目标是完成以下
任务：</p>
<ol>
<li><p>为位于<code translate="no">bucket_A</code> 中的 Collection<code translate="no">coll</code> 创建备份（<code translate="no">my_backup</code> ），并将备份存储在<code translate="no">bucket_B</code> 中。</p></li>
<li><p>在<code translate="no">bucket_B</code> 中，从备份中恢复数据，并将恢复后的 Collection 命名为<code translate="no">coll_bak</code> 。</p></li>
</ol>
