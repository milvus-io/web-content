    </button></h1><p><code translate="no">decompounder</code> 过滤器会根据指定的词典将复合词拆分为各个组成部分，从而更方便地搜索复合词的组成部分。该过滤器对于经常使用复合词的语言（如德语）特别有用。</p>
<p>组件词典可通过<code translate="no">word_list</code> 参数内联提供，也可通过<code translate="no">word_list_file</code> 参数从<a href="/docs/zh/manage-file-resources.md">已注册的文件资源中</a>加载。</p>

<p><code translate="no">decompounder</code> 过滤器对分词器生成的词进行处理，因此必须与分词器配合使用。有关Milvus中可用分词器的列表，请参阅<a href="/docs/zh/standard-tokenizer.md">“标准分词器”</a>及其相关页面。</p>
<p>定义<code translate="no">analyzer_params</code> 后，您可以在定义Collection模式时将其应用于<code translate="no">VARCHAR</code> 字段。这使Milvus能够使用指定的分析器处理该字段中的文本，从而实现高效的分词和过滤。有关详细信息，请参阅<a href="/docs/zh/analyzer-overview.md#Example-use">“使用示例”</a>。</p>

    </button></h3><p>对于大型词素词典（尤其是全语言词表），请将词素存储在文件中，并将该文件注册为远程文件资源，然后通过<code translate="no">word_list_file</code> 参数在过滤器中引用该文件。您可以单独使用<code translate="no">word_list_file</code> ，也可以与内联的<code translate="no">word_list</code> 配合使用；当两者均设置时，过滤器会将这两个来源合并为一个词素列表。</p>
<p>该文件为纯 UTF‑8 文本，<strong>每行</strong>包含<strong>一个组件词</strong>。例如：</p>
<pre><code translate="no" class="language-plaintext">dampf
schiff
fahrt
brot
backen
automat
<button class="copy-code-btn"></button></code></pre>
