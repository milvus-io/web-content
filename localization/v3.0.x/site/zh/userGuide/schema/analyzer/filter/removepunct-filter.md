    </button></h1><p><code translate="no">removepunct</code> 过滤器用于从令牌流中移除包含标点符号或空格的令牌。当您希望进行更干净的文本处理，专注于有意义的内容词而非标点符号时，请使用此过滤器。</p>
<div class="alert note">
<p>该过滤器与<code translate="no">jieba</code> 、<code translate="no">lindera</code> 和<code translate="no">icu</code> 词法分析器配合使用时效果最佳，这些词法分析器会将标点符号作为独立的词元保留（例如，<code translate="no">&quot;Hello!&quot;</code> →<code translate="no">[&quot;Hello&quot;, &quot;!&quot;]</code> ）。<code translate="no">standard</code> 分词器在分词过程中会舍弃标点符号。<code translate="no">whitespace</code> 分词器则保留标点符号，包括词内标点。当与<code translate="no">whitespace</code> 结合使用时，<code translate="no">removepunct</code> 会移除包含标点符号或空格的整个词；它不会从词中剥离单个字符。</p>
</div>
