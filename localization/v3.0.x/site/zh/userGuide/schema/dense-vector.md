  稠密向量是机器学习和数据分析中广泛使用的数值数据表示形式。它们由实数数组组成，其中大部分或所有元素均不为零。与稀疏向量相比，在相同维度下，稠密向量包含更多信息，因为每个维度都包含有意义的值。
  这种表示方式能够有效捕捉复杂的模式和关系，使数据在高维空间中更易于分析和处理。稠密向量通常具有固定的维度数，范围从几十到几百甚至几千不等，具体取决于具体应用和要求。

    </button></h1><p>稠密向量是机器学习和数据分析中广泛使用的数值数据表示形式。它们由实数数组组成，其中大部分或所有元素均不为零。与稀疏向量相比，在相同维度下，稠密向量包含更多信息，因为每个维度都包含有意义的值。 这种表示方式能够有效捕捉复杂的模式和关系，使数据在高维空间中更易于分析和处理。稠密向量通常具有固定的维度数，范围从几十到几百甚至几千，具体取决于应用场景和需求。</p>
<p>稠密向量主要应用于需要理解数据语义的场景，例如语义搜索和推荐系统。在语义搜索中，稠密向量有助于捕捉查询与文档之间的潜在关联，从而提高搜索结果的相关性。在推荐系统中，它们有助于识别用户与项目之间的相似性，从而提供更个性化的建议。</p>

<p>密集向量可通过各种<a href="https://en.wikipedia.org/wiki/Embedding">嵌入</a>模型生成，例如用于图像的卷积神经网络（如<a href="https://pytorch.org/hub/pytorch_vision_resnet/">ResNet</a>、<a href="https://pytorch.org/vision/stable/models/vgg.html">VGG</a>）以及用于文本的语言模型（如<a href="https://en.wikipedia.org/wiki/BERT_(language_model)">BERT</a>、<a href="https://en.wikipedia.org/wiki/Word2vec">Word2Vec</a>）。这些模型将原始数据转换为高维空间中的点，从而捕捉数据的语义特征。 此外，Milvus 提供了便捷的方法来帮助用户生成和处理稠密向量，具体细节请参见“Embeddings”章节。</p>

<div class="alert note">
<p>除了稠密向量外，Milvus 还支持稀疏向量和二进制向量。稀疏向量适用于基于特定术语的精确匹配，例如关键词搜索和术语匹配；而二进制向量通常用于高效处理二值化数据，例如图像模式匹配和某些哈希应用。有关更多信息，请参阅<a href="/docs/zh/binary-vector.md">“二进制向量</a>”和<a href="/docs/zh/sparse_vector.md">“稀疏向量”</a>。</p>
</div>
