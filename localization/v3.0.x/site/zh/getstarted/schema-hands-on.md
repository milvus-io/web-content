<p>Milvus 允许您通过 Collection Schema 指定搜索数据模型，从而对非结构化数据、其密集或稀疏向量表示以及结构化元数据进行组织。无论您处理的是文本、图像还是其他数据类型，本实践指南都将帮助您理解并应用关键的模式概念，在实际中设计搜索数据模型。</p>

        ></path>
      </svg>
    </button></h3><p>要有效满足业务需求，首先要分析用户将执行的查询类型，并确定最合适的搜索方法。</p>
<ul>
<li><p><strong>用户查询：</strong>识别用户可能执行的查询类型。这有助于确保您的Schema支持实际用例并优化搜索性能。这些查询可能包括：</p>
<ul>
<li><p>检索与自然语言查询匹配的文档</p></li>
<li><p>查找与参考图片相似或与文本描述匹配的图片</p></li>
<li><p>根据名称、类别或品牌等属性搜索产品</p></li>
<li><p>基于结构化元数据（例如发布日期、标签、评分）过滤项目</p></li>
<li><p>在混合查询中结合多个条件（例如，在视觉搜索中，同时考虑图片及其标题的语义相似性）</p></li>
</ul></li>
<li><p><strong>搜索方法：</strong>选择与用户将要执行的查询类型相匹配的适当搜索技术。不同的方法适用于不同的目的，通常可以组合使用以获得更强大的搜索效果：</p>
<ul>
<li><p><strong>语义搜索</strong>：利用高密度向量相似度查找语义相近的项目，非常适合文本或图像等非结构化数据。</p></li>
<li><p><strong>全文搜索</strong>：通过关键词匹配对语义搜索进行补充。全文搜索可利用词法分析，避免将长词拆分为零散的词素，并在检索过程中准确识别专业术语。</p></li>
<li><p><strong>元数据过滤</strong>：在向量搜索的基础上，应用日期范围、类别或标签等约束条件。</p></li>
</ul></li>
</ul>

    </button></h3><p>下一步是通过识别信息的核心组成部分及其搜索方法，将您的业务需求转化为具体的数据模型：</p>
<ul>
<li><p>定义需要存储的数据，例如原始内容（文本、图像、音频）、相关元数据（标题、标签、作者信息）以及上下文属性（时间戳、用户行为等）</p></li>
<li><p>确定每个元素的适当数据类型和格式。例如：</p>
<ul>
<li><p>文本描述 → 字符串</p></li>
<li><p>图像或文档Embeddings → 密集向量或稀疏向量</p></li>
<li><p>分类、标签或标记 → 字符串、数组和布尔值</p></li>
<li><p>价格或评分等数值属性 → 整数或浮点数</p></li>
<li><p>结构化信息（如作者详情）→ JSON</p></li>
</ul></li>
</ul>
<p>对这些元素的明确定义可确保数据的一致性、搜索结果的准确性，并便于与下游应用逻辑集成。</p>

<p>现在，您可以将数据模型映射为由字段组成的Schema，包括向量和任何辅助标量字段。请确保每个字段都与数据模型中的属性相对应，尤其要注意向量类型（密集型或稀疏型）及其维度。</p>

    </button></h3><p>向量字段用于存储文本、图像和音频等非结构化数据类型的Embeddings。这些Embeddings可能是稠密型、稀疏型或二进制型，具体取决于数据类型和所采用的检索方法。通常，稠密向量用于语义搜索，而稀疏向量更适合全文或词汇匹配。 当存储和计算资源受限时，二进制向量非常有用。一个Collection可以包含多个向量字段，以支持多模态或混合检索策略。有关此主题的详细指南，请参阅《<a href="/docs/zh/multi-vector-search.md">多向量混合搜索</a>》。</p>
<p>Milvus 支持以下向量数据类型：<code translate="no">FLOAT_VECTOR</code> （<a href="/docs/zh/dense-vector.md">密集向量</a>）、<code translate="no">SPARSE_FLOAT_VECTOR</code> （<a href="/docs/zh/sparse_vector.md">稀疏向量</a>）以及<code translate="no">BINARY_VECTOR</code> （<a href="/docs/zh/binary-vector.md">二进制向量</a>）</p>

<p><code translate="no">BOOL</code> 、<code translate="no">INT8/16/32/64</code> 、<code translate="no">FLOAT</code> 、<code translate="no">DOUBLE</code> 、<code translate="no">VARCHAR</code> 、<code translate="no">JSON</code> 以及<code translate="no">ARRAY</code> ，用于存储和过滤非向量数据。这些类型可提高搜索操作的精确度并增强其可定制性。</p>
