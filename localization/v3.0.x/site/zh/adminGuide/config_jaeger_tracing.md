<pre><code translate="no" class="language-shell"><span class="hljs-meta prompt_">$ </span><span class="language-bash">helm repo add jaegertracing https://jaegertracing.github.io/helm-charts</span>

<span class="hljs-meta prompt_">$ </span><span class="language-bash">helm install jaeger jaegertracing/jaeger --version 4.19.0</span>
<button class="copy-code-btn"></button></code></pre>
<p>该图表的 README 文件将其标记为实验性，并指出次要版本中可能会发生破坏性变更，因此该命令会锁定图表版本。图表版本 4.19.0 将部署 Jaeger 2.23.0。</p>

<h2 id="Install-Milvus-with-Helm-Chart" class="common-anchor-header">使用 Helm 图表安装 Milvus<button data-href="#Install-Milvus-with-Helm-Chart" class="anchor-icon" translate="no">
      <svg translate="no"
        aria-hidden="true"
        focusable="false"
        height="20"
        version="1.1"

        width="16"
      >
        <path
          fill="#0092E4"

          d="M4 9h1v1H4c-1.5 0-3-1.69-3-3.5S2.55 3 4 3h4c1.45 0 3 1.69 3 3.5 0 1.41-.91 2.72-2 3.25V8.59c.58-.45 1-1.27 1-2.09C10 5.22 8.98 4 8 4H4c-.98 0-2 1.22-2 2.5S3 9 4 9zm9-3h-1v1h1c1 0 2 1.22 2 2.5S13.98 12 13 12H9c-.98 0-2-1.22-2-2.5 0-.83.42-1.64 1-2.09V6.25c-1.09.53-2 1.84-2 3.25C6 11.31 7.55 13 9 13h4c1.45 0 3-1.69 3-3.5S14.5 6 13 6z"
        ></path>
      </svg>
    </button></h2><p>若要通过 OTLP 将 Milvus 的追踪数据发送至 Jaeger，请将以下配置保存到名为<code translate="no">values.yaml</code> 的文件中：</p>
<pre><code translate="no" class="language-yaml"><span class="hljs-attr">extraConfigFiles:</span>
  <span class="hljs-attr">user.yaml:</span> <span class="hljs-string">|+
    trace:
      exporter: otlp
      sampleFraction: 1
      otlp:
        endpoint: &quot;jaeger:4317&quot;
        method: grpc
        secure: false
</span><button class="copy-code-btn"></button></code></pre>
<p>采用这些设置后，Milvus 将对每个请求进行采样（<code translate="no">sampleFraction: 1</code> ），并通过不启用 TLS 的 OTLP gRPC（<code translate="no">secure: false</code> ）将追踪数据导出至<code translate="no">jaeger</code> 服务的<code translate="no">4317</code> 端口。</p>
<p>要将上述设置应用到新的 Milvus 部署中，请运行以下命令：</p>
<pre><code translate="no" class="language-shell"><span class="hljs-meta prompt_">$ </span><span class="language-bash">helm repo add zilliztech https://zilliztech.github.io/milvus-helm/</span>
<span class="hljs-meta prompt_">$ </span><span class="language-bash">helm repo update</span>
<span class="hljs-meta prompt_">$ </span><span class="language-bash">helm upgrade --install my-release zilliztech/milvus --version 5.0.22 -f values.yaml</span>
<button class="copy-code-btn"></button></code></pre>
<p>若要将上述设置应用到现有的 Milvus 部署中，请运行以下命令：</p>
<pre><code translate="no" class="language-shell"><span class="hljs-meta prompt_">$ </span><span class="language-bash">helm upgrade my-release zilliztech/milvus --version &lt;current-chart-version&gt; --reset-then-reuse-values -f values.yaml</span>
<button class="copy-code-btn"></button></code></pre>
<div class="alert note">
<p>此命令使用<code translate="no">--reset-then-reuse-values</code> ，该选项要求 Helm 3.14 或更高版本。使用此选项时，Helm 会将值重置为<code translate="no">--version</code> 中设置的图表版本默认值，应用当前发布版本的值，然后应用<code translate="no">-f</code> 中的值。因此，<code translate="no">values.yaml</code> 中的每个值都会覆盖当前发布版本的值，且<code translate="no">extraConfigFiles</code> 下的<code translate="no">user.yaml</code> 条目将被整体替换。 要查找 `<code translate="no">&lt;current-chart-version&gt;</code>`，请运行 `<code translate="no">helm list</code> `，并从 `<code translate="no">CHART</code> ` 列的值中移除 `<code translate="no">milvus-</code> ` 前缀。如果您在 `<code translate="no">helm upgrade</code> ` 中使用 `<code translate="no">-f</code> ` 或 `<code translate="no">--set</code> `，但未包含 `<code translate="no">--reset-then-reuse-values</code> ` 或 `<code translate="no">--reuse-values</code>`，Helm 将不会保留您在安装时设置的值。</p>
</div>
