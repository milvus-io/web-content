summary: >-
  Weighted Ranker는 여러 검색 경로의 결과에 각각 다른 중요도 가중치를 부여함으로써, 이를 지능적으로 결합하고 우선순위를
  정합니다. 숙련된 셰프가 여러 재료를 조화롭게 조합하여 완벽한 요리를 만들어내는 것과 마찬가지로, 가중치 기반 순위 결정기는 서로 다른 검색
  결과의 균형을 맞춰 가장 관련성 높은 통합 결과를 제공합니다. 이 접근 방식은 특정 필드가 다른 필드보다 최종 순위에 더 큰 비중을 차지해야
  하는 여러 벡터 필드나 모달리티를 가로질러 검색할 때 이상적입니다.

    </button></h2><p>WeightedRanker 전략의 주요 워크플로는 다음과 같습니다:</p>
<ol>
<li><p><strong>검색 점수 수집</strong>: 벡터 검색의 각 경로에서 결과와 점수(score_1, score_2)를 수집합니다.</p></li>
<li><p><strong>점수 정규화</strong>: 각 검색은 서로 다른 유사도 측정 기준을 사용할 수 있으며, 이로 인해 점수 분포가 달라질 수 있습니다. 예를 들어, 유사도 유형으로 내적(IP)을 사용하면 [−∞,+∞] 범위의 점수가 나올 수 있는 반면, 유클리드 거리(L2)를 사용하면 [0,+∞] 범위의 점수가 나옵니다. 서로 다른 검색의 점수 범위가 달라 직접 비교할 수 없기 때문에, 각 검색 경로의 점수를 정규화해야 합니다. 일반적으로 <code translate="no">arctan</code> 함수를 적용하여 점수를 [0, 1] 사이의 범위로 변환합니다(score_1_normalized, score_2_normalized). 1에 가까운 점수는 유사성이 더 높음을 나타냅니다.</p></li>
<li><p><strong>가중치 할당</strong>: 서로 다른 벡터 필드에 할당된 중요도에 따라, 정규화된 점수(score_1_normalized, score_2_normalized)에 가중치(<strong>wi</strong>)가 할당됩니다. 각 경로의 가중치는 [0, 1] 범위 내에 있어야 합니다. 그 결과로 얻어지는 가중 점수는 score_1_weighted 및 score_2_weighted입니다.</p></li>
<li><p><strong>점수 병합</strong>: 가중치 점수(score_1_weighted, score_2_weighted)를 높은 순서부터 낮은 순서로 정렬하여 최종 점수 집합(score_final)을 생성합니다.</p></li>
</ol>
