<p>특정 필드를 로드하기로 선택한 경우, <code translate="no">load_fields</code> 에 포함된 필드만 검색 및 쿼리에서 필터 및 출력 필드로 사용할 수 있다는 점에 유의해야 합니다. <code translate="no">load_fields</code> 에는 항상 기본 필드의 이름과 적어도 하나의 벡터 필드를 포함해야 합니다.</p>
<p>또한 <code translate="no">skip_load_dynamic_field</code> 를 사용하여 동적 필드를 로드할지 여부를 결정할 수도 있습니다. 동적 필드는 <strong>$meta라는</strong> 이름의 예약된 JSON 필드로, 스키마에 정의되지 않은 모든 필드와 해당 값을 키-값 쌍으로 저장합니다. 동적 필드를 로드하면 필드 내의 모든 키가 로드되어 필터링 및 출력에 사용할 수 있게 됩니다. 동적 필드의 모든 키가 메타데이터 필터링 및 출력에 사용되지 않는 경우, <code translate="no">skip_load_dynamic_field</code> 를 <code translate="no">True</code> 로 설정하십시오.</p>
<p>컬렉션 로드 후 더 많은 필드를 로드하려면, 인덱스 변경으로 인해 발생할 수 있는 오류를 방지하기 위해 먼저 컬렉션을 해제해야 합니다.</p>
