  가능합니다.

<p><code translate="no">stemmer</code> 필터는 토큰화기가 생성한 용어를 대상으로 작동하므로, 반드시 토큰화기와 함께 사용해야 합니다.</p>
<p>아랍어 텍스트의 경우, 대부분의 경우 내장된 <a href="/docs/ko/arabic-analyzer.md"><code translate="no">arabic</code></a> 분석기를 사용하십시오. 내장 분석기에는 아랍어 어근 추출과 함께 아랍어 정규화, 소수점 숫자 정규화, 아랍어 스톱워드 제거 기능이 포함되어 있습니다. 사용자 정의 분석기 파이프라인을 구축해야 하는 경우에만 <code translate="no">stemmer</code> 필터를 직접 사용하십시오.</p>
<p><code translate="no">analyzer_params</code> 를 정의한 후에는 컬렉션 스키마를 정의할 때 <code translate="no">VARCHAR</code> 필드에 이를 적용할 수 있습니다. 이를 통해 Milvus는 지정된 분석기를 사용하여 해당 필드의 텍스트를 처리함으로써 효율적인 토큰화 및 필터링을 수행할 수 있습니다. 자세한 내용은 <a href="/docs/ko/analyzer-overview.md#Example-use">사용 예제를</a> 참조하십시오.</p>
