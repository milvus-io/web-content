    </button></h2><p><code translate="no">whitespace</code> 토큰화기는 다음 5가지 ASCII 공백 문자에서만 텍스트를 분할합니다:</p>
<table>
<thead>
<tr><th>문자</th><th>이름</th><th>유니코드 코드 포인트</th></tr>
</thead>
<tbody>
<tr><td><code translate="no">\t</code></td><td>수평 탭</td><td>U+0009</td></tr>
<tr><td><code translate="no">\n</code></td><td>줄 바꿈</td><td>U+000A</td></tr>
<tr><td><code translate="no">\x0C</code> 또는 <code translate="no">\f</code></td><td>페이지 이동</td><td>U+000C</td></tr>
<tr><td><code translate="no">\r</code></td><td>캐리지 리턴</td><td>U+000D</td></tr>
<tr><td><code translate="no">' '</code></td><td>공백</td><td>U+0020</td></tr>
</tbody>
</table>
<p>이러한 구분자는 무시되며, 연속된 구분자는 빈 토큰을 생성하지 않습니다. 구두점 및 기타 문자는 토큰 내에 그대로 유지됩니다. 특히, 수직 탭(<code translate="no">\x0B</code>, U+000B), 비분리 공백(<code translate="no">\u00A0</code>) 및 표의 문자 공백(<code translate="no">\u3000</code>)은 토큰 분할을 유발하지 않습니다.</p>
<p>이 집합은 Rust의 <a href="https://doc.rust-lang.org/std/primitive.char.html#method.is_ascii_whitespace"><code translate="no">char::is_ascii_whitespace()</code></a>방식을 따르며, 다른 유니코드 공백 문자는 제외합니다.</p>
<p>다음 예제에서는 필터 없이 <code translate="no">{&quot;tokenizer&quot;: &quot;whitespace&quot;}</code> 를 사용합니다. 입력 및 출력에는 파이썬 문자열 표기법이 사용되며, <code translate="no">\t</code> 및 <code translate="no">\u00A0</code> 와 같은 이스케이프 시퀀스는 실제 문자를 나타냅니다.</p>

<thead>
<tr><th>입력</th><th>출력 토큰</th></tr>

<tbody>
<tr><td><code translate="no">&quot;a\tb\nc\x0Cd\re f&quot;</code></td><td><code translate="no">[&quot;a&quot;, &quot;b&quot;, &quot;c&quot;, &quot;d&quot;, &quot;e&quot;, &quot;f&quot;]</code></td></tr>
<tr><td><code translate="no">&quot;Hello,World! foo_bar&quot;</code></td><td><code translate="no">[&quot;Hello,World!&quot;, &quot;foo_bar&quot;]</code></td></tr>
<tr><td><code translate="no">&quot;a\x0Bb&quot;</code></td><td><code translate="no">[&quot;a\x0Bb&quot;]</code></td></tr>
