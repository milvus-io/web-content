<p>사용 사례에 따라 Milvus가 ID를 자동으로 생성하도록(AutoID) 하거나, 직접 ID를 수동으로 할당할 수 있습니다.</p>

    </button></h2><p>주 필드는 기존 데이터베이스의 기본 키와 유사하게, 컬렉션 내 각 엔티티에 대한 고유 키 역할을 합니다. Milvus는 삽입, 업서트, 삭제 및 쿼리 작업 중에 주 필드를 사용하여 엔티티를 관리합니다.</p>
<p>주요 요구 사항:</p>
<ul>
<li><p>각 컬렉션에는 <strong>정확히 하나의</strong> 기본 필드가 있어야 합니다.</p></li>
<li><p>주 필드의 값은 null일 수 없습니다.</p></li>
<li><p>데이터 유형은 생성 시 지정해야 하며, 나중에 변경할 수 없습니다.</p></li>
</ul>

   <tr>
     <th><p>모드</p></th>
     <th><p>설명</p></th>

   </tr>
</table>
<div class="alert note">
<ul>
<li><p>어떤 모드를 선택해야 할지 확실하지 않다면, 더 간편한 데이터 수집과 고유성 보장을 위해 <a href="/docs/ko/primary-field.md#Quickstart-Use-AutoID">AutoID부터 시작하는 것이</a> 좋습니다.</p></li>
<li><p>수동으로 기본 키를 설정하는 것이 유리한 경우가 아니라면, 모든 경우에 <code translate="no">autoId</code> 를 사용하는 것이 좋습니다.</p></li>
</ul>
</div>
