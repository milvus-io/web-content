    </button></h1><p>Milvus는 실행 중에 상세한 시계열 메트릭 목록을 출력합니다. <a href="https://prometheus.io/">Prometheus와</a> <a href="https://grafana.com/">Grafana를</a> 사용하여 메트릭을 시각화할 수 있습니다. 이 항목에서는 Grafana Milvus 대시보드에 표시되는 모니터링 메트릭을 소개합니다.</p>
<p>이 항목에서 사용하는 시간 단위는 밀리초입니다. 또한 이 항목에서 “99번째 백분위수”는 시간 통계의 99%가 특정 값 범위 내에 포함된다는 것을 의미합니다.</p>
<p>Prometheus 메트릭을 먼저 이해하려면 <a href="/docs/ko/monitor_overview.md">Milvus 모니터링 프레임워크 개요를</a> 읽어보시는 것을 권장합니다.</p>
