    </button></h1><p>Milvus는 기본적으로 MinIO를 오브젝트 스토리지로 사용하지만, 로그 및 인덱스 파일을 위한 영구 오브젝트 스토리지로 <a href="https://aws.amazon.com/s3/">Amazon Simple Storage Service(S3)</a> 및 기타 S3 호환 오브젝트 스토리지(예: Backblaze B2 또는 Cloudflare R2)를 사용하는 것도 지원합니다. 이 항목에서는 Milvus용 S3를 구성하는 방법을 설명합니다. MinIO 사용에 문제가 없다면 이 주제를 건너뛸 수 있습니다.</p>
<p><a href="https://docs.docker.com/get-started/overview/">Docker Compose</a> 또는 K8s에서 S3를 구성할 수 있습니다.</p>

<p>다음 표에는 YAML 파일에서 S3를 구성하는 데 사용되는 키들이 나열되어 있습니다.</p>

<tr><td><code translate="no">externalS3.enabled</code></td><td>S3를 활성화하거나 비활성화합니다.</td><td><code translate="no">true</code>/<code translate="no">false</code></td></tr>
<tr><td><code translate="no">externalS3.host</code></td><td>S3에 액세스하기 위한 엔드포인트입니다.</td><td></td></tr>
<tr><td><code translate="no">externalS3.port</code></td><td>S3에 액세스하는 포트입니다.</td><td></td></tr>
<tr><td><code translate="no">externalS3.rootPath</code></td><td>S3 스토리지의 루트 경로입니다.</td><td>기본값은 빈 문자열입니다.</td></tr>

</tbody>
</table>

<pre><code translate="no" class="language-yaml"><span class="hljs-attr">externalS3:</span>
  <span class="hljs-attr">enabled:</span> <span class="hljs-literal">true</span>

  <span class="hljs-attr">useSSL:</span> <span class="hljs-string">&lt;true/false&gt;</span>
  <span class="hljs-attr">bucketName:</span> <span class="hljs-string">&quot;&lt;your_bucket_name&gt;&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<ol start="3">
<li>앞서 설명한 섹션을 구성하고 <code translate="no">values.yaml</code> 파일을 저장한 후, 다음 명령을 실행하여 S3 구성을 사용하는 Milvus를 설치하십시오.</li>
</ol>
<pre><code translate="no" class="language-shell">helm install &lt;your_release_name&gt; milvus/milvus -f values.yaml
<button class="copy-code-btn"></button></code></pre>
