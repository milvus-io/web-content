<p>RAG 시스템은 검색 시스템과 생성 모델을 결합하여 주어진 프롬프트를 기반으로 새로운 텍스트를 생성합니다. 이 시스템은 먼저 Milvus를 사용하여 코퍼스에서 관련 문서를 검색한 다음, 생성 모델을 활용해 검색된 문서를 기반으로 새로운 텍스트를 생성합니다.</p>
<p><a href="https://haystack.deepset.ai/">Haystack은</a> deepset에서 개발한 오픈소스 Python 프레임워크로, 대규모 언어 모델(LLM)을 활용한 맞춤형 앱을 구축하는 데 사용됩니다. <a href="https://milvus.io/">Milvus는</a> 임베딩 유사도 검색 및 AI 애플리케이션을 지원하기 위해 개발된, 세계에서 가장 진보된 오픈소스 벡터 데이터베이스입니다.</p>
