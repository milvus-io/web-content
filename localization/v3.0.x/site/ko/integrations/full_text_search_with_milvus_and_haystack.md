    </button></h1><p><a href="https://milvus.io/docs/full-text-search.md#Full-Text-Search">전체 텍스트 검색은</a> 텍스트 내의 특정 키워드나 구문을 일치시켜 문서를 검색하는 전통적인 방법입니다. 이 방법은 용어 빈도 등의 요소를 바탕으로 계산된 관련성 점수에 따라 검색 결과를 순위를 매깁니다. 시맨틱 검색이 의미와 문맥을 이해하는 데 더 뛰어나지만, 전체 텍스트 검색은 정확한 키워드 일치에 탁월하므로 시맨틱 검색을 보완하는 유용한 수단이 됩니다. BM25 알고리즘은 전체 텍스트 검색의 순위 결정에 널리 사용되며, 검색 강화 생성(RAG)에서 핵심적인 역할을 합니다.</p>
<p><a href="https://milvus.io/blog/introduce-milvus-2-5-full-text-search-powerful-metadata-filtering-and-more.md">Milvus 2.5는</a> BM25를 활용한 네이티브 전체 텍스트 검색 기능을 도입했습니다. 이 접근 방식은 텍스트를 BM25 점수를 나타내는 스파스 벡터로 변환합니다. 원본 텍스트를 입력하기만 하면 Milvus가 자동으로 스파스 벡터를 생성하고 저장하므로, 수동으로 스파스 임베딩을 생성할 필요가 없습니다.</p>
<p><a href="https://haystack.deepset.ai/">Haystack은</a> 이제 이 Milvus 기능을 지원하므로, RAG 애플리케이션에 전체 텍스트 검색을 쉽게 추가할 수 있습니다. 전체 텍스트 검색을 밀집 벡터 시맨틱 검색과 결합하여, 시맨틱 이해와 키워드 일치 정확도라는 두 가지 장점을 모두 활용하는 하이브리드 접근 방식을 구현할 수 있습니다. 이러한 조합은 검색 정확도를 향상시키고 사용자에게 더 나은 결과를 제공합니다.</p>
<p>이 튜토리얼에서는 Haystack과 Milvus를 사용하여 애플리케이션에 전체 텍스트 검색 및 하이브리드 검색을 구현하는 방법을 보여줍니다.</p>
<p>이 튜토리얼은 Milvus Lite를 사용하여 로컬에서 실행하거나, Milvus 서버에 연결하거나, 완전 관리형 Milvus 서비스인 <a href="https://docs.zilliz.com/docs/register-with-zilliz-cloud">Zilliz Cloud를</a> 사용하여 실행할 수 있습니다.</p>
