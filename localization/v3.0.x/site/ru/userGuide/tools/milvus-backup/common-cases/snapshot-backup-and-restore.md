<li>Используйте Milvus Backup версии 0.6.0 и Milvus версии 3.0.1 или более поздней. Установите инструмент, как описано в разделе <a href="/docs/ru/milvus_backup_0_6_cli.md">«Резервное копирование и восстановление данных с помощью команд</a>».</li>
<li>Используйте существующую коллекцию с именем « <code translate="no">coll</code> » или создайте приведенную ниже примерную коллекцию (по желанию). Оставьте данные в ней без изменений при сравнении результатов исходного состояния и восстановленных данных.</li>
<li>Обеспечьте доступ Milvus Backup к порту gRPC Milvus (19530), порту управления (9091) и объектному хранилищу. Сервер Milvus также должен иметь доступ к хранилищу резервных копий для экспорта и импорта снимков.</li>
<li>Замените примерные имена хостов, имена корзин, корневые пути и учетные данные на свои настройки развертывания. Настройки хранилища Milvus должны соответствовать запущенному экземпляру; изменение конфигурации резервного копирования не приводит к перенастройке Milvus.</li>
<li>Убедитесь, что файл « <code translate="no">coll_bak</code> » отсутствует в целевом экземпляре.</li>
</ul>
<p>Настройки хранилища Milvus см. в разделе <a href="/docs/ru/deploy_s3.md">«Объектное хранилище</a>». Информацию о существующих конфигурациях резервного копирования версии 1 см. в разделе <a href="/docs/ru/milvus_backup_upgrade.md#Migrate-the-configuration">«Обновление Milvus Backup</a>».</p>

<p>При проверке подключения должен отображаться результат <code translate="no">Success!</code>. Команда создания должна возвращать результат <code translate="no">create backup success</code>, а в информации о резервной копии должен указываться адрес <code translate="no">coll</code>.</p>
<p>Явное указание <code translate="no">--format snapshot</code> выбирает рабочий процесс создания моментального снимка. По умолчанию <code translate="no">auto</code> также выбирает создание моментального снимка в Milvus 3.0. Резервная копия включает метаданные и экспортированный пакет моментального снимка, расположенный в <code translate="no">bucket-a/backup/my_backup</code>. Сохраните весь каталог целиком.</p>

<pre><code translate="no" class="language-shell">./milvus-backup restore --filter coll_bak -n my_backup -s _bak --config configs/backup-source.yaml
<button class="copy-code-btn"></button></code></pre>
<p>Команда CLI <code translate="no">--filter</code> сопоставляется с целевым именем <strong>после</strong> применения <code translate="no">-s</code> или <code translate="no">--rename</code>. В этой команде восстановления используйте <code translate="no">coll_bak</code>, а не <code translate="no">coll</code>. Фильтр, не дающий результатов, может успешно завершиться без создания коллекции.</p>
<p>Восстановленная коллекция использует настроенное хранилище целевого экземпляра. Milvus управляет импортом моментального снимка и последующей организацией данных.</p>
