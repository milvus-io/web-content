    </button></h1><p>При работе с большими наборами данных зачастую нет необходимости обрабатывать все данные для получения аналитических выводов или тестирования логики фильтрации. Случайная выборка решает эту проблему, позволяя работать со статистически репрезентативным подмножеством данных, что значительно сокращает время выполнения запросов и снижает потребление ресурсов.</p>
<p>Случайная выборка осуществляется на уровне сегментов, что обеспечивает высокую производительность при сохранении случайности выборки в рамках распределения данных вашей коллекции.</p>
<p><strong>Основные сценарии использования:</strong></p>
<ul>
<li><p><strong>Изучение данных</strong>: быстрый просмотр структуры и содержания коллекции с минимальным использованием ресурсов</p></li>
<li><p><strong>Тестирование разработки</strong>: тестирование сложной логики фильтрации на управляемых выборках данных перед полномасштабным развертыванием</p></li>
<li><p><strong>Оптимизация ресурсов</strong>: сокращение вычислительных затрат на исследовательские запросы и статистический анализ</p></li>
</ul>

<p><strong>Параметры:</strong></p>
<ul>
<li><code translate="no">sampling_factor</code>: Коэффициент выборки в диапазоне (0, 1), исключая границы. Например, <code translate="no">RANDOM_SAMPLE(0.001)</code> выбирает примерно 0,1% результатов.</li>
</ul>
<p><strong>Важные правила:</strong></p>
<ul>
<li><p>В выражении не учитывается регистр (<code translate="no">RANDOM_SAMPLE</code> или <code translate="no">random_sample</code>)</p></li>
<li><p>Коэффициент выборки должен находиться в диапазоне (0, 1), исключая границы</p></li>
</ul>
