    </button></h2><p>При выполнении запроса на поиск по диапазону Milvus использует в качестве центра векторы, наиболее схожие с вектором запроса из результатов поиска ANN, при этом <strong>радиус</strong>, указанный в запросе на поиск, служит радиусом внешнего круга, а параметр <strong>range_filter</strong> — радиусом внутреннего круга, на основе чего рисуются два концентрических круга. Будут возвращены все векторы, показатели схожести которых находятся в кольцевой области, образованной этими двумя концентрическими кругами. При этом параметр <strong>range_filter</strong> можно установить равным <strong>0</strong>, что означает, что будут возвращены все объекты, показатели схожести которых находятся в пределах указанного значения (радиуса).</p>

<p>На приведенной выше схеме показано, что запрос на поиск по диапазону содержит два параметра: <strong>radius</strong> и <strong>range_filter</strong>. При получении запроса на поиск по диапазону Milvus выполняет следующие действия:</p>
<ul>
<li><p>Использует указанный тип метрики (<strong>COSINE</strong>) для поиска всех векторных вложений, наиболее схожих с вектором запроса.</p></li>
<li><p>Фильтрует векторные вложения, <strong>расстояния</strong> или <strong>оценки сходства</strong> которых по отношению к вектору запроса находятся в диапазоне, заданном параметрами <strong>radius</strong> и <strong>range_filter</strong>.</p></li>
<li><p>Возвращает <strong>K лучших</strong> объектов из отфильтрованных.</p></li>
</ul>
<p>Способ настройки <strong>radius</strong> и <strong>range_filter</strong> зависит от типа метрики поиска. В следующей таблице приведены требования к настройке этих двух параметров для различных типов метрик.</p>
<table>
   <tr>
     <th><p>Тип метрики</p></th>
     <th><p>Обозначения</p></th>
     <th><p>Требования к настройке radius и range_filter</p></th>
   </tr>
   <tr>
     <td><p><code translate="no">L2</code></p></td>
     <td><p>Чем меньше L2-расстояние, тем выше степень сходства.</p></td>
     <td><p>Чтобы игнорировать наиболее схожие векторные вложения, убедитесь, что</p><p><code translate="no">range_filter</code> &lt;= расстояние &lt; <code translate="no">radius</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">IP</code></p></td>
     <td><p>Более большое расстояние IP указывает на более высокую степень сходства.</p></td>
     <td><p>Чтобы игнорировать наиболее схожие векторные вложения, убедитесь, что</p><p><code translate="no">radius</code> &lt; расстояние &lt;= <code translate="no">range_filter</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">COSINE</code></p></td>
     <td><p>Большее расстояние по косинусу указывает на более высокую степень сходства.</p></td>
     <td><p>Чтобы игнорировать наиболее схожие векторные вложения, убедитесь, что</p><p><code translate="no">radius</code> &lt; расстояние &lt;= <code translate="no">range_filter</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">JACCARD</code></p></td>
     <td><p>Чем меньше расстояние по Жаккарду, тем выше степень сходства.</p></td>
     <td><p>Чтобы игнорировать наиболее схожие векторные вложения, убедитесь, что</p><p><code translate="no">range_filter</code> &lt;= расстояние &lt; <code translate="no">radius</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">HAMMING</code></p></td>
     <td><p>Чем меньше расстояние Хэмминга, тем выше степень сходства.</p></td>
     <td><p>Чтобы игнорировать наиболее схожие векторные вложения, убедитесь, что</p><p><code translate="no">range_filter</code> &lt;= расстояние &lt; <code translate="no">radius</code></p></td>
   </tr>
</table>
