title: Поиск с фильтрацией
summary: >-
  Поиск с использованием нейронной сети (ANN) позволяет найти векторные
  вложения, наиболее схожие с заданными векторными вложениями. Однако результаты
  поиска не всегда могут быть правильными. В запрос на поиск можно включить
  условия фильтрации, чтобы Milvus проводил фильтрацию по метаданным перед
  выполнением поиска с использованием нейронной сети, сужая область поиска с
  всей коллекции до объектов, соответствующих заданным условиям фильтрации.

Как только Milvus получает поисковый запрос с условием фильтрации, он ограничивает область поиска объектами, соответствующими указанному условию фильтрации.</p>

 </span></p>
<p>Как показано на приведенной выше схеме, поисковый запрос содержит условие фильтрации « <code translate="no">chunk like &quot;%red%&quot;</code> », указывающее, что Milvus должен провести поиск с помощью нейронной сети (ANN) среди всех объектов, в поле « <code translate="no">chunk</code> » которых присутствует слово « <code translate="no">red</code> ». В частности, Milvus выполняет следующие действия:</p>
<ul>
<li><p>Отфильтровывает сущности, соответствующие условиям фильтрации, указанным в поисковом запросе.</p></li>
<li><p>Проводит поиск с помощью нейронной сети (ANN) среди отфильтрованных объектов.</p></li>
<li><p>Возвращает K лучших объектов.</p></li>
</ul>

        ></path>
      </svg>
    </button></h3><p>Стандартный процесс фильтрации эффективно сужает область поиска до небольшого диапазона. Однако чрезмерно сложные выражения фильтрации могут привести к очень высокой задержке поиска. В таких случаях альтернативой может служить итеративная фильтрация, помогающая снизить нагрузку на скалярную фильтрацию.</p>
<p><span class="img-wrapper">
  
   <img translate="no" src="https://milvus-docs.s3.us-west-2.amazonaws.com/assets/iterative-filtering.png" alt="Iterative Filtering" class="doc-image" id="iterative-filtering" /> 
   <span>Итеративная фильтрация</span>
  
 </span></p>
<p>Как показано на приведенной выше схеме, поиск с итеративной фильтрацией выполняет векторный поиск в несколько этапов. Каждый объект, возвращаемый итератором, проходит скалярную фильтрацию, и этот процесс продолжается до тех пор, пока не будет получено заданное количество лучших K результатов.</p>
<p>Этот метод значительно сокращает количество объектов, подвергаемых скалярной фильтрации, что делает его особенно полезным при работе со сложными выражениями фильтрации.</p>
<p>Однако важно отметить, что итератор обрабатывает сущности по одной за раз. Такой последовательный подход может привести к увеличению времени обработки или потенциальным проблемам с производительностью, особенно когда скалярной фильтрации подвергается большое количество сущностей.</p>

<p>Условие фильтрации, передаваемое в запросе на поиск, имеет вид <code translate="no">color like &quot;red%&quot; and likes &gt; 50</code>. В нём используется оператор «and» для объединения двух условий: первое ищет сущности, у которых значение в поле <code translate="no">color</code> начинается с <code translate="no">red</code>, а второе — сущности, у которых значение в поле <code translate="no">likes</code> превышает <code translate="no">50</code>. Существует только два объекта, отвечающих этим требованиям. При значении параметра top-K, установленном на <code translate="no">5</code>, Milvus рассчитает расстояние между этими двумя объектами и вектором запроса и вернет их в качестве результатов поиска.</p>
