<p>В зависимости от вашего сценария использования вы можете либо позволить Milvus автоматически генерировать идентификаторы (AutoID), либо назначать собственные идентификаторы вручную.</p>

        ></path>
      </svg>
    </button></h2><p>Первичное поле выступает в качестве уникального ключа для каждого объекта в коллекции, аналогично первичному ключу в традиционной базе данных. Milvus использует первичное поле для управления объектами при операциях вставки, обновления с условием (upsert), удаления и запроса.</p>
<p>Основные требования:</p>
<ul>
<li><p>Каждая коллекция должна иметь <strong>ровно одно</strong> первичное поле.</p></li>
<li><p>Значения первичного поля не могут быть нулевыми.</p></li>
<li><p>Тип данных должен быть указан при создании и не может быть изменен впоследствии.</p></li>
</ul>

<table>
   <tr>
     <th><p>Тип данных</p></th>

   <tr>
     <td><p><code translate="no">INT64</code></p></td>
     <td><p>64-разрядный целочисленный тип, обычно используемый с AutoID. Это рекомендуемый вариант для большинства случаев использования.</p></td>
   </tr>
   <tr>
     <td><p><code translate="no">VARCHAR</code></p></td>
     <td><p>Тип строки переменной длины. Используйте его, когда идентификаторы сущностей поступают из внешних систем (например, коды продуктов или идентификаторы пользователей). Требуется свойство « <code translate="no">max_length</code> » для определения максимального количества байтов, допустимого для каждого значения.</p></td>
   </tr>
</table>

    </button></h2><p>Milvus поддерживает два режима присвоения значений первичного ключа.</p>
<table>
   <tr>
     <th><p>Режим</p></th>
     <th><p>Описание</p></th>
     <th><p>Рекомендуется для</p></th>
   </tr>
   <tr>
     <td><p>AutoID</p></td>
     <td><p>Milvus автоматически генерирует уникальные идентификаторы для вставленных или импортированных сущностей.</p></td>
     <td><p>Большинство сценариев, в которых нет необходимости управлять идентификаторами вручную.</p></td>
   </tr>
   <tr>
     <td><p>Идентификаторы, задаваемые вручную</p></td>
     <td><p>Вы самостоятельно указываете уникальные идентификаторы при вставке или импорте данных.</p></td>
     <td><p>Когда идентификаторы должны совпадать с внешними системами или уже существующими наборами данных.</p></td>
   </tr>
</table>
<div class="alert note">
<ul>
<li><p>Если вы не уверены, какой режим выбрать, <a href="/docs/ru/primary-field.md#Quickstart-Use-AutoID">начните с AutoID</a> для упрощения импорта и обеспечения уникальности.</p></li>
<li><p>Рекомендуется во всех случаях полагаться на « <code translate="no">autoId</code> », за исключением тех случаев, когда ручная настройка первичных ключей приносит пользу.</p></li>
</ul>
</div>
