    </button></h1><p>Токенизатор <code translate="no">icu</code> основан на проекте с открытым исходным кодом <a href="http://site.icu-project.org/">Internationalization Components of Unicode</a> (ICU), который предоставляет ключевые инструменты для интернационализации программного обеспечения. Используя алгоритм разбиения слов ICU, токенизатор может точно разбивать текст на слова в большинстве языков мира.</p>
<div class="alert note">
<p>Токенизатор <code translate="no">icu</code> сохраняет знаки препинания и пробелы в виде отдельных токенов в выходных данных. Например, « <code translate="no">&quot;Привет! Как дела?&quot;</code> » преобразуется в « <code translate="no">[&quot;Привет&quot;, &quot;!&quot;, &quot; &quot;, &quot;Как&quot;, &quot; &quot;, &quot;дела&quot;, &quot;?&quot;]</code> ». Чтобы удалить эти отдельные токены-знаки препинания, используйте фильтр <a href="/docs/ru/removepunct-filter.md"><code translate="no">removepunct</code></a> фильтр.</p>
</div>
