    </button></h2><p>Создание индекса для конкретного поля ускоряет поиск по этому полю. Индекс фиксирует порядок элементов в коллекции. Как показано в приведенных ниже фрагментах кода, вы можете использовать <code translate="no">metric_type</code> и <code translate="no">index_type</code>, чтобы выбрать подходящие способы индексирования поля в Milvus и измерения сходства между векторными вложениями.</p>
<p>В Milvus в качестве типа индекса для всех векторных полей можно использовать <code translate="no">AUTOINDEX</code>, а в качестве типа метрики — один из следующих вариантов: <code translate="no">COSINE</code>, <code translate="no">L2</code> или <code translate="no">IP</code>, в зависимости от ваших потребностей.</p>
<p>Как показано в приведенном выше фрагменте кода, для векторных полей необходимо задать как тип индекса, так и тип метрики, а для скалярных полей — только тип индекса. Индексы являются обязательными для векторных полей, и рекомендуется создавать индексы для скалярных полей, часто используемых в условиях фильтрации.</p>

<h3 id="Set-Shard-Number" class="common-anchor-header">Установка количества шардов<button data-href="#Set-Shard-Number" class="anchor-icon" translate="no">
      <svg translate="no"
        aria-hidden="true"
        focusable="false"
        height="20"
        version="1.1"
        viewBox="0 0 16 16"

          d="M4 9h1v1H4c-1.5 0-3-1.69-3-3.5S2.55 3 4 3h4c1.45 0 3 1.69 3 3.5 0 1.41-.91 2.72-2 3.25V8.59c.58-.45 1-1.27 1-2.09C10 5.22 8.98 4 8 4H4c-.98 0-2 1.22-2 2.5S3 9 4 9zm9-3h-1v1h1c1 0 2 1.22 2 2.5S13.98 12 13 12H9c-.98 0-2-1.22-2-2.5 0-.83.42-1.64 1-2.09V6.25c-1.09.53-2 1.84-2 3.25C6 11.31 7.55 13 9 13h4c1.45 0 3-1.69 3-3.5S14.5 6 13 6z"
        ></path>
      </svg>
    </button></h3><p>Шарды представляют собой горизонтальные фрагменты коллекции, и каждый шард соответствует каналу ввода данных. По умолчанию каждая коллекция имеет один шард. Вы можете указать количество шардов при создании коллекции, чтобы лучше адаптировать её к объёму данных и рабочей нагрузке.</p>
<p>В качестве общего руководства при настройке количества шардов учитывайте следующее:</p>
<ul>
<li><strong>Объем данных:</strong> Обычно на каждые 200 миллионов сущностей приходится один шард. Вы также можете рассчитать количество шардов исходя из общего объема данных, например, добавляя один шард на каждые 100 ГБ данных, которые планируется внести.</li>
<li><strong>Загрузка узлов потоковой обработки:</strong> если ваш экземпляр Milvus имеет несколько узлов потоковой обработки, рекомендуется использовать несколько шардов. Это гарантирует, что нагрузка при вставке данных распределяется по всем доступным узлам потоковой обработки, предотвращая ситуацию, когда одни узлы простаивают, а другие перегружены.</li>
</ul>
