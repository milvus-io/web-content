<p>Синтаксис выражений см. в разделах <a href="/docs/ru/basic-operators.md">«Основные операторы</a> » и <a href="/docs/ru/pattern-matching.md">«Сопоставление шаблонов</a>».</p>
<p>При вычислении диапазона может выполняться обращение к нескольким индексированным строкам. Шаблоны суффиксов, подстрок, общие шаблоны <code translate="no">LIKE</code> и шаблоны регулярных выражений также могут оцениваться по индексированным строкам, но для этого может потребоваться обращение к множеству различных значений. Для рабочих нагрузок с подстроками или регулярными выражениями сравните <a href="/docs/ru/ngram.md">NGRAM</a>, используя его правила допустимости шаблонов.</p>
<p><a id="Best-practices"></a></p>
<p>Сравните задержку запроса с типичными длинами строк, префиксами и количеством результатов.</p>

<summary><strong>Процесс поиска в префиксном дереве</strong></summary></p>
<p>Во время построения индекса Milvus вставляет строки в префиксное дерево и сохраняет его. Символы хранятся вдоль ребер, общие префиксы хранятся один раз, а каждый терминальный узел фиксирует идентификаторы сущностей, связанных с данной строкой.</p>
<p>Для проверки равенства выполняется обход дерева до конечного узла, соответствующего точной строке. Для префикса необходимо найти узел префикса и собрать идентификаторы из его поддерева. Исполнитель запроса получает идентификаторы соответствующих сущностей.</p>
<p>Обход до узла строки или префикса зависит от длины шаблона; для возврата совпадений также требуется сбор связанных идентификаторов сущностей.</p>
