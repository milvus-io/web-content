    </button></h1><p>Во время работы Milvus выводит список подробных временных рядов метрик. Для визуализации этих метрик можно использовать <a href="https://prometheus.io/">Prometheus</a> и <a href="https://grafana.com/">Grafana</a>. В данном разделе представлены метрики мониторинга, отображаемые на панели инструментов Milvus в Grafana.</p>
<p>Единицей измерения времени в данном разделе являются миллисекунды. Термин «99-й процентиль» в данном разделе означает, что 99 процентов статистических данных по времени находятся в пределах определенного значения.</p>
<p>Рекомендуем сначала ознакомиться с <a href="/docs/ru/monitor_overview.md">обзором инфраструктуры мониторинга Milvus</a>, чтобы понять, что такое метрики Prometheus.</p>
