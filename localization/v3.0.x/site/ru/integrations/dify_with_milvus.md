    </button></h1><p><a href="https://dify.ai/">Dify</a> — это платформа с открытым исходным кодом, разработанная для упрощения создания приложений искусственного интеллекта за счет объединения модели «бэкенд как услуга» (Backend-as-a-Service) с LLMOps. Она поддерживает основные модели большого языкового моделирования (LLM), предлагает интуитивно понятный интерфейс для оркестрации подсказок, высококачественные движки RAG и гибкую среду для агентов искусственного интеллекта. Благодаря рабочим процессам с минимальным программированием, удобным интерфейсам и API Dify позволяет как разработчикам, так и пользователям без технической подготовки сосредоточиться на создании инновационных, применимых в реальной жизни решений на базе ИИ, не сталкиваясь со сложными техническими проблемами.</p>
<p>В этом руководстве мы покажем, как развернуть Dify с помощью Milvus для обеспечения эффективного поиска и работы движка RAG.</p>
<div class="alert note">
<p>Данная документация в основном основана на официальной <a href="https://docs.dify.ai/">документации Dify</a>. Если вы обнаружите устаревшую или несогласованную информацию, пожалуйста, руководствуйтесь официальной документацией и не стесняйтесь создавать для нас заявки.</p>
</div>

<div class="alert note">
<ul>
<li>Файл ` <code translate="no">MILVUS_URI</code> ` использует ` <code translate="no">host.docker.internal:19530</code> `, что позволяет контейнерам Docker получать доступ к Milvus, запущенному на хост-машине, через внутреннюю сеть Docker.</li>
<li>Конфигурация Dify для Docker Compose по умолчанию включает аутентификацию Milvus. Укажите в файле ` <code translate="no">MILVUS_TOKEN</code> ` значение ` <code translate="no">username:password</code>`; ` <code translate="no">root:Milvus</code> ` использует исходные учетные данные. Если вы изменили учетные данные, замените это значение соответствующим образом.</li>
</ul>
</div>
