    </button></h1><p><a href="https://dify.ai/">O Dify</a> é uma plataforma de código aberto concebida para simplificar a criação de aplicações de IA, combinando Backend-as-a-Service com LLMOps. Suporta os principais modelos de linguagem (LLMs), oferece uma interface intuitiva de orquestração de prompts, motores RAG de alta qualidade e uma estrutura flexível de agentes de IA. Com fluxos de trabalho «low-code», interfaces fáceis de utilizar e APIs, o Dify permite que tanto programadores como utilizadores sem conhecimentos técnicos se concentrem na criação de soluções de IA inovadoras e aplicáveis ao mundo real, sem terem de lidar com complexidades.</p>
<p>Neste tutorial, iremos mostrar-lhe como implementar o Dify com o Milvus, para permitir uma recuperação eficiente e o funcionamento do motor RAG.</p>
<div class="alert note">
<p>Esta documentação baseia-se principalmente na <a href="https://docs.dify.ai/">documentação</a> oficial <a href="https://docs.dify.ai/">do Dify</a>. Se encontrar algum conteúdo desatualizado ou inconsistente, dê prioridade à documentação oficial e não hesite em nos comunicar o problema.</p>
</div>

<pre><code translate="no"><span class="hljs-attr">VECTOR_STORE</span>=milvus

<div class="alert note">
<ul>
<li>O ficheiro ` <code translate="no">MILVUS_URI</code> ` utiliza ` <code translate="no">host.docker.internal:19530</code> `, o que permite que os contentores do Docker acedam ao Milvus em execução na máquina anfitriã através da rede interna do Docker.</li>
<li>A configuração do Docker Compose do Dify ativa a autenticação do Milvus por predefinição. Defina ` <code translate="no">MILVUS_TOKEN</code> ` como ` <code translate="no">username:password</code>`; ` <code translate="no">root:Milvus</code> ` utiliza as credenciais iniciais. Se tiver alterado as credenciais, substitua este valor em conformidade.</li>
</ul>
</div>
