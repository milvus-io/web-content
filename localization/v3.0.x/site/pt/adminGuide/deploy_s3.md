    </button></h1><p>O Milvus utiliza o MinIO como armazenamento de objetos por predefinição, mas também suporta a utilização <a href="https://aws.amazon.com/s3/">do Amazon Simple Storage Service (S3)</a> e de outros armazenamentos de objetos compatíveis com o S3 (por exemplo, o Backblaze B2 ou o Cloudflare R2) como armazenamento persistente de objetos para ficheiros de registo e de índice. Este tópico descreve como configurar o S3 para o Milvus. Pode ignorar este tópico se estiver satisfeito com o MinIO.</p>
<p>Pode configurar o S3 com <a href="https://docs.docker.com/get-started/overview/">o Docker Compose</a> ou no K8s.</p>

<tr><td><code translate="no">externalS3.accessKey</code></td><td>O ID da chave de acesso para o S3.</td><td></td></tr>
<tr><td><code translate="no">externalS3.secretKey</code></td><td>A chave de acesso secreta do S3.</td><td></td></tr>

<button class="copy-code-btn"></button></code></pre>
<ol start="3">
<li>Após configurar as secções anteriores e guardar o ficheiro <code translate="no">values.yaml</code>, execute o seguinte comando para instalar o Milvus utilizando as configurações do S3.</li>
</ol>
<pre><code translate="no" class="language-shell">helm install &lt;your_release_name&gt; milvus/milvus -f values.yaml
<button class="copy-code-btn"></button></code></pre>
