    </button></h2><ul>
<li>O PyMilvus 3.0.2 requer o Python 3.9 ou posterior para se ligar a um servidor Milvus remoto.</li>
<li>Os exemplos locais do Milvus Lite 3.2.2 requerem o Python 3.10 ou superior e uma plataforma suportada. Consulte <a href="/docs/pt/milvus_lite.md">Executar o Milvus Lite localmente</a>.</li>
<li>Instale as dependências através de <code translate="no">pip</code>. O PyMilvus 3.0.2 requer <code translate="no">protobuf&gt;=5.27.2</code>; não fixe separadamente <code translate="no">protobuf==3.20.0</code>. Não é necessário <code translate="no">grpcio-tools</code> para utilizar o SDK.</li>
</ul>

    </button></h2><p>O PyMilvus está disponível no <a href="https://pypi.org/project/pymilvus/">Python Package Index</a>.</p>
<div class="alert note">
Recomenda-se instalar uma versão do PyMilvus que corresponda à versão do servidor Milvus que instalou. Para mais informações, consulte <a href="/docs/pt/release_notes.md">as Notas de Lançamento</a>.
</div>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus==3.0.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Isto instala o cliente para um servidor Milvus remoto. Não instala o Milvus Lite nem um modelo de integração.</p>
<p>Para a base de dados local utilizada no <a href="/docs/pt/quickstart.md">Guia de Início Rápido</a>, instale o extra « <code translate="no">milvus-lite</code> » e o pacote Lite correspondente:</p>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus[milvus-lite]==3.0.2&quot;</span> <span class="hljs-string">&quot;milvus-lite==3.2.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Para os auxiliares de incorporação, instale o extra « <code translate="no">model</code> » separadamente:</p>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus[model]==3.0.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>No Windows, o pip ignora o extra « <code translate="no">milvus-lite</code> » do PyMilvus 3.0.2 devido ao seu marcador de plataforma. O comando acima nomeia explicitamente « <code translate="no">milvus-lite</code> », pelo que é instalado no Windows desde que existam «wheels» para « <code translate="no">faiss-cpu</code> » e « <code translate="no">pyarrow</code> » para a sua versão do Python.</p>
