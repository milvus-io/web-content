    </button></h1><p>O índice <strong>IVF_RABITQ</strong> é um algoritmo de indexação <strong>baseado na quantização binária</strong> que quantiza vetores FP32 em representações binárias. Este índice oferece uma eficiência de armazenamento excecional, com uma taxa de compressão de 1 para 32, mantendo simultaneamente taxas de recuperação relativamente boas. Suporta um refinamento opcional para alcançar uma maior taxa de recuperação à custa de armazenamento adicional, tornando-o um substituto versátil para <a href="/docs/pt/ivf-sq8.md">o IVF_SQ8</a> e <a href="/docs/pt/ivf-flat.md">o IVF_FLAT</a> em cenários com restrições de memória.</p>

    </button></h3><p><strong>O Inverted File (IVF)</strong> organiza o espaço vetorial em regiões geríveis utilizando <a href="https://en.wikipedia.org/wiki/K-means_clustering">agrupamento k-means</a>. Cada agrupamento é representado por um centroide, que serve como ponto de referência para os vetores dentro desse agrupamento. Esta abordagem de agrupamento reduz o espaço de pesquisa, permitindo que o algoritmo se concentre apenas nos agrupamentos mais relevantes durante o processamento da consulta.</p>
<p>Para saber mais sobre os detalhes técnicos do IVF, consulte <a href="/docs/pt/ivf-flat.md">IVF_FLAT</a>.</p>

<p>O RaBitQ introduz vários conceitos inovadores:</p>
<p><strong>Codificação de Informação Angular</strong>: Ao contrário da codificação espacial tradicional, o RaBitQ codifica a informação angular através da normalização de vetores. No IVF_RABITQ, os vetores de dados são normalizados em relação ao seu centroide IVF mais próximo, aumentando a precisão do processo de quantização.</p>

<ol>
<li><p><strong>Filtragem grosseira</strong>: O IVF divide o espaço vetorial em agrupamentos, reduzindo significativamente o âmbito da pesquisa ao concentrar-se nas regiões de agrupamento mais relevantes.</p></li>
<li><p><strong>Quantização binária</strong>: Dentro de cada cluster, o RaBitQ comprime os vetores em representações binárias, preservando simultaneamente as relações de distância essenciais através de garantias teóricas.</p></li>
<li><p><strong>Aperfeiçoamento opcional</strong>: quando ativado, o índice armazena dados aperfeiçoados adicionais utilizando formatos de maior precisão (SQ6, SQ8, FP16, BF16 ou FP32) para melhorar as taxas de recuperação, à custa de um aumento do espaço de armazenamento.</p></li>
</ol>
