      </svg>
    </button></h2><p>No Milvus, uma base de dados funciona como uma unidade lógica para organizar e gerir dados. Para reforçar a segurança dos dados e permitir a multilocação, pode criar várias bases de dados para isolar logicamente os dados de diferentes aplicações ou locatários. Por exemplo, pode criar uma base de dados para armazenar os dados do utilizador A e outra para o utilizador B.</p>
