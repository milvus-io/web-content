    </button></h1><p>No Milvus, um alias é um nome secundário e alterável para uma coleção. A utilização de aliases proporciona uma camada de abstração que permite alternar dinamicamente entre coleções sem modificar o código da sua aplicação. Isto é particularmente útil em ambientes de produção para atualizações de dados sem interrupções, testes A/B e outras tarefas operacionais.</p>
<p>Esta página demonstra como criar, listar, reatribuir e eliminar aliases de coleções.</p>

        ></path>
      </svg>
    </button></h2><p>A principal vantagem de utilizar um alias é dissociar a sua aplicação cliente de um nome de coleção físico específico.</p>
<p>Imagine que tem uma aplicação em produção que consulta uma coleção através de um alias chamado <code translate="no">prod_data</code>. Quando precisar de atualizar os dados subjacentes, pode efetuar a atualização sem qualquer interrupção do serviço. O fluxo de trabalho seria o seguinte:</p>
<ol>
<li><strong>Criar uma nova coleção</strong>: Crie uma nova coleção, por exemplo, <code translate="no">prod_data_v2</code>.</li>
<li><strong>Preparar os dados</strong>: indexar e carregar os novos dados em <code translate="no">prod_data_v2</code>.</li>
<li><strong>Mudar o alias</strong>: Assim que a nova coleção estiver pronta para o serviço, reatribua de forma atómica o alias <code translate="no">prod_data</code> da coleção antiga para <code translate="no">prod_data_v2</code>.</li>
</ol>
<p>A sua aplicação continua a enviar pedidos para o alias <code translate="no">prod_data</code>, sem qualquer tempo de inatividade. Este mecanismo permite atualizações contínuas e simplifica operações como implementações «blue-green» para o seu serviço de pesquisa vetorial.</p>
<p><strong>Principais características dos aliases:</strong></p>
<ul>
<li>Uma coleção pode ter vários aliases.</li>
<li>Um alias só pode apontar para uma coleção de cada vez.</li>
<li>Ao processar um pedido, o Milvus verifica primeiro se existe uma coleção com o nome fornecido. Caso contrário, verifica se o nome é um alias de uma coleção.</li>
</ul>
