Utilize-o quando a sua consulta e os dados armazenados forem ambos representados como listas de vetores e pretender uma recuperação com interação tardia ao nível da entidade, com métricas de « <code translate="no">MAX_SIM*</code> ».</p>
<p>Para conhecer os conceitos básicos do StructArray subjacentes a este tutorial, consulte <a href="/docs/pt/create-structarray-field.md">«Criar um campo StructArray</a>», <a href="/docs/pt/index-structarray-fields.md">«Indexar campos StructArray</a>» e <a href="/docs/pt/basic-vector-search-with-structarray.md">«Pesquisa vetorial básica com StructArray</a>». Este tutorial centra-se nos fluxos de trabalho do ColBERT e do ColPali, em vez de na sintaxe geral do StructArray.</p>

    </button></h2><p>Para criar um sistema de recuperação de texto, poderá ser necessário dividir os documentos em blocos e armazenar cada bloco, juntamente com as suas incorporações, como uma entidade numa base de dados de vetores, a fim de garantir precisão e exatidão, especialmente no caso de documentos longos, em que as incorporações de texto completo poderiam diluir a especificidade semântica ou exceder os limites de entrada do modelo.</p>
<p>No entanto, o armazenamento de dados em fragmentos conduz a resultados de pesquisa por fragmento, o que significa que a recuperação identifica inicialmente <em>segmentos</em> relevantes, em vez de <em>documentos</em> coesos. Para resolver esta questão, deve realizar um processamento adicional pós-pesquisa.</p>
<p>O ColBERT (arXiv: <a href="https://arxiv.org/abs/2004.12832">2004.12832</a>) é um sistema de recuperação texto-texto que oferece uma pesquisa eficiente e eficaz de passagens através de interações contextuais tardias sobre o BERT. Permite a codificação independente, por token, de consultas e documentos e calcula a sua semelhança.</p>
