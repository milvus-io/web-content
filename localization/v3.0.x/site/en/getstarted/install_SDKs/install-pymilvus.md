<li>PyMilvus 3.0.2 requires Python 3.9 or later for connecting to a remote Milvus server.</li>
<li>The local Milvus Lite 3.2.2 examples require Python 3.10 or later and a supported platform. See <a href="/docs/milvus_lite.md">Run Milvus Lite Locally</a>.</li>
<li>Install dependencies through <code translate="no">pip</code>. PyMilvus 3.0.2 requires <code translate="no">protobuf&gt;=5.27.2</code>; do not separately pin <code translate="no">protobuf==3.20.0</code>. You do not need <code translate="no">grpcio-tools</code> to use the SDK.</li>
</ul>

    </button></h2><p>PyMilvus is available in <a href="https://pypi.org/project/pymilvus/">Python Package Index</a>.</p>
<div class="alert note">
It is recommended to install a PyMilvus version that matches the version of the Milvus server you installed. For more information, see <a href="/docs/release_notes.md">Release Notes</a>.
</div>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus==3.0.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>This installs the client for a remote Milvus server. It does not install Milvus Lite or an embedding model.</p>
<p>For the local database used in <a href="/docs/quickstart.md">Quickstart</a>, install the <code translate="no">milvus-lite</code> extra and the matching Lite package:</p>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus[milvus-lite]==3.0.2&quot;</span> <span class="hljs-string">&quot;milvus-lite==3.2.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>For embedding helpers, install the separate <code translate="no">model</code> extra:</p>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus[model]==3.0.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>On Windows, pip skips the <code translate="no">milvus-lite</code> extra of PyMilvus 3.0.2 because of its platform marker. The command above names <code translate="no">milvus-lite</code> explicitly, so it installs on Windows as long as wheels for <code translate="no">faiss-cpu</code> and <code translate="no">pyarrow</code> exist for your Python version.</p>
