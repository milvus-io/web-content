Add only the parameters that you want to change, and use the downloaded <code translate="no">milvus.yaml</code> file as a reference for their names and default values. Milvus reads <code translate="no">user.yaml</code> after <code translate="no">milvus.yaml</code>, so the values in <code translate="no">user.yaml</code> override the defaults. The following example changes the log level:</p>
<pre><code translate="no" class="language-yaml"><span class="hljs-attr">log:</span>
  <span class="hljs-attr">level:</span> <span class="hljs-string">warn</span>
<button class="copy-code-btn"></button></code></pre>

    </button></h2><p>In <code translate="no">docker-compose.yml</code>, map the local path to your <code translate="no">user.yaml</code> file onto <code translate="no">/milvus/configs/user.yaml</code> in the <code translate="no">volumes</code> section of the <code translate="no">standalone</code> service. Keep the existing volume entries and the other settings of the service, such as the image, environment variables, health check, and dependencies:</p>
<pre><code translate="no" class="language-yaml"><span class="hljs-attr">services:</span>
  <span class="hljs-attr">standalone:</span>
    <span class="hljs-attr">volumes:</span>
      <span class="hljs-bullet">-</span> <span class="hljs-string">${DOCKER_VOLUME_DIRECTORY:-.}/volumes/milvus:/var/lib/milvus</span>
      <span class="hljs-bullet">-</span> <span class="hljs-string">/local/path/to/your/user.yaml:/milvus/configs/user.yaml</span>   <span class="hljs-comment"># Map the local path to the container path</span>
<button class="copy-code-btn"></button></code></pre>
<div class="alert note">
Data are stored in the <code translate="no">./volumes</code> folder according to the default configuration in <code translate="no">docker-compose.yml</code>. To change the folder to store data, edit <code translate="no">docker-compose.yml</code> or run <code translate="no">$ export DOCKER_VOLUME_DIRECTORY=</code>.
</div>
