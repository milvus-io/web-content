<p>Milvus gestisce un numero considerevole di parametri che configurano il sistema. Ogni configurazione ha un valore predefinito, che può essere utilizzato direttamente. È possibile modificare questi parametri in modo flessibile affinché Milvus possa soddisfare al meglio le esigenze della propria applicazione. Per ulteriori informazioni, consultare <a href="/docs/it/configure-docker.md">la sezione Configurazione di Milvus</a>.</p>
<div class="alert note">
Nella versione attuale, tutti i parametri hanno effetto solo dopo essere stati configurati all’avvio di Milvus.
</div>

<p>È possibile modificare il proprio MQ impostando il campo mq.type.</p>
<p>Se non si imposta il campo `mq.type` sul valore predefinito, è presente una nota relativa all’abilitazione della priorità nel caso in cui si configurino più MQ in questo file.</p>
<ol>
<li><p>Modalità standalone (locale): rocksmq (predefinito) &gt; Pulsar &gt; Kafka</p></li>
<li><p>modalità cluster: Pulsar (impostazione predefinita) &gt; Kafka (rocksmq non è supportato in modalità cluster)</p></li>
<li><p>Woodpecker può essere utilizzato sia in modalità standalone che in modalità cluster impostando `mq.type` su `woodpecker`.</p></li>
</ol>
