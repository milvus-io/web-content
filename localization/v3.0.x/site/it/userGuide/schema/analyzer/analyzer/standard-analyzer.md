    </button></h1><p>L'analizzatore " <code translate="no">standard</code> " è l'analizzatore predefinito in Milvus, che viene applicato automaticamente ai campi di testo se non viene specificato alcun analizzatore. Utilizza la tokenizzazione basata sulla grammatica, rendendolo efficace per la maggior parte delle lingue.</p>
<div class="alert note">
<p>L'analizzatore " <code translate="no">standard</code> " è adatto alle lingue che utilizzano separatori (come spazi o segni di punteggiatura) per definire i confini delle parole. Tuttavia, lingue come il cinese, l'arabo, il thailandese, il giapponese e il coreano richiedono una tokenizzazione o una normalizzazione specifica per la lingua. In questi casi, utilizzare un analizzatore specifico per la lingua, come <a href="/docs/it/chinese-analyzer.md"><code translate="no">chinese</code></a>, <a href="/docs/it/arabic-analyzer.md"><code translate="no">arabic</code></a>, oppure <a href="/docs/it/thai-analyzer.md"><code translate="no">thai</code></a>, oppure analizzatori personalizzati con tokenizzatori specializzati come <a href="/docs/it/lindera-tokenizer.md"><code translate="no">lindera</code></a> e <a href="/docs/it/icu-tokenizer.md"><code translate="no">icu</code></a>.</p>
</div>

    </button></h2><p>L'analizzatore " <code translate="no">standard</code> " è costituito da:</p>
<ul>
<li><p><strong>Tokenizzatore</strong>: utilizza il tokenizzatore " <code translate="no">standard</code> " per suddividere il testo in singole parole in base alle regole grammaticali. Per ulteriori informazioni, consultare <a href="/docs/it/standard-tokenizer.md">Tokenizzatore standard</a>.</p></li>
<li><p><strong>Filtro</strong>: utilizza il filtro " <code translate="no">lowercase</code> " per convertire tutti i token in minuscolo, consentendo ricerche che non tengono conto delle maiuscole e minuscole. Per ulteriori informazioni, consultare " <a href="/docs/it/lowercase-filter.md">Minuscolo"</a>.</p></li>
</ul>
