    </button></h1><p>Milvus supporta operatori avanzati per l'interrogazione e il filtraggio dei campi JSON, rendendoli perfetti per la gestione di dati complessi e strutturati. Questi operatori consentono un'interrogazione altamente efficace dei documenti JSON, permettendo di recuperare entità in base a elementi, valori o condizioni specifici all'interno dei campi JSON. Questa sezione vi guiderà nell’utilizzo degli operatori specifici per JSON in Milvus, fornendo esempi pratici per illustrarne le funzionalità.</p>
<div class="alert note">
<p>I campi JSON non sono in grado di gestire strutture complesse e annidate e trattano tutte le strutture annidate come semplici stringhe. Pertanto, quando si lavora con i campi JSON, è consigliabile evitare un annidamento eccessivamente profondo e assicurarsi che le strutture dei dati siano il più possibile piatte per ottenere prestazioni ottimali.</p>
</div>

    </button></h2><p>Milvus mette a disposizione diversi potenti operatori JSON che aiutano a filtrare e interrogare i dati JSON; tali operatori sono:</p>
<ul>
<li><p><a href="#JSONCONTAINS"><code translate="no">JSON_CONTAINS(identifier, expr)</code></a>: Filtra le entità in cui l’espressione JSON specificata è presente all’interno del campo.</p></li>
<li><p><a href="#JSONCONTAINSALL"><code translate="no">JSON_CONTAINS_ALL(identifier, expr)</code></a>: Assicura che tutti gli elementi dell’espressione JSON specificata siano presenti nel campo.</p></li>
<li><p><a href="#JSONCONTAINSANY"><code translate="no">JSON_CONTAINS_ANY(identifier, expr)</code></a>: Filtra le entità in cui almeno un membro dell’espressione JSON è presente all’interno del campo.</p></li>
</ul>
<p>Esploriamo questi operatori con alcuni esempi per vedere come possono essere applicati in scenari reali.</p>

    </button></h2><p>L’operatore <code translate="no">json_contains</code> verifica se un elemento specifico o un sottoarray è presente all’interno di un campo JSON. È utile quando si desidera assicurarsi che un array o un oggetto JSON contenga un valore particolare.</p>

Volete filtrare i prodotti che hanno il tag ` <code translate="no">&quot;sale&quot;</code>`.</p>
