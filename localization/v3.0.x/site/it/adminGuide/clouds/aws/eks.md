<li>È necessario che AWS CLI sia installato sul proprio PC locale o su un'istanza Amazon EC2, che fungerà da endpoint per eseguire le operazioni descritte in questo documento. Su Amazon Linux 2 o Amazon Linux 2023, gli strumenti AWS CLI sono già installati. Per installare AWS CLI sul proprio PC locale, consultare la guida <a href="https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html">Come installare AWS CLI</a>.</li>
<li>È necessario che Kubernetes e gli strumenti EKS siano installati sul dispositivo endpoint preferito, tra cui:
<ul>
<li><a href="https://docs.aws.amazon.com/eks/latest/userguide/install-kubectl.html"><code translate="no">kubectl</code></a></li>
<li><a href="https://helm.sh/docs/intro/install/"><code translate="no">helm</code></a></li>
<li><a href="https://docs.aws.amazon.com/eks/latest/userguide/eksctl.html"><code translate="no">eksctl</code></a></li>
</ul></li>
<li>Le autorizzazioni AWS IAM devono essere state concesse correttamente. È possibile seguire una delle seguenti procedure per concedere al proprio soggetto le autorizzazioni appropriate.
<ul>
<li>(Non consigliato) È sufficiente impostare la policy di associazione dell’utente/ruolo utilizzato sulla policy gestita da AWS <code translate="no">AdministratorAccess</code>.</li>
