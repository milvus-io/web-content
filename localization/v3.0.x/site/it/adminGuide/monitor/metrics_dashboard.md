    </button></h1><p>Milvus genera un elenco di metriche dettagliate relative alle serie temporali durante l'esecuzione. È possibile utilizzare <a href="https://prometheus.io/">Prometheus</a> e <a href="https://grafana.com/">Grafana</a> per visualizzare le metriche. Questo argomento illustra le metriche di monitoraggio visualizzate nella dashboard Milvus di Grafana.</p>
<p>L'unità di tempo utilizzata in questo argomento è il millisecondo. Il termine «99° percentile» in questo contesto indica che il 99% delle statistiche temporali rientra entro un determinato valore.</p>
<p>Si consiglia di leggere <a href="/docs/it/monitor_overview.md">la panoramica sul framework di monitoraggio di Milvus</a> per comprendere innanzitutto le metriche di Prometheus.</p>
