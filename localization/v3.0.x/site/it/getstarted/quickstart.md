<p>I vettori, il formato di output dei modelli di reti neurali, sono in grado di codificare efficacemente le informazioni e svolgono un ruolo fondamentale nelle applicazioni di intelligenza artificiale quali le basi di conoscenza, la ricerca semantica, la Retrieval Augmented Generation (RAG) e altro ancora.</p>
<p>Milvus è un database vettoriale open source adatto ad applicazioni di intelligenza artificiale di qualsiasi dimensione, dall’esecuzione di un chatbot dimostrativo in Jupyter Notebook alla creazione di motori di ricerca su scala web al servizio di miliardi di utenti. In questa guida vi illustreremo come configurare Milvus localmente in pochi minuti e come utilizzare la libreria client Python per generare, archiviare ed effettuare ricerche sui vettori.</p>

    </button></h2><p>In Milvus, è necessaria una collezione per memorizzare i vettori e i metadati associati. È possibile considerarla come una tabella nei tradizionali database SQL. Durante la creazione di una collezione, è possibile definire i parametri dello schema e dell’indice per configurare le specifiche dei vettori, quali la dimensionalità, i tipi di indice e le metriche di distanza. Esistono anche concetti complessi per ottimizzare l’indice al fine di migliorare le prestazioni della ricerca vettoriale. Per ora, concentriamoci solo sulle nozioni di base e utilizziamo le impostazioni predefinite per tutto ciò che è possibile. Come minimo, è sufficiente impostare il nome della collezione e la dimensione del campo vettoriale della collezione.</p>
<pre><code translate="no" class="language-python"><span class="hljs-keyword">if</span> client.has_collection(collection_name=<span class="hljs-string">&quot;demo_collection&quot;</span>):
    client.drop_collection(collection_name=<span class="hljs-string">&quot;demo_collection&quot;</span>)
client.create_collection(
    collection_name=<span class="hljs-string">&quot;demo_collection&quot;</span>,
    dimension=<span class="hljs-number">768</span>,  <span class="hljs-comment"># The vectors we will use in this demo have 768 dimensions</span>
)
<button class="copy-code-btn"></button></code></pre>
<p>Nella configurazione sopra riportata,</p>
<ul>
<li>la chiave primaria e i campi vettoriali utilizzano i nomi predefiniti (“id” e “vector”).</li>
<li>Il tipo di metrica (definizione della distanza vettoriale) è impostato sul valore predefinito (<a href="https://milvus.io/docs/metric.md#Cosine-Similarity">COSINE</a>).</li>
<li>Il campo della chiave primaria accetta numeri interi e non viene incrementato automaticamente (ovvero, non utilizza <a href="https://milvus.io/docs/schema.md">la funzione auto-id</a>).
In alternativa, è possibile definire formalmente lo schema della collezione seguendo queste <a href="https://milvus.io/api-reference/pymilvus/v2.4.x/MilvusClient/Collections/create_schema.md">istruzioni</a>.</li>
</ul>

<p>Milvus Lite è l'ideale per muovere i primi passi con un programma Python locale. Se disponi di dati su larga scala o desideri utilizzare Milvus in produzione, puoi scoprire come distribuire Milvus su <a href="https://milvus.io/docs/install_standalone-docker.md">Docker</a> e <a href="https://milvus.io/docs/install_cluster-milvusoperator.md">Kubernetes</a>. Tutte le modalità di distribuzione di Milvus condividono la stessa API, quindi il codice lato client non richiede modifiche significative in caso di passaggio a un’altra modalità di distribuzione. È sufficiente specificare <a href="https://milvus.io/api-reference/pymilvus/v2.4.x/MilvusClient/Client/MilvusClient.md">l’URI e il token</a> di un server Milvus distribuito ovunque:</p>
<pre><code translate="no" class="language-python">client = MilvusClient(uri=<span class="hljs-string">&quot;http://localhost:19530&quot;</span>, token=<span class="hljs-string">&quot;root:Milvus&quot;</span>)
<button class="copy-code-btn"></button></code></pre>
<p>Per migrare i dati da Milvus Lite a Milvus distribuito su Docker o Kubernetes, consultare la guida <a href="/docs/it/milvus_lite.md#Migrating-data-from-Milvus-Lite">alla migrazione dei dati da Milvus Lite</a>.</p>
<p>Milvus fornisce API REST e gRPC, con librerie client in linguaggi quali <a href="https://milvus.io/docs/install-pymilvus.md">Python</a>, <a href="https://milvus.io/docs/install-java.md">Java</a>, <a href="https://milvus.io/docs/install-go.md">Go</a>, C# e <a href="https://milvus.io/docs/install-node.md">Node.js</a>.</p>
<p>Per la progettazione dello schema, Milvus supporta un approccio flessibile, in cui è possibile definire i campi e i relativi tipi di dati, compresi i campi vettoriali. È inoltre possibile definire il tipo di indice e i parametri per ciascun campo. Per ulteriori informazioni, consultare <a href="https://milvus.io/docs/schema-hands-on.md">Progettazione del modello di dati per la ricerca</a>.</p>
