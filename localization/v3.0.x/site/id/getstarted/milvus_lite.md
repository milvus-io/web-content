    </button></h2><p>Milvus Lite dapat diimpor ke dalam aplikasi Python Anda, sehingga menyediakan fungsi pencarian vektor inti dari Milvus. Milvus Lite sudah disertakan dalam <a href="https://github.com/milvus-io/pymilvus">SDK Python Milvus</a>. Milvus Lite dapat dengan mudah diterapkan menggunakan <code translate="no">pip install pymilvus</code>.</p>
<p>Dengan Milvus Lite, Anda dapat mulai membangun aplikasi AI dengan pencarian kesamaan vektor dalam hitungan menit! Milvus Lite cocok untuk dijalankan di lingkungan berikut:</p>
<ul>
<li>Jupyter Notebook / Google Colab</li>
<li>Laptop</li>
<li>Perangkat Edge</li>
</ul>
<p>Milvus Lite menggunakan API yang sama dengan Milvus Standalone dan Distributed, serta mencakup sebagian besar fitur seperti penyimpanan dan pengelolaan data vektor, operasi CRUD vektor, pencarian vektor spars dan padat, penyaringan metadata, serta pencarian multi-vektor dan hybrid_search. Secara bersama-sama, fitur-fitur ini memberikan pengalaman yang konsisten di berbagai jenis lingkungan, mulai dari perangkat tepi hingga kluster di cloud, sehingga cocok untuk kasus penggunaan dengan skala yang beragam. Dengan kode sisi klien yang sama, Anda dapat menjalankan aplikasi GenAI dengan Milvus Lite di laptop atau Jupyter Notebook, atau Milvus Standalone di kontainer Docker, atau Milvus Distributed di kluster Kubernetes berskala besar yang melayani miliaran vektor dalam produksi.</p>

Anda juga dapat mempertimbangkan Milvus yang dikelola sepenuhnya di <a href="https://zilliz.com/cloud">Zilliz Cloud</a>.</p>

usage: milvus-lite dump [-h] [-d DB_FILE] [-c COLLECTION] [-p PATH]

optional arguments:
