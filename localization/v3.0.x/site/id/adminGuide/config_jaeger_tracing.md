<pre><code translate="no" class="language-shell"><span class="hljs-meta prompt_">$ </span><span class="language-bash">helm repo add jaegertracing https://jaegertracing.github.io/helm-charts</span>

<span class="hljs-meta prompt_">$ </span><span class="language-bash">helm install jaeger jaegertracing/jaeger --version 4.19.0</span>
<button class="copy-code-btn"></button></code></pre>
<p>Bagian README chart menandai chart ini sebagai eksperimental dan menyatakan bahwa perubahan yang memengaruhi kompatibilitas mundur mungkin terjadi pada versi minor, sehingga perintah ini mengunci versi chart. Versi chart 4.19.0 menginstal Jaeger 2.23.0.</p>

        ></path>
      </svg>
    </button></h2><p>Untuk mengirim jejak dari Milvus ke Jaeger melalui OTLP, simpan pengaturan berikut dalam berkas bernama <code translate="no">values.yaml</code>:</p>
<pre><code translate="no" class="language-yaml"><span class="hljs-attr">extraConfigFiles:</span>
  <span class="hljs-attr">user.yaml:</span> <span class="hljs-string">|+
    trace:
      exporter: otlp
      sampleFraction: 1
      otlp:
        endpoint: &quot;jaeger:4317&quot;
        method: grpc
        secure: false
</span><button class="copy-code-btn"></button></code></pre>
<p>Dengan pengaturan ini, Milvus mengambil sampel setiap permintaan (<code translate="no">sampleFraction: 1</code>) dan mengekspor jejak melalui OTLP gRPC tanpa TLS (<code translate="no">secure: false</code>) ke port <code translate="no">4317</code> dari layanan <code translate="no">jaeger</code>.</p>
<p>Untuk menerapkan pengaturan di atas ke deployment Milvus baru, jalankan perintah berikut:</p>
<pre><code translate="no" class="language-shell"><span class="hljs-meta prompt_">$ </span><span class="language-bash">helm repo add zilliztech https://zilliztech.github.io/milvus-helm/</span>
<span class="hljs-meta prompt_">$ </span><span class="language-bash">helm repo update</span>
<span class="hljs-meta prompt_">$ </span><span class="language-bash">helm upgrade --install my-release zilliztech/milvus --version 5.0.22 -f values.yaml</span>
<button class="copy-code-btn"></button></code></pre>
<p>Untuk menerapkan pengaturan di atas ke deployment Milvus yang sudah ada, jalankan perintah berikut:</p>
<pre><code translate="no" class="language-shell"><span class="hljs-meta prompt_">$ </span><span class="language-bash">helm upgrade my-release zilliztech/milvus --version &lt;current-chart-version&gt; --reset-then-reuse-values -f values.yaml</span>
<button class="copy-code-btn"></button></code></pre>
<div class="alert note">
<p>Perintah ini menggunakan opsi ` <code translate="no">--reset-then-reuse-values</code>`, yang memerlukan Helm versi 3.14 atau yang lebih baru. Dengan opsi ini, Helm akan mengatur ulang nilai-nilai ke nilai default versi chart yang ditetapkan di <code translate="no">--version</code>, menerapkan nilai-nilai dari rilis Anda saat ini, dan kemudian menerapkan nilai-nilai dari <code translate="no">-f</code>. Oleh karena itu, setiap nilai di <code translate="no">values.yaml</code> akan menggantikan nilai dari rilis Anda saat ini, dan entri ` <code translate="no">user.yaml</code> ` di bawah <code translate="no">extraConfigFiles</code> akan diganti secara keseluruhan. Untuk menemukan ` <code translate="no">&lt;current-chart-version&gt;</code>`, jalankan ` <code translate="no">helm list</code> ` dan hapus awalan ` <code translate="no">milvus-</code> ` dari nilai di kolom ` <code translate="no">CHART</code> `. Jika Anda menjalankan ` <code translate="no">helm upgrade</code> ` dengan ` <code translate="no">-f</code> ` atau ` <code translate="no">--set</code> ` tetapi tanpa ` <code translate="no">--reset-then-reuse-values</code> ` atau ` <code translate="no">--reuse-values</code>`, Helm tidak akan mempertahankan nilai yang Anda tetapkan saat instalasi.</p>
</div>
