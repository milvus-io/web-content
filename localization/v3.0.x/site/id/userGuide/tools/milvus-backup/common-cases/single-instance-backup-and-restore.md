<p>Asumsikan kita memiliki sebuah instance Milvus, <code translate="no">milvus_A</code>, yang menggunakan bucket bernama<code translate="no">bucket_A</code> untuk penyimpanan data. Dalam contoh ini, tujuan kita adalah menyelesaikan
tugas-tugas berikut:</p>
<ol>
<li><p>Membuat cadangan (<code translate="no">my_backup</code>) untuk koleksi coll di <code translate="no">bucket_A</code>.</p></li>
<li><p>Memulihkan dari cadangan dan menamai koleksi yang dipulihkan sebagai <code translate="no">coll_bak</code>.</p></li>
</ol>

berikut:</p>
<pre><code translate="no" class="language-shell">./milvus-backup restore -c coll -n my_backup -s _bak --config configs/backup.yaml
<button class="copy-code-btn"></button></code></pre>
<p>Perintah ini memulihkan data dari cadangan dan membuat koleksi baru bernama
coll_bak di <code translate="no">milvus_A</code>, menggunakan akar penyimpanan yang dikonfigurasi pada instance <code translate="no">bucket_A/files</code>.</p>
<p>Pada Backup 0.5.16, opsi <code translate="no">-c</code> yang sudah tidak direkomendasikan lagi memilih nama koleksi dalam cadangan, sebelum <code translate="no">_bak</code> diterapkan. Penggantinya pada versi 0.6.0, <code translate="no">--filter</code>, menggunakan nama target sebagai gantinya; lihat <a href="/docs/id/milvus_backup_upgrade.md#Update-CLI-commands">Perbarui perintah CLI</a>.</p>
<p>Setelah pemulihan, pastikan bahwa <code translate="no">coll_bak</code> ada, buat indeks vektor yang sesuai jika diperlukan, dan bandingkan jumlah entitas, nilai representatif, serta hasil pencariannya dengan baseline yang diambil sebelum pencadangan. Perintah yang berhasil saja tidak menjamin keakuratan data.</p>
