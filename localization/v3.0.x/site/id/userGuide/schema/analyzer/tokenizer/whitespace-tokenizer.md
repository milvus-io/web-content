<p>Pemisah-pemisah ini diabaikan, dan pemisah yang berurutan tidak menghasilkan token kosong. Tanda baca dan karakter lainnya tetap ada dalam token. Secara khusus, tab vertikal (<code translate="no">\x0B</code>, U+000B), spasi anti-pemecahan (<code translate="no">\u00A0</code>), dan spasi ideografis (<code translate="no">\u3000</code>) tidak memicu pemisahan.</p>
<p>Kumpulan ini mengikuti aturan Rust’s <a href="https://doc.rust-lang.org/std/primitive.char.html#method.is_ascii_whitespace"><code translate="no">char::is_ascii_whitespace()</code></a>, yang mengecualikan karakter spasi kosong Unicode lainnya.</p>
<p>Contoh-contoh berikut menggunakan <code translate="no">{&quot;tokenizer&quot;: &quot;whitespace&quot;}</code> tanpa filter. Masukan dan keluaran menggunakan notasi string Python: urutan escape seperti <code translate="no">\t</code> dan <code translate="no">\u00A0</code> mewakili karakter sebenarnya.</p>
