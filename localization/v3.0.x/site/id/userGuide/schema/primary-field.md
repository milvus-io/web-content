    </button></h2><p>Kolom utama berfungsi sebagai kunci unik untuk setiap entitas dalam sebuah koleksi, mirip dengan kunci utama dalam basis data tradisional. Milvus menggunakan kolom utama untuk mengelola entitas selama operasi penyisipan, pembaruan, penghapusan, dan kueri.</p>
<p>Persyaratan utama:</p>
<ul>
<li><p>Setiap koleksi harus memiliki <strong>tepat satu</strong> bidang utama.</p></li>
<li><p>Nilai bidang utama tidak boleh null.</p></li>
<li><p>Tipe data harus ditentukan saat pembuatan dan tidak dapat diubah kemudian.</p></li>
</ul>

<table>
   <tr>
     <th><p>Tipe Data</p></th>
     <th><p>Deskripsi</p></th>
   </tr>
   <tr>
     <td><p><code translate="no">INT64</code></p></td>
     <td><p>Tipe bilangan bulat 64-bit, umumnya digunakan dengan AutoID. Ini adalah opsi yang direkomendasikan untuk sebagian besar kasus penggunaan.</p></td>
   </tr>
   <tr>
     <td><p><code translate="no">VARCHAR</code></p></td>
     <td><p>Tipe string panjang variabel. Gunakan ini ketika pengidentifikasi entitas berasal dari sistem eksternal (misalnya, kode produk atau ID pengguna). Membutuhkan properti ` <code translate="no">max_length</code> ` untuk menentukan jumlah byte maksimum yang diperbolehkan per nilai.</p></td>
   </tr>
</table>

        ></path>
      </svg>
    </button></h2><p>Milvus mendukung dua mode untuk menetapkan nilai kunci utama.</p>
<table>
   <tr>
     <th><p>Mode</p></th>
     <th><p>Deskripsi</p></th>
     <th><p>Direkomendasikan Untuk</p></th>
   </tr>
   <tr>
     <td><p>AutoID</p></td>
     <td><p>Milvus secara otomatis menghasilkan pengenal unik untuk entitas yang disisipkan atau diimpor.</p></td>
     <td><p>Sebagian besar skenario di mana Anda tidak perlu mengelola ID secara manual.</p></td>
   </tr>
   <tr>
     <td><p>ID Manual</p></td>
     <td><p>Anda sendiri yang menentukan ID unik saat menyisipkan atau mengimpor data.</p></td>
     <td><p>Hal ini berlaku ketika ID harus selaras dengan sistem eksternal atau kumpulan data yang sudah ada sebelumnya.</p></td>
   </tr>
</table>
<div class="alert note">
<ul>
<li><p>Jika Anda ragu mode mana yang harus dipilih, <a href="/docs/id/primary-field.md#Quickstart-Use-AutoID">mulailah dengan AutoID</a> untuk proses pengimporan yang lebih sederhana dan keunikan yang terjamin.</p></li>
<li><p>Anda disarankan untuk mengandalkan " <code translate="no">autoId</code> " dalam semua kasus kecuali jika pengaturan kunci utama secara manual memberikan manfaat.</p></li>
</ul>
</div>
