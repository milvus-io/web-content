    </button></h1><p><a href="https://github.com/meta-llama/llama-stack/tree/main">Llama Stack</a>是一種以服務為導向、API 優先的架構，專為建置生產級 AI 應用程式而設計。它提供了一個通用技術堆疊，讓開發者能夠在任何地方開發、部署至任何環境，並利用真正具備供應商獨立性的生產級組件。Llama Stack 著重於 Meta 的 Llama 模型、可組合性、生產就緒性，以及合作夥伴生態系統。</p>
<p>在本教學中，我們將介紹如何建置一臺配置了 Milvus 的 Llama Stack 伺服器，讓您能夠匯入私有資料作為知識庫。接著，我們將在伺服器上執行查詢，打造一套完整的 RAG 應用程式。</p>

    </button></h3><p>由於我們需要使用 Together AI 作為大型語言模型（LLM）服務，因此必須先登入官方網站申請<a href="https://api.together.xyz/settings/api-keys">API 金鑰</a>，並將 API 金鑰<code translate="no">TOGETHER_API_KEY</code> 設定為環境變數。</p>
<p>克隆 Llama Stack 原始碼</p>
<pre><code translate="no" class="language-bash">$ git <span class="hljs-built_in">clone</span> https://github.com/meta-llama/llama-stack.git
$ <span class="hljs-built_in">cd</span> llama-stack
<button class="copy-code-btn"></button></code></pre>
<p>建立 conda 環境並安裝依賴項</p>
<pre><code translate="no" class="language-bash">$ conda create -n stack python=3.10
$ conda activate stack

$ pip install -e .
<button class="copy-code-btn"></button></code></pre>
<p>修改<code translate="no">llama_stack/llama_stack/templates/together/run.yaml</code> 中的內容，將 vector_io 區段變更為相關的 Milvus 配置。例如，新增：</p>
<pre><code translate="no" class="language-yaml"><span class="hljs-attr">vector_io:</span>
<span class="hljs-bullet">-</span> <span class="hljs-attr">provider_id:</span> <span class="hljs-string">milvus</span>
  <span class="hljs-attr">provider_type:</span> <span class="hljs-string">inline::milvus</span>
  <span class="hljs-attr">config:</span>
    <span class="hljs-attr">db_path:</span> <span class="hljs-string">~/.llama/distributions/together/milvus_store.db</span>

<span class="hljs-comment">#  - provider_id: milvus</span>
<span class="hljs-comment">#    provider_type: remote::milvus</span>
<span class="hljs-comment">#    config:</span>
<span class="hljs-comment">#      uri: http://localhost:19530</span>
<span class="hljs-comment">#      token: root:Milvus</span>
<button class="copy-code-btn"></button></code></pre>
<p>在 Llama Stack 中，Milvus 可透過兩種方式進行配置：本地配置（即<code translate="no">inline::milvus</code> ）與遠端配置（即<code translate="no">remote::milvus</code> ）。</p>
<ul>
<li><p>最簡單的方法是本地配置，這需要設定<code translate="no">db_path</code> ，作為本地儲存<a href="https://milvus.io/docs/quickstart.md">Milvus-Lite</a>檔案的路徑。</p></li>
<li><p>遠端配置則適用於大型資料儲存。</p>
<ul>
<li>若您擁有大量資料，可在<a href="https://milvus.io/docs/quickstart.md">Docker 或 Kubernetes</a> 上架設高效能的 Milvus 伺服器。在此設定中，請將伺服器 URI（例如<code translate="no">http://localhost:19530</code> ）作為您的<code translate="no">uri</code> 。預設的<code translate="no">token</code> 為<code translate="no">root:Milvus</code> 。</li>
<li>若您欲使用<a href="https://zilliz.com/cloud">Zilliz Cloud</a>（Milvus 的全託管雲端服務），請調整<code translate="no">uri</code> 和<code translate="no">token</code> ，這兩者分別對應於 Zilliz Cloud 中的「<a href="https://docs.zilliz.com/docs/on-zilliz-cloud-console#free-cluster-details">公開端點」與「API 金鑰」</a>。</li>
</ul></li>
</ul>
