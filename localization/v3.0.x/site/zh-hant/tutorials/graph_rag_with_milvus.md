<p>大型語言模型的廣泛應用，凸顯了提升其回應準確性與相關性的重要性。 檢索增強生成（RAG）透過外部知識庫強化模型，提供更多語境資訊，並緩解「幻覺」與「知識不足」等問題。然而，僅依賴簡單的 RAG 範式存在其局限性，特別是在處理複雜的實體關係與多跳問題時，模型往往難以提供準確的答案。</p>
<p>將知識圖譜（KGs）引入 RAG 系統提供了一種新的解決方案。知識圖譜以結構化的方式呈現實體及其關係，提供更精確的檢索資訊，並協助 RAG 更好地處理複雜的問答任務。 KG-RAG 仍處於早期階段，目前對於如何有效從知識圖譜中檢索實體與關係，以及如何將向量相似度搜尋與圖結構整合，尚無共識。</p>
<p>在本筆記本中，我們介紹了一種簡單卻強大的方法，用以大幅提升此情境下的表現。這是一種採用多路檢索並進行重新排序的簡易 RAG 範式，但它在邏輯上實現了圖 RAG（Graph RAG），並在處理多跳問題時達到了最先進的表現。 讓我們來看看它的具體實現方式。</p>
