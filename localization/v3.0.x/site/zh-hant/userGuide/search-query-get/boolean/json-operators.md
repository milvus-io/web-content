    </button></h1><p>Milvus 支援用於查詢和篩選 JSON 欄位的進階運算子，使其成為管理複雜、結構化資料的理想工具。這些運算子能讓您高效地查詢 JSON 文件，並根據 JSON 欄位中的特定元素、值或條件來擷取實體。 本節將引導您了解如何在 Milvus 中使用 JSON 專用運算子，並透過實用範例說明其功能。</p>
<div class="alert note">
<p>JSON 欄位無法處理複雜的嵌套結構，並會將所有嵌套結構視為純文字。因此，在處理 JSON 欄位時，建議避免過深的嵌套，並確保資料結構盡可能扁平化，以獲得最佳效能。</p>
</div>

    </button></h2><p>Milvus 提供數種強大的 JSON 運算子，有助於篩選和查詢 JSON 資料，這些運算子包括：</p>
<ul>
<li><p><a href="#JSONCONTAINS"><code translate="no">JSON_CONTAINS(identifier, expr)</code></a>: 篩選該欄位中包含指定 JSON 表達式的實體。</p></li>
<li><p><a href="#JSONCONTAINSALL"><code translate="no">JSON_CONTAINS_ALL(identifier, expr)</code></a>: 確保指定 JSON 表達式中的所有元素均存在於該欄位中。</p></li>
<li><p><a href="#JSONCONTAINSANY"><code translate="no">JSON_CONTAINS_ANY(identifier, expr)</code></a>: 篩選該欄位中至少包含 JSON 表達式中任一成員的實體。</p></li>
</ul>
<p>讓我們透過範例來探索這些運算子，了解它們如何應用於實際情境中。</p>
