    </button></h1><p><code translate="no">icu</code> 詞元化器建構於<a href="http://site.icu-project.org/">「Unicode 國際化元件」</a>（ICU）開源專案之上，該專案為軟體國際化提供了關鍵工具。透過運用 ICU 的斷詞演算法，此詞元化器能將全球多數語言的文字精準地分割為單詞。</p>
<div class="alert note">
<p><code translate="no">icu</code> 詞元化器會在輸出中將標點符號和空格保留為獨立的詞元。例如，<code translate="no">&quot;Привет! Как дела?&quot;</code> 會變成<code translate="no">[&quot;Привет&quot;, &quot;!&quot;, &quot; &quot;, &quot;Как&quot;, &quot; &quot;, &quot;дела&quot;, &quot;?&quot;]</code> 。若要移除這些獨立的標點詞元，請使用 <a href="/docs/zh-hant/removepunct-filter.md"><code translate="no">removepunct</code></a> 篩選器。</p>
</div>
