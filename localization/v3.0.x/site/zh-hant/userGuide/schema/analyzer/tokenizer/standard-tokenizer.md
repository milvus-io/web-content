    </button></h2><p><code translate="no">standard</code> 分詞器會將屬於以下集合的連續字元保留在同一個詞元中：</p>
<ul>
<li><strong>ASCII 字元：</strong>字母<code translate="no">A-Z</code> 和<code translate="no">a-z</code> ，以及數字<code translate="no">0-9</code> 。</li>
<li><strong>非 ASCII 字元：</strong>具有 Unicode<code translate="no">Alphabetic</code> 屬性，或屬於以下數值通用類別之一的字元：<code translate="no">Nd</code> 、<code translate="no">Nl</code> 或<code translate="no">No</code> 。</li>
</ul>
<table>
<thead>
<tr><th>Unicode 屬性或類別</th><th>含義</th><th>保留在標記中的字元範例</th></tr>
</thead>
<tbody>
<tr><td><code translate="no">Alphabetic</code></td><td>跨書寫系統的字母（包括漢字和日語假名），以及某些組合標記</td><td><code translate="no">中文测试</code>,<code translate="no">カタカナ</code></td></tr>
<tr><td><code translate="no">Nd</code> (<code translate="no">Decimal_Number</code>)</td><td>十進位數字</td><td><code translate="no">٣</code></td></tr>
<tr><td><code translate="no">Nl</code> (<code translate="no">Letter_Number</code>)</td><td>類似字母的數字字元</td><td><code translate="no">Ⅷ</code></td></tr>
<tr><td><code translate="no">No</code> (<code translate="no">Other_Number</code>)</td><td>其他數字字元，例如圈號、上標及分數</td><td><code translate="no">①²¾</code></td></tr>
</tbody>
</table>
<p>這些集合以外的字元會用來分隔標記，並被捨棄。這些字元包括空白、標點符號、底線 (<code translate="no">_</code>)、連字號 (<code translate="no">-</code>)、單引號 (<code translate="no">'</code>)，以及符號如<code translate="no">+</code> 、<code translate="no">$</code> 和<code translate="no">😀</code> 。連續的分隔符號不會產生空標記。</p>
<p>字元分類遵循 Rust 的 <a href="https://doc.rust-lang.org/std/primitive.char.html#method.is_alphanumeric"><code translate="no">char::is_alphanumeric()</code></a>。有關屬性定義，請參閱《<a href="https://www.unicode.org/reports/tr44/">Unicode 標準附錄 #44</a>》。完整的 Unicode 17.0 字元清單可於 <a href="https://www.unicode.org/Public/17.0.0/ucd/DerivedCoreProperties.txt"><code translate="no">DerivedCoreProperties.txt</code></a><code translate="no">Alphabetic</code> 以及 <a href="https://www.unicode.org/Public/17.0.0/ucd/extracted/DerivedGeneralCategory.txt"><code translate="no">DerivedGeneralCategory.txt</code></a><code translate="no">Nd</code> 、<code translate="no">Nl</code> 及<code translate="no">No</code> 的完整 Unicode 17.0 字元清單。字元歸屬取決於部署版本所使用的 Unicode 資料。</p>
<p>以下範例使用未套用任何篩選條件的<code translate="no">{&quot;tokenizer&quot;: &quot;standard&quot;}</code> 。該詞元化器會保留字母的大小寫，且不會將連續的中文文字分割成單獨的詞彙。</p>
