      </svg>
    </button></h2><p><code translate="no">english</code> 分析器使用以下元件：</p>
<ul>
<li><p><strong>分詞器</strong>：使用<a href="/docs/zh-hant/standard-tokenizer.md"><code translate="no">standard</code> 分詞器</a>，將文字分割為獨立的單字單位。</p></li>
<li><p><strong>篩選器</strong>：包含多個篩選器，用於全面的文字處理：</p>
<ul>
<li><p><a href="/docs/zh-hant/lowercase-filter.md"><code translate="no">lowercase</code></a>：將所有詞元轉換為小寫，以實現不區分大小寫的搜尋。</p></li>
<li><p><a href="/docs/zh-hant/stemmer-filter.md"><code translate="no">stemmer</code></a>：將單字還原為詞根形式，以支援更廣泛的匹配（例如，「running」會變成「run」）。</p></li>
<li><p><a href="/docs/zh-hant/stop-filter.md"><code translate="no">stop_words</code></a>：移除常見的英文停用詞，以聚焦於文本中的關鍵詞。</p></li>
</ul></li>
</ul>
