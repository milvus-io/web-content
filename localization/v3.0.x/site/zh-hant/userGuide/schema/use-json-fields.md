<ul>
<li><p><code translate="no">metadata</code> 是資料結構中定義的 JSON 欄位。</p></li>

    </button></h2><p>若要使用 JSON 欄位，請在集合架構中明確定義該欄位，並將 `<code translate="no">DataType</code> ` 指定為 `<code translate="no">JSON</code>`。</p>
<p>以下範例建立一個集合，其架構包含以下欄位：</p>
<ul>
<li><p>主鍵（<code translate="no">product_id</code> ）</p></li>
<li><p>一個 `<code translate="no">vector</code> ` 欄位（每個集合皆為必填）</p></li>
<li><p>類型為 `<code translate="no">JSON</code>` 的 `<code translate="no">metadata</code> ` 欄位，可用於儲存結構化資料，例如平面值、陣列或嵌套物件</p></li>
</ul>

<ul>
<li><p><strong>JSON 路徑</strong>(<code translate="no">json_path</code>)：您要建立索引的 JSON 物件中，該鍵或嵌套欄位的路徑。</p>
<ul>
<li><p>範例：</p>
<ul>
<li><p>針對鍵，<code translate="no">metadata[&quot;category&quot;]</code></p></li>
<li><p>若為嵌套欄位，<code translate="no">metadata[&quot;contact&quot;][&quot;email&quot;]</code></p></li>
</ul>
<p>這定義了索引引擎應在 JSON 結構中的何處進行檢索。</p></li>
</ul></li>
<li><p><strong>JSON 轉換類型</strong>(<code translate="no">json_cast_type</code>)：Milvus 在解析及索引指定路徑下的值時應使用的資料類型。</p>
<ul>
<li><p>此類型必須與正在建立索引的欄位之實際資料類型相符。若您希望在建立索引時將資料類型轉換為其他類型，請考慮<a href="/docs/zh-hant/use-json-fields.md#Use-JSON-cast-functions-for-type-conversion--Milvus-2514">使用轉換函式</a>。</p></li>
<li><p>完整清單請參閱<a href="/docs/zh-hant/use-json-fields.md#Supported-JSON-cast-types">下方</a>。</p></li>
</ul></li>
</ul>
