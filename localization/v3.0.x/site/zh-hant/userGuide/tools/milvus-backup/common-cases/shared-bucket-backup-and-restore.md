作為物件儲存，且每個實例具有不同的根路徑。</p>

<p>假設我們有兩個 Milvus 實例：<code translate="no">milvus_A</code> 和<code translate="no">milvus_B</code> ，兩者皆使用
預設的 MinIO 儲存引擎進行物件儲存。這些實例
共用同一個儲存桶<code translate="no">bucket_A</code> ，但各自將資料儲存於不同的根
路徑：<code translate="no">milvus_A</code> 儲存於<code translate="no">files_A</code> ，而<code translate="no">milvus_B</code> 則儲存於 files_B。在此範例中，
我們的目標是完成以下任務：</p>
<ol>
<li><p>為集合 coll 建立一個備份 (my_backup)，並將其儲存於
<code translate="no">files_A</code> 路徑下，供<code translate="no">milvus_A</code> 使用。</p></li>
<li><p>從備份還原資料，並將其儲存至<code translate="no">milvus_B</code> 的 files_B 中。</p></li>
</ol>
