</ul>

    </button></h3><p><a href="https://en.wikipedia.org/wiki/MinHash">MinHash</a>是一種機率性技術，能提供估算雅卡德相似度的有效方法。其運作原理是將每個集合轉換為緊湊的<strong>簽名向量</strong>，同時保留足夠的資訊以高效地近似集合相似度。</p>
<p><strong>核心概念</strong>：</p>
<p>兩個集合越相似，其 MinHash 簽名在相同位置匹配的可能性就越高。此特性使 MinHash 能夠近似計算集合之間的雅卡德相似度。</p>
<p>此特性使 MinHash 無需直接比較完整集合，<strong>即可近似計算</strong>集合之間的<strong>雅卡德相似度</strong>。</p>
<p>MinHash 的運作流程包含：</p>
<ol>
<li><p><strong>分片</strong>：將文件轉換為重疊的標記序列集合（分片）</p></li>
<li><p><strong>雜湊</strong>：對每個片段應用多個獨立的雜湊函數</p></li>
<li><p><strong>最小值篩選</strong>：針對每個哈希函數，記錄所有片段中的<strong>最小</strong>哈希值</p></li>
</ol>

    </button></h3><p>儘管 MinHash 簽名能顯著降低計算文件間精確 Jaccard 相似度的成本，但在大規模應用時，仍需耗費大量資源來逐對比對每個簽名向量。</p>
<p>為解決此問題，採用了<a href="https://zilliz.com/learn/Local-Sensitivity-Hashing-A-Comprehensive-Guide">LSH</a>。LSH 透過確保相似項目以高機率被哈希到同一個「桶」中，從而實現快速的近似相似度搜尋——避免了必須直接比較每一對的必要性。</p>
<p>該過程包含：</p>
<ol>
<li><p><strong>簽名分段：</strong></p>
<p>將<em>n 維的</em> MinHash 簽名劃分為<em>b 個</em>頻帶。每個頻帶包含<em>r 個</em>連續的雜湊值，因此簽名的總長度滿足：<em>n = b × r</em>。</p>
<p>舉例來說，若有一組 128 維的 MinHash 簽名（<em>n = 128</em>），並將其劃分為 32 個區段（<em>b = 32</em>），則每個區段包含 4 個雜湊值（<em>r = 4</em>）。</p></li>
<li><p><strong>頻帶級哈希運算：</strong></p>
<p>分割後，每個頻帶會透過標準雜湊函數獨立處理，並將其分配至一個桶位。若兩個簽名在同一個頻帶內產生相同的雜湊值——也就是說，它們落入同一個桶位——則被視為潛在匹配。</p></li>
<li><p><strong>候選項篩選：</strong></p>
<p>在至少一個頻段中發生碰撞的配對，將被選為相似性候選對。</p></li>
</ol>

      </svg>
    </button></h3><p>MinHash 簽名是透過固定長度的二進位向量，來近似表示集合間的 Jaccard 相似度。然而，由於這些簽名並未保留原始集合的結構，因此無法直接套用標準指標（如<code translate="no">JACCARD</code> 、<code translate="no">L2</code> 或<code translate="no">COSINE</code> ）來進行比較。</p>
<p>為解決此問題，Milvus 引入了一種名為<code translate="no">MHJACCARD</code> 的專用度量類型，專門用於比較 MinHash 簽名。</p>
<p>在 Milvus 中使用 MinHash 時：</p>
<ul>
<li><p>向量欄位必須為<code translate="no">BINARY_VECTOR</code></p></li>
<li><p><code translate="no">index_type</code> 必須為<code translate="no">MINHASH_LSH</code> （或<code translate="no">BIN_FLAT</code> ）</p></li>
<li><p><code translate="no">metric_type</code> 必須設定為<code translate="no">MHJACCARD</code></p></li>
</ul>
<p>若使用其他指標，將導致無效或產生錯誤結果。</p>
<p>有關此度量類型的更多資訊，請參閱<a href="/docs/zh-hant/metric.md#MHJACCARD">MHJACCARD</a>。</p>
