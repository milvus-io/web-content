<p>自 Milvus v2.5 起<strong>，milvus-helm</strong>和<strong>milvus-operator</strong>將預設使用 Pulsar V3，以修復部分錯誤及安全漏洞。​ 雖然 Milvus 2.5 與 Pulsar 2.x 相容，但升級至 Pulsar V3 屬可選操作。為提升穩定性與效能，我們建議您升級至 Pulsar V3。</p>
<p>若您希望在 Milvus v2.5.x 中使用 Pulsar V2，請參閱《<a href="/docs/zh-hant/use-pulsar-v2.md">在 Milvus v2.5.x 中使用 Pulsar V2</a>》。</p>
<div class="alert note">
<ol>
<li><p>升級過程需要短暫的中斷服務（通常耗時數分鐘至十多分鐘不等，視資料量而定）。​</p></li>
<li><p>操作前，您需要停止所有正在運行的客戶端向 Milvus 寫入資料。否則，已寫入的資料可能會遺失。​</p></li>
<li><p>本文假設 Milvus 安裝於命名空間<code translate="no">default</code> ，且命名為<code translate="no">my-release</code> 。執行從本頁複製的指令時，請將參數替換為您自己的命名空間及版本名稱。​</p></li>
<li><p>請確保您的工作環境在 Kubernetes 叢集的上述命名空間下具備權限，且已安裝以下指令：​</p>
<p>a.<code translate="no">kubectl</code> &gt;= 1.20​</p>
<p>b.<code translate="no">helm</code> &gt;= 3.14.0​</p>
<p>c.<code translate="no">cat</code> 、<code translate="no">grep</code> 、<code translate="no">awk</code> ，用於字串處理操作​</p>
<p>d. 需使用<code translate="no">curl</code> 或<strong>Attu v2.4+</strong>才能與 Milvus 管理 API 進行互動​</p></li>
</ol>
</div>

<h4 id="Approach-1-Using-Attu" class="common-anchor-header">方法 1：使用 Attu</h4><p>若您當前的 Milvus 部署中僅有少量集合且分段數量不多，可使用 Attu 將資料持久化至物件儲存服務。​</p>
<ol>
<li><p>選取所有資料庫中的每個集合，進入「<code translate="no">Segments</code> 」面板，點擊「<code translate="no">Flush</code> 」按鈕​</p>
<p><span class="img-wrapper">
  
   <img translate="no" src="https://milvus-docs.s3.us-west-2.amazonaws.com/assets/attu-select-collection.png" alt="Segment panel of a collection" class="doc-image" id="segment-panel-of-a-collection" /> 
   <span>集合的「分段」面板</span>
  
 </span></p></li>
<li><p>接著在彈出視窗中，再次點擊「<code translate="no">Flush</code> 」。​</p>
<p><span class="img-wrapper">
  
   <img translate="no" src="https://milvus-docs.s3.us-west-2.amazonaws.com/assets/data-flush-prompt.png" alt="Data flush prompt in Attu" class="doc-image" id="data-flush-prompt-in-attu" /> 
   <span>Attu 中的資料沖洗提示</span>
  
 </span></p></li>
<li><p>接著請等待，直到所有集合的「持久化區段狀態」均顯示為「<code translate="no">Flushed</code> 」。​</p>
