    </button></h1><p>本主題說明如何使用 Grafana 視覺化 Milvus 指標。</p>
<p><a href="/docs/zh-hant/monitor.md">如監控指南</a>所述，指標包含諸如特定 Milvus 元件佔用多少記憶體等有用資訊。監控指標有助於您更深入了解 Milvus 的效能及其運行狀態，從而能及時調整資源分配。</p>
<p>可視化是一種圖表，用以顯示資源使用量隨時間的變化，這能讓您更輕鬆地快速察看並察覺資源使用量的變化，特別是在發生事件時。</p>
<p>本教學將使用 Grafana（一個用於時間序列分析的開源平台），來視覺化部署於 Kubernetes（K8s）上的 Milvus 叢集各項效能指標。</p>

</ul>
