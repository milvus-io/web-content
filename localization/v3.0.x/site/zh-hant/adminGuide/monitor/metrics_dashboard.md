    </button></h1><p>Milvus 在執行期間會輸出一組詳細的時間序列指標清單。您可以使用<a href="https://prometheus.io/">Prometheus</a>和<a href="https://grafana.com/">Grafana</a>來將這些指標視覺化。本主題將介紹在 Grafana Milvus 儀表板中顯示的監控指標。</p>
