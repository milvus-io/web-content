    </button></h1><p>Milvus genera una lista de métricas detalladas de series temporales durante la ejecución. Puedes utilizar <a href="https://prometheus.io/">Prometheus</a> y <a href="https://grafana.com/">Grafana</a> para visualizar las métricas. En este tema se presentan las métricas de supervisión que se muestran en el panel de control de Milvus en Grafana.</p>
<p>La unidad de tiempo utilizada en este tema es el milisegundo. Además, el «percentil 99» al que se hace referencia en este tema indica que el 99 % de las estadísticas temporales se sitúan dentro de un valor determinado.</p>
<p>Recomendamos leer <a href="/docs/es/monitor_overview.md">la descripción general del marco de monitorización de Milvus</a> para comprender primero las métricas de Prometheus.</p>
