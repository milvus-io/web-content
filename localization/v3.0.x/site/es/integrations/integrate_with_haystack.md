    </button></h1><p>Esta guía muestra cómo crear un sistema de generación aumentada por recuperación (RAG) utilizando Haystack y Milvus.</p>
<p>El sistema RAG combina un sistema de recuperación con un modelo generativo para generar texto nuevo a partir de una indicación dada. El sistema recupera primero los documentos relevantes de un corpus utilizando Milvus y, a continuación, utiliza un modelo generativo para generar texto nuevo basado en los documentos recuperados.</p>
<p><a href="https://haystack.deepset.ai/">Haystack</a> es el marco de trabajo de código abierto en Python desarrollado por deepset para crear aplicaciones personalizadas con modelos de lenguaje a gran escala (LLM). <a href="https://milvus.io/">Milvus</a> es la base de datos vectorial de código abierto más avanzada del mundo, diseñada para potenciar la búsqueda de similitudes mediante incrustaciones y las aplicaciones de IA.</p>

<pre><code translate="no" class="language-python"><span class="hljs-keyword">from</span> haystack.components.builders <span class="hljs-keyword">import</span> ChatPromptBuilder

    ChatMessage.from_user(
        <span class="hljs-string">&quot;&quot;&quot;Answer the following query based on the provided context. If the context does
        not include an answer, reply with &#x27;I don&#x27;t know&#x27;.

        Query: {{query}}
        Documents:
        {% for doc in documents %}
            {{ doc.content }}
        {% endfor %}

        &quot;&quot;&quot;</span>

]

rag_pipeline = Pipeline()
rag_pipeline.add_component(<span class="hljs-string">&quot;text_embedder&quot;</span>, OpenAITextEmbedder())

    <span class="hljs-string">&quot;retriever&quot;</span>, MilvusEmbeddingRetriever(document_store=document_store, top_k=<span class="hljs-number">3</span>)
)
rag_pipeline.add_component(
    <span class="hljs-string">&quot;prompt_builder&quot;</span>, ChatPromptBuilder(template=prompt_template)
)
rag_pipeline.add_component(
    <span class="hljs-string">&quot;generator&quot;</span>,
    OpenAIChatGenerator(
        api_key=Secret.from_env_var(<span class="hljs-string">&quot;OPENAI_API_KEY&quot;</span>),
