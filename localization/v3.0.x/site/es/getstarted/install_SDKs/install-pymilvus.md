      </svg>
    </button></h2><ul>
<li>PyMilvus 3.0.2 requiere Python 3.9 o posterior para conectarse a un servidor Milvus remoto.</li>
<li>Los ejemplos locales de Milvus Lite 3.2.2 requieren Python 3.10 o posterior y una plataforma compatible. Consulta <a href="/docs/es/milvus_lite.md">«Ejecutar Milvus Lite localmente</a>».</li>
<li>Instala las dependencias a través de <code translate="no">pip</code>. PyMilvus 3.0.2 requiere <code translate="no">protobuf&gt;=5.27.2</code>; no fijes por separado <code translate="no">protobuf==3.20.0</code>. No necesitas <code translate="no">grpcio-tools</code> para utilizar el SDK.</li>
</ul>

    </button></h2><p>PyMilvus está disponible en <a href="https://pypi.org/project/pymilvus/">el Python Package Index</a>.</p>
<div class="alert note">
Se recomienda instalar una versión de PyMilvus que coincida con la versión del servidor Milvus que hayas instalado. Para obtener más información, consulta <a href="/docs/es/release_notes.md">las Notas de la versión</a>.
</div>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus==3.0.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Esto instala el cliente para un servidor Milvus remoto. No instala Milvus Lite ni ningún modelo integrado.</p>
<p>Para la base de datos local utilizada en <a href="/docs/es/quickstart.md">la guía de inicio rápido</a>, instala el complemento « <code translate="no">milvus-lite</code> » y el paquete Lite correspondiente:</p>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus[milvus-lite]==3.0.2&quot;</span> <span class="hljs-string">&quot;milvus-lite==3.2.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Para los ayudantes de incrustación, instala el complemento independiente « <code translate="no">model</code> »:</p>
<pre><code translate="no" class="language-bash">python3 -m pip install <span class="hljs-string">&quot;pymilvus[model]==3.0.2&quot;</span>
<button class="copy-code-btn"></button></code></pre>
<p>En Windows, pip omite el complemento « <code translate="no">milvus-lite</code> » de PyMilvus 3.0.2 debido a su marcador de plataforma. El comando anterior especifica explícitamente « <code translate="no">milvus-lite</code> », por lo que se instala en Windows siempre que existan los archivos «wheels» para <code translate="no">faiss-cpu</code> y <code translate="no">pyarrow</code> compatibles con su versión de Python.</p>
