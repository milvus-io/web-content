    </button></h1><p>Milvus admite operadores avanzados para consultar y filtrar campos JSON, lo que los hace perfectos para gestionar datos complejos y estructurados. Estos operadores permiten realizar consultas muy eficaces en documentos JSON, lo que te permite recuperar entidades en función de elementos, valores o condiciones específicos dentro de los campos JSON. En esta sección se explica cómo utilizar los operadores específicos de JSON en Milvus, con ejemplos prácticos que ilustran su funcionamiento.</p>
<div class="alert note">
<p>Los campos JSON no pueden gestionar estructuras complejas y anidadas, y tratan todas las estructuras anidadas como cadenas de texto simples. Por lo tanto, al trabajar con campos JSON, es recomendable evitar anidamientos excesivamente profundos y asegurarse de que las estructuras de datos sean lo más planas posible para obtener un rendimiento óptimo.</p>
</div>

    </button></h2><p>Milvus ofrece varios operadores JSON potentes que ayudan a filtrar y consultar datos JSON; estos operadores son:</p>
<ul>
<li><p><a href="#JSONCONTAINS"><code translate="no">JSON_CONTAINS(identifier, expr)</code></a>: Filtra las entidades en las que se encuentra la expresión JSON especificada dentro del campo.</p></li>
<li><p><a href="#JSONCONTAINSALL"><code translate="no">JSON_CONTAINS_ALL(identifier, expr)</code></a>: Garantiza que todos los elementos de la expresión JSON especificada estén presentes en el campo.</p></li>
<li><p><a href="#JSONCONTAINSANY"><code translate="no">JSON_CONTAINS_ANY(identifier, expr)</code></a>: Filtra las entidades en las que exista al menos un miembro de la expresión JSON dentro del campo.</p></li>
</ul>
<p>Veamos estos operadores con ejemplos para comprender cómo se pueden aplicar en situaciones reales.</p>
