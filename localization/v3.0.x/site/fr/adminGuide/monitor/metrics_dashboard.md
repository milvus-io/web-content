    </button></h1><p>Milvus génère une liste de métriques détaillées sous forme de séries chronologiques pendant son exécution. Vous pouvez utiliser <a href="https://prometheus.io/">Prometheus</a> et <a href="https://grafana.com/">Grafana</a> pour visualiser ces métriques. Cette rubrique présente les métriques de surveillance affichées dans le tableau de bord Grafana de Milvus.</p>
<p>L'unité de temps utilisée dans cette rubrique est la milliseconde. Le « 99e centile » mentionné ici signifie que 99 % des statistiques temporelles se situent en deçà d'une certaine valeur.</p>
<p>Nous vous recommandons de lire d’abord <a href="/docs/fr/monitor_overview.md">la présentation du cadre de surveillance Milvus</a> pour bien comprendre les métriques Prometheus.</p>
