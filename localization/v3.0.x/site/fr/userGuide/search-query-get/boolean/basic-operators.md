        ></path>
      </svg>
    </button></h2><p>Les opérateurs de correspondance de motifs permettent de filtrer des valeurs de type chaîne de caractères en fonction de motifs avec caractères génériques ou d’expressions régulières.</p>
<ul>
<li><p><code translate="no">LIKE</code>: Permet de faire correspondre des motifs simples avec des caractères génériques sur des valeurs de chaîne. Par exemple, « <code translate="no">name LIKE &quot;Prod%&quot;</code> » correspond aux valeurs commençant par « <code translate="no">Prod</code> ».</p></li>
<li><p><code translate="no">=~</code>: Permet de faire correspondre une valeur de chaîne à une expression régulière RE2. Par exemple, <code translate="no">code =~ &quot;E[0-9]{4}&quot;</code> correspond aux valeurs contenant un code d'erreur tel que <code translate="no">E1001</code>.</p></li>
<li><p><code translate="no">!~</code>: Permet d’exclure les valeurs de chaîne qui correspondent à une expression régulière RE2. Cela équivaut à « <code translate="no">NOT (field =~ &quot;pattern&quot;)</code> ».</p></li>
</ul>
<p>Pour rechercher les entités dont la valeur « <code translate="no">name</code> » commence par « <code translate="no">Prod</code> » :</p>
<pre><code translate="no" class="language-python"><span class="hljs-built_in">filter</span> = <span class="hljs-string">&#x27;name LIKE &quot;Prod%&quot;&#x27;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Pour rechercher les entités dont la valeur « <code translate="no">code</code> » contient un code d’erreur tel que « <code translate="no">E1001</code> » :</p>
<pre><code translate="no" class="language-python"><span class="hljs-built_in">filter</span> = <span class="hljs-string">&#x27;code =~ &quot;E[0-9]{4}&quot;&#x27;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Pour exclure les entités dont l’ <code translate="no">message</code> commence par <code translate="no">DEBUG</code>:</p>
<pre><code translate="no" class="language-python"><span class="hljs-built_in">filter</span> = <span class="hljs-string">&#x27;message !~ &quot;^DEBUG&quot;&#x27;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Pour plus de détails sur le choix entre « <code translate="no">LIKE</code> » et les expressions régulières, les types de champs pris en charge, la syntaxe des expressions régulières, les règles d’échappement et les performances, consultez la section <a href="/docs/fr/pattern-matching.md">« Correspondance de motifs</a> ». Milvus vous permet également de créer un index « <code translate="no">NGRAM</code> » sur des champs « <code translate="no">VARCHAR</code> » ou des chemins de chaînes JSON afin d’accélérer les filtres de correspondance de motifs éligibles. Pour plus de détails, consultez la section « <a href="/docs/fr/ngram.md">NGRAM</a> ».</p>
