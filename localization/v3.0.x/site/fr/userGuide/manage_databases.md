    </button></h2><p>Dans Milvus, une base de données sert d'unité logique pour organiser et gérer les données. Afin de renforcer la sécurité des données et de permettre la multi-location, vous pouvez créer plusieurs bases de données pour isoler logiquement les données de différentes applications ou de différents locataires. Par exemple, vous pouvez créer une base de données pour stocker les données de l'utilisateur A et une autre pour celles de l'utilisateur B.</p>
