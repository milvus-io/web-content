    </button></h1><p><a href="https://dify.ai/">Dify</a> est une plateforme open source conçue pour simplifier le développement d’applications d’IA en combinant un Backend-as-a-Service (BaaS) avec des LLMOps. Elle prend en charge les principaux modèles de langage (LLM), offre une interface intuitive d’orchestration des invites, des moteurs RAG de haute qualité et un framework d’agents IA flexible. Grâce à des workflows « low-code », des interfaces conviviales et des API, Dify permet tant aux développeurs qu’aux utilisateurs non techniciens de se concentrer sur la création de solutions d’IA innovantes et concrètes, sans avoir à gérer la complexité.</p>
<p>Dans ce tutoriel, nous allons vous montrer comment déployer Dify avec Milvus, afin de bénéficier d’une recherche efficace et d’un moteur RAG performant.</p>
<div class="alert note">
<p>Cette documentation s’appuie principalement sur la <a href="https://docs.dify.ai/">documentation</a> officielle <a href="https://docs.dify.ai/">de Dify</a>. Si vous constatez des informations obsolètes ou incohérentes, veuillez vous référer en priorité à la documentation officielle et n’hésitez pas à nous signaler le problème.</p>
</div>

<div class="alert note">
<ul>
<li>Le fichier ` <code translate="no">MILVUS_URI</code> ` utilise ` <code translate="no">host.docker.internal:19530</code> `, ce qui permet aux conteneurs Docker d’accéder à Milvus s’exécutant sur la machine hôte via le réseau interne de Docker.</li>
<li>La configuration Docker Compose de Dify active l’authentification Milvus par défaut. Définissez ` <code translate="no">MILVUS_TOKEN</code> ` sur ` <code translate="no">username:password</code>` ; ` <code translate="no">root:Milvus</code> ` utilise les identifiants initiaux. Si vous avez modifié les identifiants, remplacez cette valeur en conséquence.</li>
</ul>
</div>
