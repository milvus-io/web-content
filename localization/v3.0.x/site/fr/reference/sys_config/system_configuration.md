<p>Milvus gère un nombre considérable de paramètres permettant de configurer le système. Chaque paramètre dispose d'une valeur par défaut, qui peut être utilisée directement. Vous pouvez modifier ces paramètres de manière flexible afin que Milvus réponde au mieux aux besoins de votre application. Pour plus d'informations, consultez la section « <a href="/docs/fr/configure-docker.md">Configurer Milvus</a> ».</p>
<div class="alert note">
Dans la version actuelle, tous les paramètres ne prennent effet qu’après avoir été configurés au démarrage de Milvus.
</div>

<p>Si vous ne définissez pas le champ `mq.type` sur sa valeur par défaut, une remarque indique comment activer la priorité lorsque plusieurs queues de messages sont configurées dans ce fichier.</p>

<li><p>Mode cluster : Pulsar (par défaut) &gt; Kafka (rocksmq n'est pas pris en charge en mode cluster)</p></li>
<li><p>Woodpecker peut être utilisé aussi bien en mode autonome qu’en mode cluster en définissant « mq.type » sur « woodpecker ».</p></li>
