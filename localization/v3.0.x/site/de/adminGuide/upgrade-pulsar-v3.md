    </button></h1><p>Dieser Artikel beschreibt die Vorgehensweise für das Upgrade Ihrer Pulsar-Komponente von Version 2 auf Version 3, falls Sie bereits über eine funktionierende Milvus-Bereitstellung mit Pulsar V2 verfügen.​</p>
<p>Seit Milvus v2.5 verwenden <strong>„milvus-helm“</strong> und <strong>„milvus-operator“</strong> standardmäßig Pulsar V3, um einige Fehler und Sicherheitslücken zu beheben.​ Milvus 2.5 ist zwar mit Pulsar 2.x kompatibel, das Upgrade auf Pulsar V3 ist jedoch optional. Für mehr Stabilität und Leistung empfehlen wir ein Upgrade auf Pulsar V3.</p>
<p>Wenn Sie Pulsar V2 mit Milvus v2.5.x verwenden möchten, lesen Sie den Abschnitt <a href="/docs/de/use-pulsar-v2.md">„Pulsar V2 mit Milvus v2.5.x verwenden</a>“.</p>
<div class="alert note">
<ol>
<li><p>Der Upgrade-Vorgang erfordert eine kurze Dienstunterbrechung (dauert in der Regel einige Minuten bis zu mehr als zehn Minuten, je nach Datenmenge).​</p></li>
<li><p>Vor dem Vorgang müssen Sie alle laufenden Clients daran hindern, Daten in Milvus zu schreiben. Andernfalls können die geschriebenen Daten verloren gehen.​</p></li>
<li><p>Dieser Artikel geht davon aus, dass Milvus im Namespace „ <code translate="no">default</code> “ installiert ist und den Namen „ <code translate="no">my-release</code> “ trägt. Bitte passen Sie die Parameter an Ihren eigenen Namespace und Ihren Release-Namen an, während Sie die von dieser Seite kopierten Befehle ausführen.​</p></li>
<li><p>Stellen Sie sicher, dass Ihre Arbeitsumgebung über Berechtigungen im oben genannten Namespace im Kubernetes-Cluster verfügt und die folgenden Befehle installiert sind:​</p>
<p>a. <code translate="no">kubectl</code> &gt;= 1.20​</p>
<p>b. <code translate="no">helm</code> &gt;= 3.14.0​</p>
<p>c. <code translate="no">cat</code>, <code translate="no">grep</code>, <code translate="no">awk</code> für Operationen zur Zeichenfolgenbearbeitung​</p>
<p>d. <code translate="no">curl</code> oder <strong>Attu v2.4+</strong> für die Interaktion mit der Milvus-Management-API​</p></li>
</ol>
</div>
