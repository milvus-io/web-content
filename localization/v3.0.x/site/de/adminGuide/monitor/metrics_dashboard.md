    </button></h1><p>Milvus gibt während der Laufzeit eine Liste detaillierter Zeitreihen-Metriken aus. Sie können <a href="https://prometheus.io/">Prometheus</a> und <a href="https://grafana.com/">Grafana</a> verwenden, um die Metriken zu visualisieren. In diesem Abschnitt werden die Überwachungsmetriken vorgestellt, die im Grafana-Milvus-Dashboard angezeigt werden.</p>
<p>Die Zeiteinheit in diesem Abschnitt ist Millisekunden. Der Begriff „99. Perzentil“ bezieht sich in diesem Zusammenhang darauf, dass 99 Prozent der Zeitstatistiken innerhalb eines bestimmten Wertes liegen.</p>
<p>Wir empfehlen, zunächst <a href="/docs/de/monitor_overview.md">die Übersicht über das Milvus-Überwachungsframework</a> zu lesen, um die Prometheus-Metriken zu verstehen.</p>
