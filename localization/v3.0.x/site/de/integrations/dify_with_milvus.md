    </button></h1><p><a href="https://dify.ai/">Dify</a> ist eine Open-Source-Plattform, die durch die Kombination von Backend-as-a-Service mit LLMOps die Entwicklung von KI-Anwendungen vereinfacht. Sie unterstützt gängige LLMs, bietet eine intuitive Schnittstelle zur Prompt-Orchestrierung, hochwertige RAG-Engines und ein flexibles KI-Agenten-Framework. Dank Low-Code-Workflows, benutzerfreundlicher Oberflächen und APIs ermöglicht Dify sowohl Entwicklern als auch nicht-technischen Anwendern, sich auf die Erstellung innovativer, praxisorientierter KI-Lösungen zu konzentrieren, ohne sich mit Komplexität auseinandersetzen zu müssen.</p>
<p>In diesem Tutorial zeigen wir Ihnen, wie Sie Dify mit Milvus bereitstellen, um eine effiziente Datenabfrage und den Einsatz der RAG-Engine zu ermöglichen.</p>
<div class="alert note">
<p>Diese Dokumentation basiert in erster Linie auf der offiziellen <a href="https://docs.dify.ai/">Dify-Dokumentation</a>. Sollten Sie veraltete oder inkonsistente Inhalte finden, orientieren Sie sich bitte vorrangig an der offiziellen Dokumentation und melden Sie uns gegebenenfalls ein Problem.</p>
</div>

<div class="alert note">
<ul>
<li>Die Datei „ <code translate="no">MILVUS_URI</code> “ verwendet „ <code translate="no">host.docker.internal:19530</code> “, wodurch Docker-Container über das interne Netzwerk von Docker auf Milvus zugreifen können, das auf dem Host-Rechner läuft.</li>
<li>Die Docker-Compose-Konfiguration von Dify aktiviert standardmäßig die Milvus-Authentifizierung. Setzen Sie ` <code translate="no">MILVUS_TOKEN</code> ` auf ` <code translate="no">username:password</code>`; ` <code translate="no">root:Milvus</code> ` verwendet die ursprünglichen Anmeldedaten. Falls Sie die Anmeldedaten geändert haben, ersetzen Sie diesen Wert entsprechend.</li>
</ul>
