<p>Milvus verfügt über eine beträchtliche Anzahl von Parametern zur Systemkonfiguration. Jede Konfiguration hat einen Standardwert, der direkt verwendet werden kann. Sie können diese Parameter flexibel anpassen, damit Milvus Ihre Anwendung optimal unterstützt. <div class="alert note">
In der aktuellen Version werden alle Parameter erst wirksam, nachdem sie beim Start von Milvus konfiguriert wurden.
</div>

    </button></h3><p>Milvus unterstützt vier MQ: rocksmq (basierend auf RockDB), Pulsar, Kafka und Woodpecker.</p>
<p>Sie können den MQ ändern, indem Sie das Feld „mq.type“ festlegen.</p>
<p>Wenn Sie das Feld „mq.type“ nicht auf den Standardwert setzen, gibt es einen Hinweis zur Aktivierung der Priorität, falls in dieser Datei mehrere MQ-Dienste konfiguriert werden.</p>
<ol>
<li><p>Standalone-Modus (lokal): rocksmq (Standard) &gt; Pulsar &gt; Kafka</p></li>
<li><p>Cluster-Modus: Pulsar (Standard) &gt; Kafka (rocksmq wird im Cluster-Modus nicht unterstützt)</p></li>
<li><p>Woodpecker kann sowohl im Standalone- als auch im Cluster-Modus verwendet werden, indem „mq.type“ auf „woodpecker“ gesetzt wird.</p></li>
</ol>
