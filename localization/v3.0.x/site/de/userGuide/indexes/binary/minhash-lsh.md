</ul>

    </button></h3><p><a href="https://en.wikipedia.org/wiki/MinHash">MinHash</a> ist eine probabilistische Technik, die eine effiziente Methode zur Schätzung der Jaccard-Ähnlichkeit bietet. Dabei wird jede Menge in einen kompakten <strong>Signaturvektor</strong> umgewandelt, wobei genügend Informationen erhalten bleiben, um die Ähnlichkeit der Mengen effizient zu approximieren.</p>
<p><strong>Die Kernidee</strong>:</p>
<p>Je ähnlicher sich zwei Mengen sind, desto wahrscheinlicher ist es, dass ihre MinHash-Signaturen an denselben Positionen übereinstimmen. Diese Eigenschaft ermöglicht es MinHash, die Jaccard-Ähnlichkeit zwischen Mengen zu approximieren.</p>
<p>Dank dieser Eigenschaft kann MinHash <strong>die Jaccard-Ähnlichkeit</strong> zwischen Mengen <strong>annähern</strong>, ohne die vollständigen Mengen direkt vergleichen zu müssen.</p>
<p>Der MinHash-Prozess umfasst:</p>
<ol>
<li><p><strong>Shingling</strong>: Umwandlung von Dokumenten in Sätze überlappender Token-Sequenzen (Shingles)</p></li>
<li><p><strong>Hashing</strong>: Auf jedes Shingle werden mehrere unabhängige Hash-Funktionen angewendet</p></li>
<li><p><strong>Min-Auswahl</strong>: Für jede Hash-Funktion wird der <strong>minimale</strong> Hash-Wert über alle Shingles hinweg erfasst</p></li>
</ol>

    </button></h3><p>Zwar reduzieren MinHash-Signaturen den Rechenaufwand für die Berechnung der exakten Jaccard-Ähnlichkeit zwischen Dokumenten erheblich, doch ist der umfassende Vergleich jedes Paares von Signaturvektoren bei großem Umfang nach wie vor ineffizient.</p>
<p>Um dieses Problem zu lösen, wird <a href="https://zilliz.com/learn/Local-Sensitivity-Hashing-A-Comprehensive-Guide">LSH</a> eingesetzt. LSH ermöglicht eine schnelle, approximative Ähnlichkeitssuche, indem sichergestellt wird, dass ähnliche Elemente mit hoher Wahrscheinlichkeit in denselben „Bucket“ gehasht werden – wodurch die Notwendigkeit entfällt, jedes Paar direkt zu vergleichen.</p>
<p>Der Prozess umfasst:</p>
<ol>
<li><p><strong>Signatursegmentierung:</strong></p>
<p>Eine <em>n-dimensionale</em> MinHash-Signatur wird in <em>b</em> Bänder unterteilt. Jedes Band enthält <em>r</em> aufeinanderfolgende Hash-Werte, sodass die Gesamtlänge der Signatur der folgenden Gleichung entspricht: <em>n = b × r</em>.</p>
<p>Wenn Sie beispielsweise eine 128-dimensionale MinHash-Signatur (<em>n = 128</em>) haben und diese in 32 Bänder (<em>b = 32</em>) unterteilen, enthält jedes Band 4 Hash-Werte (<em>r = 4</em>).</p></li>
<li><p><strong>Hashing auf Bandebene:</strong></p>
<p>Nach der Segmentierung wird jedes Band unabhängig mithilfe einer Standard-Hash-Funktion verarbeitet, um es einem Bucket zuzuordnen. Wenn zwei Signaturen innerhalb eines Bandes denselben Hash-Wert erzeugen – d. h., sie fallen in denselben Bucket –, gelten sie als potenzielle Übereinstimmungen.</p></li>
<li><p><strong>Auswahl der Kandidaten:</strong></p>
<p>Paare, die in mindestens einem Band kollidieren, werden als Ähnlichkeitskandidaten ausgewählt.</p></li>
</ol>

Da diese Signaturen jedoch die ursprünglichen Mengen nicht beibehalten, können Standardmetriken wie „ <code translate="no">JACCARD</code> “, „ <code translate="no">L2</code> “ oder „ <code translate="no">COSINE</code> “ nicht direkt angewendet werden, um sie zu vergleichen.</p>
<p>Um diesem Problem zu begegnen, führt Milvus einen speziellen Metriktyp namens „ <code translate="no">MHJACCARD</code> “ ein, der speziell für den Vergleich von MinHash-Signaturen entwickelt wurde.</p>
<p>Bei der Verwendung von MinHash in Milvus gilt:</p>
<ul>
<li><p>muss das Vektorfeld vom Typ <code translate="no">BINARY_VECTOR</code></p></li>
<li><p>Die „ <code translate="no">index_type</code> “ muss „ <code translate="no">MINHASH_LSH</code> “ (oder „ <code translate="no">BIN_FLAT</code> “) lauten</p></li>
<li><p>Die „ <code translate="no">metric_type</code> “ muss auf <code translate="no">MHJACCARD</code></p></li>
</ul>
<p>Die Verwendung anderer Metriken ist entweder ungültig oder führt zu falschen Ergebnissen.</p>
<p>Weitere Informationen zu diesem Metriktyp finden Sie unter <a href="/docs/de/metric.md#MHJACCARD">MHJACCARD</a>.</p>
