      </svg>
    </button></h2><p>Musterabgleichsoperatoren helfen dabei, Zeichenfolgenwerte anhand von Platzhaltermustern oder regulären Ausdrücken zu filtern.</p>
<ul>
<li><p><code translate="no">LIKE</code>: Wird verwendet, um einfache Platzhaltermuster mit Zeichenfolgenwerten abzugleichen. Beispielsweise findet „ <code translate="no">name LIKE &quot;Prod%&quot;</code> “ Werte, die mit „ <code translate="no">Prod</code> “ beginnen.</p></li>
<li><p><code translate="no">=~</code>: Wird verwendet, um einen Zeichenfolgenwert mit einem RE2-regulären Ausdruck abzugleichen. Beispielsweise passt „ <code translate="no">code =~ &quot;E[0-9]{4}&quot;</code> “ auf Werte, die einen Fehlercode wie „ <code translate="no">E1001</code> “ enthalten.</p></li>
<li><p><code translate="no">!~</code>: Wird verwendet, um Zeichenfolgenwerte auszuschließen, die einem RE2-regulären Ausdruck entsprechen. Dies entspricht „ <code translate="no">NOT (field =~ &quot;pattern&quot;)</code> “.</p></li>
</ul>
<p>So finden Sie Entitäten, bei denen „ <code translate="no">name</code> “ mit „ <code translate="no">Prod</code> “ beginnt:</p>
<pre><code translate="no" class="language-python"><span class="hljs-built_in">filter</span> = <span class="hljs-string">&#x27;name LIKE &quot;Prod%&quot;&#x27;</span>
<button class="copy-code-btn"></button></code></pre>
<p>So finden Sie Entitäten, deren „ <code translate="no">code</code> “ einen Fehlercode wie „ <code translate="no">E1001</code> “ enthält:</p>
<pre><code translate="no" class="language-python"><span class="hljs-built_in">filter</span> = <span class="hljs-string">&#x27;code =~ &quot;E[0-9]{4}&quot;&#x27;</span>
<button class="copy-code-btn"></button></code></pre>
<p>So schließen Sie Entitäten aus, deren „ <code translate="no">message</code> “ mit „ <code translate="no">DEBUG</code> “ beginnt:</p>
<pre><code translate="no" class="language-python"><span class="hljs-built_in">filter</span> = <span class="hljs-string">&#x27;message !~ &quot;^DEBUG&quot;&#x27;</span>
<button class="copy-code-btn"></button></code></pre>
<p>Weitere Informationen zur Wahl zwischen „ <code translate="no">LIKE</code> “ und regulären Ausdrücken, zu unterstützten Feldtypen, zur Syntax regulärer Ausdrücke, zu Escaping-Regeln und zur Leistung finden Sie unter <a href="/docs/de/pattern-matching.md">„Musterabgleich</a>“. Milvus ermöglicht es Ihnen außerdem, einen „ <code translate="no">NGRAM</code> “-Index für „ <code translate="no">VARCHAR</code> “-Felder oder JSON-String-Pfade zu erstellen, um geeignete Filter für den Musterabgleich zu beschleunigen. Weitere Informationen finden Sie unter <a href="/docs/de/ngram.md">„NGRAM</a>“.</p>

<p>Zilliz Cloud legt keine Längenbeschränkung für die Liste der Übereinstimmungswerte in Filterbedingungen fest. Eine übermäßig lange Liste kann jedoch die Abfrageleistung erheblich beeinträchtigen.
Wenn Ihre Filterbedingung eine lange Liste von Übereinstimmungswerten oder einen komplexen Ausdruck mit vielen Elementen enthält, empfehlen wir die Verwendung <a href="/docs/de/filtering-templating.md">von Filtervorlagen</a>, um die Abfrageleistung zu verbessern.</p>
