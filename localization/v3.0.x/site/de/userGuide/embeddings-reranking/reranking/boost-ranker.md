    </button></h1><p>Anstatt sich ausschließlich auf die anhand von Vektorabständen berechnete semantische Ähnlichkeit zu verlassen, ermöglichen Ihnen Boost Ranker, Suchergebnisse auf sinnvolle Weise zu beeinflussen. Sie eignen sich ideal für die schnelle Anpassung von Suchergebnissen mithilfe von Metadatenfiltern.</p>
<p>Wenn eine Suchanfrage eine Boost-Ranker-Funktion enthält, nutzt Milvus die optionale Filterbedingung innerhalb der Funktion, um Übereinstimmungen unter den Suchergebniskandidaten zu finden, und erhöht die Bewertungen dieser Übereinstimmungen durch Anwendung der angegebenen Gewichtung. Auf diese Weise können Sie die Platzierung der übereinstimmenden Entitäten im Endergebnis verbessern oder verschlechtern.</p>

<p>Wenn Sie Daten einfügen, verteilt Milvus diese auf verschiedene Segmente. Bei einer Suche liefert jedes Segment eine Reihe von Kandidaten, und Milvus ordnet diese Kandidaten aus allen Segmenten in eine Rangfolge ein, um die Endergebnisse zu ermitteln. Wenn eine Suchanfrage einen „Boost Ranker“ enthält, wendet Milvus diesen auf die Kandidaten aus jedem Segment an, um einen möglichen Präzisionsverlust zu verhindern und den Recall zu verbessern.</p>
<p>Vor der endgültigen Festlegung der Ergebnisse verarbeitet Milvus diese Kandidaten mit dem „Boost Ranker“ wie folgt:</p>
<ol>
<li><p>Wendet den im Boost-Ranker angegebenen optionalen Filterausdruck an, um die Entitäten zu identifizieren, die dem Ausdruck entsprechen.</p></li>
<li><p>Wendet die im „Boost Ranker“ festgelegte Gewichtung an, um die Bewertungen der identifizierten Entitäten zu erhöhen.</p></li>
</ol>
<div class="alert note">
<p>Sie können den „Boost Ranker“ nicht als Ranker in einer Multi-Vektor-Hybridsuche verwenden. Sie können ihn jedoch als Ranker in jeder ihrer Unteranfragen verwenden (<code translate="no">AnnSearchRequest</code>).</p>
</div>

<p>Konkret gibt es zwei „Boost Ranker“: Der eine wendet eine feste Gewichtung auf alle gefundenen Entitäten an, während der andere ihnen eine zufällige Gewichtung zuweist. Anschließend verweisen wir in einem <strong>„FunctionScore“</strong> auf diese beiden Ranker, wobei dort auch definiert wird, wie die Gewichtungen die Bewertungen der gefundenen Entitäten beeinflussen.</p>
