    </button></h1><p>Der Filter „ <code translate="no">decompounder</code> “ zerlegt zusammengesetzte Wörter anhand eines angegebenen Wörterbuchs in einzelne Bestandteile, wodurch die Suche nach Teilen von zusammengesetzten Begriffen erleichtert wird. Dieser Filter ist besonders nützlich für Sprachen, in denen häufig zusammengesetzte Wörter verwendet werden, wie beispielsweise Deutsch.</p>
<p>Das Komponentenwörterbuch kann inline über den Parameter „ <code translate="no">word_list</code> “ übergeben oder über den Parameter „ <code translate="no">word_list_file</code> “ aus einer <a href="/docs/de/manage-file-resources.md">registrierten Dateiressource</a> geladen werden.</p>

<p>Der Filter „ <code translate="no">decompounder</code> “ verarbeitet die vom Tokenizer generierten Begriffe und muss daher in Kombination mit einem Tokenizer verwendet werden. Eine Liste der in Milvus verfügbaren Tokenizer finden Sie unter <a href="/docs/de/standard-tokenizer.md">„Standard-Tokenizer“</a> und den zugehörigen Seiten.</p>
<p>Nachdem Sie „ <code translate="no">analyzer_params</code> “ definiert haben, können Sie diese bei der Definition eines Sammlungsschemas auf ein „ <code translate="no">VARCHAR</code> “-Feld anwenden. Dadurch kann Milvus den Text in diesem Feld mit dem angegebenen Analysator verarbeiten, um eine effiziente Tokenisierung und Filterung zu gewährleisten. Weitere Informationen finden Sie unter <a href="/docs/de/analyzer-overview.md#Example-use">„Anwendungsbeispiel</a>“.</p>

    </button></h3><p>Bei umfangreichen Komponentenwörterbüchern – insbesondere bei Wortlisten für ganze Sprachen – speichern Sie die Komponenten in einer Datei und registrieren Sie die Datei als Remote-Dateiressource; verweisen Sie dann im Filter über den Parameter „ <code translate="no">word_list_file</code> “ darauf. Sie können „ <code translate="no">word_list_file</code> “ allein oder zusammen mit dem Inline-Parameter „ <code translate="no">word_list</code> “ verwenden; wenn beide gesetzt sind, führt der Filter die beiden Quellen zu einer einzigen Komponentenliste zusammen.</p>
<p>Die Datei besteht aus einfachem UTF-8-Text mit <strong>einem Komponentenwort pro Zeile</strong>. Beispiel:</p>
<pre><code translate="no" class="language-plaintext">dampf
schiff
fahrt
brot
backen
automat
<button class="copy-code-btn"></button></code></pre>
