    </button></h1><p>このトピックでは、Grafana を使用して Milvus のメトリクスを可視化する方法について説明します。</p>
<p><a href="/docs/ja/monitor.md">モニタリングガイドで</a>説明されているように、メトリクスには特定のMilvusコンポーネントが使用するメモリ量など、有用な情報が含まれています。メトリクスをモニタリングすることで、Milvusのパフォーマンスや稼働状況をより深く理解し、リソースの割り当てを適時に調整できるようになります。</p>
<p>可視化とは、時間の経過に伴うリソース使用量の変化を示すグラフのことで、特に何らかのイベントが発生した際に、リソース使用量の変化を素早く把握し、気づきやすくなります。</p>
<p>このチュートリアルでは、時系列分析のためのオープンソースプラットフォームであるGrafanaを使用して、Kubernetes（K8s）上にデプロイされたMilvusクラスタのさまざまなパフォーマンスメトリクスを可視化します。</p>

</ul>
