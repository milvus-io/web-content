    </button></h3><p>Milvus は、rocksmq（RockDB ベース）、Pulsar、Kafka、Woodpecker の 4 種類の MQ をサポートしています。</p>
<p>mq.type フィールドを設定することで、MQ を変更できます。</p>
<p>mq.type フィールドをデフォルト値に設定しない場合、このファイルで複数の MQ を設定する際に優先順位を有効にする方法についての注記があります。</p>
<ol>
<li><p>スタンドアロン（ローカル）モード：rocksmq（デフォルト） &gt; Pulsar &gt; Kafka</p></li>
<li><p>クラスタモード：Pulsar（デフォルト） &gt; Kafka（クラスタモードでは rocksmq はサポートされていません）</p></li>
<li><p>Woodpecker は、mq.type を woodpecker に設定することで、スタンドアロンモードとクラスタモードの両方で使用できます。</p></li>
</ol>
<p>このセクションの各パラメータに関する詳細な説明については、「<a href="/docs/ja/configure_mq.md">mq 関連の設定</a>」を参照してください。</p>
