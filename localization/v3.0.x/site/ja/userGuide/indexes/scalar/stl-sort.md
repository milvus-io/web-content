    </button></h1><p><code translate="no">STL_SORT</code> インデックスは、Milvus内の数値フィールド（INT8、INT16など）、<code translate="no">VARCHAR</code> フィールド、または<code translate="no">TIMESTAMPTZ</code> フィールドについて、データをソート順に整理することでクエリのパフォーマンスを向上させるために特別に設計されたインデックスタイプです。</p>
<p>次のようなクエリを頻繁に実行する場合は、<code translate="no">STL_SORT</code> インデックスを使用してください：</p>
<ul>
<li><p><code translate="no">==</code> 、<code translate="no">!=</code> 、<code translate="no">&gt;</code> 、<code translate="no">&lt;</code> 、<code translate="no">&gt;=</code> 、および<code translate="no">&lt;=</code> 演算子を用いた比較フィルタリング</p></li>
<li><p><code translate="no">IN</code> および<code translate="no">LIKE</code> 演算子による範囲フィルタリング</p></li>
</ul>

      </svg>
    </button></h2><p>Milvusは、<code translate="no">STL_SORT</code> を2つのフェーズで実装しています：</p>
<ol>
<li><p><strong>インデックスの構築</strong></p>
<ul>
<li><p>データ取り込み中に、Milvusはインデックス対象フィールドのすべての値を収集します。</p></li>
<li><p>これらの値は、C++ STLの<a href="https://en.cppreference.com/w/cpp/algorithm/sort.html">std::sort</a>を使用して昇順でソートされます。</p></li>
<li><p>各値は対応するエンティティIDと紐付けられ、ソートされた配列がインデックスとして永続化されます。</p></li>
</ul></li>
<li><p><strong>クエリの高速化</strong></p>
<ul>
<li><p>クエリ実行時、Milvusはソート済みの配列に対して<strong>二分探索</strong>（<a href="https://en.cppreference.com/w/cpp/algorithm/lower_bound.html">std::lower_bound</a>および<a href="https://en.cppreference.com/w/cpp/algorithm/upper_bound.html">std::upper_bound</a>）を行います。</p></li>
<li><p>等価検索の場合、Milvus は一致するすべての値を迅速に見つけ出します。</p></li>
<li><p>範囲検索の場合、Milvus は開始位置と終了位置を特定し、その間のすべての値を返します。</p></li>
<li><p>一致するエンティティ ID は、最終的な結果の組み立てのためにクエリ実行部に渡されます。</p></li>
</ul></li>
</ol>
<p>これにより、クエリの計算量は<strong>O(n)</strong>(フルスキャン) から<strong>O(log n + m)</strong> に削減されます。ここで、<em>m は</em>一致した件数です。</p>
