    </button></h1><p>SiliconFlow Rankerは、<a href="https://www.siliconflow.com/">SiliconFlowの</a>包括的な再ランク付けモデルを活用し、セマンティック再ランク付けを通じて検索の関連性を高めます。柔軟なドキュメントのチャンキング機能を備え、さまざまなプロバイダーが提供する幅広い専門的な再ランク付けモデルに対応しています。</p>
<p>SiliconFlow Rankerは、特に次のような要件を持つアプリケーションにおいて有用です：</p>
<ul>
<li><p>長い文書を処理するための、オーバーラップを構成可能な高度な文書チャンキング</p></li>
<li><p>BAAI/bge-rerankerシリーズをはじめとする多様な再ランク付けモデルや、その他の専門モデルへのアクセス</p></li>
<li><p>最高スコアのチャンクがドキュメントのスコアとなる、柔軟なチャンクベースのスコアリング</p></li>
<li><p>標準モデルとプロモデルの両方をサポートした、コスト効率に優れた再ランク付け</p></li>
</ul>
