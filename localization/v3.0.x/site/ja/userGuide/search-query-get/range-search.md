      </svg>
    </button></h2><p>範囲検索リクエストを実行する際、MilvusはANN検索の結果からクエリベクトルに最も類似したベクトルを中心とし、検索リクエストで指定された<strong>半径</strong>を外側の円の半径、<strong>range_filterを</strong>内側の円の半径として、2つの同心円を描画します。 これら2つの同心円によって形成される環状領域内に類似度スコアが収まるすべてのベクトルが返されます。ここで、`<strong>range_filter</strong>`<strong>を0に</strong>設定すると、指定された類似度スコア（半径）内のすべてのエンティティが返されることを意味します。</p>
<p><span class="img-wrapper">
  
   <img translate="no" src="https://milvus-docs.s3.us-west-2.amazonaws.com/assets/range-search.png" alt="Range Search" class="doc-image" id="range-search" /> 
   <span>範囲検索</span>
  
 </span></p>
<p>上の図に示すように、範囲検索リクエストには「<strong>radius</strong>」と「<strong>range_filter</strong>」の2つのパラメータが含まれます。Milvusは範囲検索リクエストを受信すると、以下の処理を行います：</p>
<ul>
<li><p>指定されたメトリックタイプ（<strong>COSINE</strong>）を使用して、クエリベクトルに最も類似したすべてのベクトル埋め込みを検索します。</p></li>
<li><p>クエリベクトルまでの<strong>距離</strong>または<strong>スコア</strong>が、<strong>radius</strong>および<strong>range_filter</strong>パラメータで指定された範囲内にあるベクトル埋め込みをフィルタリングします。</p></li>
<li><p>フィルタリングされたエンティティの中から<strong>上位K</strong>件を返します。</p></li>
</ul>
<p><strong>radius</strong>および<strong>range_filter</strong>の設定方法は、検索のメトリックタイプによって異なります。以下の表に、各メトリックタイプにおけるこれら2つのパラメータの設定要件を示します。</p>
<table>
   <tr>
     <th><p>メトリックタイプ</p></th>
     <th><p>記号</p></th>
     <th><p>radius および range_filter の設定要件</p></th>
   </tr>
   <tr>
     <td><p><code translate="no">L2</code></p></td>
     <td><p>L2 距離が小さいほど、類似度が高いことを示します。</p></td>
     <td><p>最も類似性の高いベクトル埋め込みを無視するには、以下の条件を満たすようにしてください。</p><p><code translate="no">range_filter</code> &lt;= 距離 &lt;<code translate="no">radius</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">IP</code></p></td>
     <td><p>IP距離が大きいほど、類似度が高いことを示します。</p></td>
     <td><p>最も類似性の高いベクトル埋め込みを無視するには、次の条件を満たすようにしてください。&lt;= distance &lt;</p><p><code translate="no">radius</code> &lt; 距離 &lt;=<code translate="no">range_filter</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">COSINE</code></p></td>
     <td><p>COSINE距離が大きいほど、類似度が高いことを示します。</p></td>
     <td><p>最も類似性の高いベクトル埋め込みを無視するには、次の条件を満たすようにしてください。&lt; 距離 &lt;=</p><p><code translate="no">radius</code> &lt; 距離 &lt;=<code translate="no">range_filter</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">JACCARD</code></p></td>
     <td><p>ジャッカード距離が小さいほど、類似度が高いことを示します。</p></td>
     <td><p>最も類似性の高いベクトル埋め込みを無視するには、次の条件を満たすようにしてください。&lt; 距離 &lt;=</p><p><code translate="no">range_filter</code> &lt;= 距離 &lt;<code translate="no">radius</code></p></td>
   </tr>
   <tr>
     <td><p><code translate="no">HAMMING</code></p></td>
     <td><p>ハミング距離が小さいほど、類似度が高いことを示します。</p></td>
     <td><p>最も類似性の高いベクトル埋め込みを無視するには、次の条件を満たすようにしてください。&lt;= 距離 &lt;ハミング距離が小さいほど、類似度が高いことを示します。</p><p><code translate="no">range_filter</code> &lt;= 距離 &lt;<code translate="no">radius</code></p></td>
   </tr>
</table>
