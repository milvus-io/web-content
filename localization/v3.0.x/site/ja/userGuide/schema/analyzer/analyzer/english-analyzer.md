        ></path>
      </svg>
    </button></h2><p><code translate="no">english</code> アナライザーは、以下のコンポーネントを使用します：</p>
<ul>
<li><p><strong>トークナイザー</strong>：<a href="/docs/ja/standard-tokenizer.md"><code translate="no">standard</code> トークナイザー</a>を使用して、テキストを個別の単語単位に分割します。</p></li>
<li><p><strong>フィルタ</strong>：包括的なテキスト処理を行うための複数のフィルタが含まれています：</p>
<ul>
<li><p><a href="/docs/ja/lowercase-filter.md"><code translate="no">lowercase</code></a>: すべてのトークンを小文字に変換し、大文字小文字を区別しない検索を可能にします。</p></li>
<li><p><a href="/docs/ja/stemmer-filter.md"><code translate="no">stemmer</code></a>: より広範な一致を可能にするため、単語を語幹形に還元します（例：「running」が「run」になります）。</p></li>
<li><p><a href="/docs/ja/stop-filter.md"><code translate="no">stop_words</code></a>: テキスト内の重要な用語に焦点を当てるため、一般的な英語のストップワードを除去します。</p></li>
</ul></li>
</ul>
