        ></path>
      </svg>
    </button></h2><p><code translate="no">whitespace</code> トークナイザーは、以下の5つのASCII空白文字でのみテキストを分割します：</p>
<table>
<thead>
<tr><th>文字</th><th>名前</th><th>Unicodeコードポイント</th></tr>
</thead>
<tbody>
<tr><td><code translate="no">\t</code></td><td>水平タブ</td><td>U+0009</td></tr>
<tr><td><code translate="no">\n</code></td><td>改行</td><td>U+000A</td></tr>
<tr><td><code translate="no">\x0C</code> または<code translate="no">\f</code></td><td>フォームフィード</td><td>U+000C</td></tr>
<tr><td><code translate="no">\r</code></td><td>キャリッジリターン</td><td>U+000D</td></tr>
<tr><td><code translate="no">' '</code></td><td>スペース</td><td>U+0020</td></tr>
</tbody>
</table>
<p>これらの区切り文字は破棄され、連続する区切り文字があっても空のトークンは生成されません。句読点やその他の文字はトークン内に残ります。特に、垂直タブ (<code translate="no">\x0B</code>, U+000B)、非改行スペース (<code translate="no">\u00A0</code>)、および表意文字用スペース (<code translate="no">\u3000</code>) は、分割を引き起こしません。</p>
<p>このセットは、Rustの <a href="https://doc.rust-lang.org/std/primitive.char.html#method.is_ascii_whitespace"><code translate="no">char::is_ascii_whitespace()</code></a>に準拠しており、他のUnicode空白文字は除外されます。</p>
<p>以下の例では、フィルターを適用せずに `<code translate="no">{&quot;tokenizer&quot;: &quot;whitespace&quot;}</code> ` を使用しています。入力および出力には Python の文字列表記を使用しています。つまり、`<code translate="no">\t</code> ` や `<code translate="no">\u00A0</code> ` などのエスケープシーケンスは、実際の文字を表しています。</p>
<table>
<thead>
<tr><th>入力</th><th>出力トークン</th></tr>
</thead>
<tbody>
<tr><td><code translate="no">&quot;a\tb\nc\x0Cd\re f&quot;</code></td><td><code translate="no">[&quot;a&quot;, &quot;b&quot;, &quot;c&quot;, &quot;d&quot;, &quot;e&quot;, &quot;f&quot;]</code></td></tr>
<tr><td><code translate="no">&quot;Hello,World! foo_bar&quot;</code></td><td><code translate="no">[&quot;Hello,World!&quot;, &quot;foo_bar&quot;]</code></td></tr>
<tr><td><code translate="no">&quot;a\x0Bb&quot;</code></td><td><code translate="no">[&quot;a\x0Bb&quot;]</code></td></tr>
<tr><td><code translate="no">&quot;a\u00A0b&quot;</code></td><td><code translate="no">[&quot;a\u00A0b&quot;]</code></td></tr>
<tr><td><code translate="no">&quot;a\u3000b&quot;</code></td><td><code translate="no">[&quot;a\u3000b&quot;]</code></td></tr>
<tr><td><code translate="no">&quot; a b &quot;</code></td><td><code translate="no">[&quot;a&quot;, &quot;b&quot;]</code></td></tr>
</tbody>
</table>
