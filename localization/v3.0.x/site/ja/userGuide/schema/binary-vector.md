  バイナリベクトルは、従来の高次元浮動小数点ベクトルを、0と1のみを含むバイナリベクトルに変換する、データ表現の特殊な形式です。この変換により、ベクトルのサイズが圧縮されるだけでなく、意味情報を保持したまま、ストレージコストと計算コストを削減することができます。
  重要度の低い特徴量において精度が必須でない場合、バイナリベクトルは元の浮動小数点ベクトルの完全性と有用性の大部分を効果的に維持することができます。

    </button></h1><p>バイナリベクトルとは、従来の高次元浮動小数点ベクトルを、0と1のみを含むバイナリベクトルに変換する、データ表現の特殊な形式です。この変換により、ベクトルのサイズが圧縮されるだけでなく、意味情報を保持したまま、ストレージコストと計算コストを削減することができます。 重要度の低い特徴量において精度が必須でない場合、バイナリベクトルは元の浮動小数点ベクトルの整合性と有用性の大部分を効果的に維持することができます。</p>
<p>バイナリベクトルは、特に計算効率とストレージの最適化が重要な状況において、幅広い用途があります。検索エンジンやレコメンデーションシステムなどの大規模AIシステムでは、膨大な量のデータをリアルタイムで処理することが鍵となります。ベクトルのサイズを縮小することで、バイナリベクトルは精度を大幅に犠牲にすることなく、レイテンシと計算コストの低減に貢献します。 さらに、バイナリベクトルは、メモリや処理能力が限られているモバイルデバイスや組み込みシステムなど、リソースに制約のある環境でも有用です。バイナリベクトルを活用することで、こうした制約のある環境においても、高いパフォーマンスを維持しながら複雑なAI機能を実装することが可能になります。</p>

    </button></h2><p>バイナリベクトルとは、画像、テキスト、音声などの複雑なオブジェクトを、固定長のバイナリ値にエンコードする手法です。Milvusでは、バイナリベクトルは通常、ビット配列またはバイト配列として表現されます。例えば、8次元のバイナリベクトルは、<code translate="no">[1, 0, 1, 1, 0, 0, 1, 0]</code> のように表現できます。</p>
<p>以下の図は、バイナリベクトルがテキストコンテンツ内のキーワードの有無をどのように表現しているかを示しています。 この例では、10次元のバイナリベクトルを使用して2つの異なるテキスト（<strong>テキスト</strong> <strong>1とテキスト2</strong>）を表現しています。各次元は語彙内の単語に対応しており、1はその単語がテキスト内に存在することを示し、0は存在しないことを示します。</p>

 </span></p>
<p>バイナリベクトルには、次のような特徴があります。</p>
<ul>
<li><p><strong>効率的な保存：</strong>各次元に必要な保存容量はわずか1ビットであるため、保存スペースを大幅に削減できます。</p></li>
<li><p><strong>高速な計算：</strong>XORなどのビット演算を使用することで、ベクトル間の類似度を迅速に計算できます。</p></li>
<li><p><strong>固定長：</strong>元のテキストの長さにかかわらずベクトルの長さは一定であるため、インデックス作成や検索が容易になります。</p></li>
<li><p><strong>シンプルで直感的：</strong>キーワードの有無を直接反映するため、特定の専門的な検索タスクに適しています。</p></li>
</ul>
<p>バイナリベクトルは、さまざまな方法で生成できます。テキスト処理では、あらかじめ定義された語彙を用いて、単語の有無に基づいて対応するビットを設定できます。画像処理では、知覚ハッシュアルゴリズム（<a href="https://en.wikipedia.org/wiki/Perceptual_hashing">pHashなど</a>）を用いて、画像のバイナリ特徴量を生成できます。機械学習アプリケーションでは、モデルの出力を二値化することで、バイナリベクトル表現を取得できます。</p>
<p>バイナリベクトル化後、データは管理およびベクトル検索のためにMilvusに保存できます。以下の図は、その基本的なプロセスを示しています。</p>
<p><span class="img-wrapper">
  
   <img translate="no" src="https://milvus-docs.s3.us-west-2.amazonaws.com/assets/use-binary-vector.png" alt="Use Binary Vector" class="doc-image" id="use-binary-vector" /> 
   <span>バイナリベクトルの活用</span>
  
 </span></p>
<div class="alert note">
<p>バイナリベクトルは特定のシナリオでは優れた性能を発揮しますが、表現力には限界があり、複雑な意味的関係を捉えることが困難です。そのため、実際のシナリオでは、効率と表現力のバランスを取るために、バイナリベクトルが他のベクトル型と併用されることがよくあります。詳細については、<a href="/docs/ja/dense-vector.md">「密ベクトル</a>」および<a href="/docs/ja/sparse_vector.md">「疎ベクトル」</a>を参照してください。</p>
</div>

</ol>
