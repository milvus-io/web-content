   <tr>
     <th><p>属性</p></th>
     <th><p>描述</p></th>
   </tr>
   <tr>
     <td><p><code translate="no">collection.ttl.seconds</code></p></td>
     <td><p>如果需要在特定时间段后删除 Collection 中的数据，请考虑以秒为单位设置其生存时间 (TTL)。一旦 TTL 超时，Milvus 将从 Collection 中删除所有实体。 </p><p>删除操作是异步的，这意味着在删除完成之前，仍然可以进行搜索和查询。</p><p>有关详细信息，请参阅<a href="/docs/zh/v2.6.x/set-collection-ttl.md">“设置 Collection TTL</a>”。</p></td>
   </tr>
   <tr>
     <td><p><code translate="no">mmap.enabled</code></p></td>
     <td><p>内存映射（Mmap）支持直接访问磁盘上的大文件，使 Milvus 能够将索引和数据同时存储在内存和硬盘中。这种方法有助于根据访问频率优化数据放置策略，在不影响搜索性能的情况下扩展 Collections 的存储容量。</p><p>有关详细信息，请参阅<a href="/docs/zh/v2.6.x/mmap.md">“使用 mmap</a>”。</p></td>
   </tr>
   <tr>
     <td><p><code translate="no">partitionkey.isolation</code></p></td>
     <td><p>启用 Partition Key 隔离后，Milvus 会根据 Partition Key 值对实体进行分组，并为每个组创建一个单独的索引。 收到搜索请求后，Milvus 会根据过滤条件中指定的Partition Key值定位索引，并将搜索范围限制在该索引所包含的实体内，从而避免在搜索过程中扫描无关实体，并大大提高搜索性能。</p><p>有关详细信息，请参阅<a href="/docs/zh/v2.6.x/use-partition-key.md#Use-Partition-Key-Isolation">“使用Partition Key隔离</a>”。</p></td>
   </tr>
   <tr>
     <td><p><code translate="no">dynamicfield.enabled</code></p></td>
     <td><p>为未启用Dynamic Field的Collection启用该功能。启用后，您可以插入包含原始Schema中未定义字段的实体。有关详细信息，请参阅<a href="/docs/zh/v2.6.x/enable-dynamic-field.md">“Dynamic Field”</a>。</p></td>
   </tr>
   <tr>
     <td><p><code translate="no">allow_insert_auto_id</code></p></td>
     <td><p>当 Collection 已启用 AutoID 时，是否允许该 Collection 接受用户提供的primary key值。</p><ul><li><p>当设置为<strong>“true”时</strong>：插入、更新或插入（upsert）以及批量导入操作会使用用户提供的主键（如果存在）；否则，主键值将自动生成。</p></li><li><p>当设置为<strong>“false”时</strong>：用户提供的primary key值将被拒绝或忽略，primary key值始终自动生成。默认值为<strong>“false”</strong>。</p></li></ul></td>
   </tr>
   <tr>
     <td><p><code translate="no">timezone</code></p></td>
     <td><p>指定在处理与时间相关的操作（尤其是<code translate="no">TIMESTAMPTZ</code> 字段）时，该Collection的默认时区。时间戳在内部以UTC格式存储，Milvus会根据此设置转换值以供显示和比较。如果设置了此选项，Collection时区将覆盖数据库的默认时区；查询的时区参数可以临时覆盖这两者。 该值必须是有效的<a href="https://en.wikipedia.org/wiki/List_of_tz_database_time_zones">IANA 时区标识符</a>（例如<strong>Asia/Shanghai</strong>、<strong>America/Chicago</strong> 或<strong>UTC</strong>）。有关如何使用<code translate="no">TIMESTAMPTZ</code> 字段的详细信息，请参阅<a href="/docs/zh/v2.6.x/timestamptz-field.md">TIMESTAMPTZ 字段</a>。</p></td>
   </tr>
   <tr>
     <td><p><code translate="no">consistency_level</code></p></td>
     <td><p>更改Collection的一致性级别。新级别适用于后续对该Collection且未自行指定一致性级别的搜索和查询；按请求设置仍具有优先级。该值必须为<strong>“Strong”</strong>、<strong>“Session”</strong>、<strong>“Bounded”</strong>（默认）<strong>或“Eventually”</strong>之一。更改此属性无需释放Collection。 有关详细信息，请参阅<a href="/docs/zh/v2.6.x/tune_consistency.md">“一致性级别</a>”。</p></td>
   </tr>
</table>
