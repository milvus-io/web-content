    </button></h2><p>Milvus에서는 파티션을 사용하여 데이터를 분리하고, 검색 범위를 특정 파티션으로 제한함으로써 검색 성능을 향상시킬 수 있습니다. 파티션을 수동으로 관리하는 경우, 컬렉션당 최대 1,024개의 파티션을 생성할 수 있으며, 특정 규칙에 따라 엔티티를 해당 파티션에 삽입함으로써 특정 수의 파티션 내에서만 검색을 제한하여 검색 범위를 좁힐 수 있습니다.</p>
<p>Milvus는 컬렉션에서 생성할 수 있는 파티션 수의 제한을 극복하고, 데이터 분할 시 파티션을 재사용할 수 있도록 파티션 키를 도입했습니다. 컬렉션을 생성할 때 스칼라 필드를 파티션 키로 사용할 수 있습니다. 컬렉션이 준비되면 Milvus는 컬렉션 내에 지정된 수의 파티션을 생성합니다. 삽입된 엔티티를 수신하면 Milvus는 해당 엔티티의 파티션 키 값을 사용하여 해시 값을 계산하고, 해시 값과 컬렉션의 ` <code translate="no">partitions_num</code> ` 속성을 기반으로 모듈로 연산을 수행하여 대상 파티션 ID를 구한 뒤, 해당 엔티티를 대상 파티션에 저장합니다.</p>

<ul>
<li><p>파티션 키가 비활성화된 경우, Milvus는 컬렉션 내에서 쿼리 벡터와 가장 유사한 엔티티를 검색합니다. 가장 관련성 높은 결과가 포함된 파티션을 알고 있다면 검색 범위를 좁힐 수 있습니다.</p></li>
<li><p>파티션 키가 활성화된 경우, Milvus는 검색 필터에 지정된 파티션 키 값을 기반으로 검색 범위를 결정하고, 일치하는 파티션 내의 엔티티만 스캔합니다.</p></li>
</ul>

<p>파티션 키는 검색 범위를 일치하는 파티션 키 값을 포함할 가능성이 있는 파티션으로 좁혀줍니다. 그러나 각 파티션에는 대개 서로 다른 파티션 키 값을 가진 엔티티가 다수 포함되어 있으므로, Milvus는 검색 대상 파티션 내의 모든 엔티티에 대해 파티션 키 기반 필터를 여전히 평가합니다. 해당 필드에 스칼라 인덱스가 없으면, 이 평가 과정은 필드 값에 대한 전체 스캔이 되며, 대규모 컬렉션의 경우 검색 지연 시간의 상당 부분을 차지할 수 있습니다. 스칼라 인덱스가 있으면 Milvus는 대신 인덱스에서 일치하는 엔티티를 조회합니다.</p>
<p>이러한 평가 과정은 벡터 인덱스 유형과 무관하게 발생합니다. Milvus는 파티션 키 값을 HNSW 계열 벡터 인덱스에 내장하여, 파티션 키로 필터링된 검색이 관련 하위 인덱스만 탐색하도록 할 수 있지만, 이러한 최적화는 벡터 탐색 범위를 좁힐 뿐 필터 평가 자체를 제거하지는 않습니다. 스칼라 필드만으로 필터링하는 검색에는 이에 상응하는 단축 경로가 없습니다. 두 경우 모두, 파티션 키 필드에 대한 스칼라 인덱스가 평가 속도를 빠르게 유지하는 핵심 요소입니다.</p>
<p>파티션 키 필드에 따라 인덱스 유형을 선택하십시오:</p>
<ul>
<li><p><a href="/docs/ko/v2.6.x/inverted.md">INVERTED는</a> 대부분의 파티션 키 필드에 적합합니다. 파티션 키 기반 필터는 ‘ <code translate="no">==</code> ’ 및 ‘ <code translate="no">in</code> ’ 조건을 사용하기 때문입니다.</p></li>
<li><p><a href="/docs/ko/v2.6.x/bitmap.md">BITMAP은</a> 고유 값이 적은 필드에 적합합니다. 일반적인 지침으로, 필드에 포함된 고유 값이 500개 미만인 경우에만 사용하십시오.</p></li>
<li><p><a href="/docs/ko/v2.6.x/stl-sort.md">STL_SORT는</a> 숫자형 및 <code translate="no">VARCHAR</code> 필드에 대한 대안입니다.</p></li>
</ul>

<p><span class="img-wrapper">

<p>위 그림에서 볼 수 있듯이, Milvus는 파티션 키 값을 기준으로 엔티티를 그룹화하고 각 그룹에 대해 별도의 인덱스를 생성합니다. 검색 요청을 수신하면 Milvus는 필터링 조건에 지정된 파티션 키 값을 기반으로 인덱스를 찾아내고, 해당 인덱스에 포함된 엔티티 내에서만 검색 범위를 제한합니다. 이를 통해 검색 중 관련 없는 엔티티를 스캔하는 것을 방지하여 검색 성능을 크게 향상시킵니다.</p>
<p>파티션 키 격리를 활성화한 후에는, Milvus가 일치하는 인덱스에 포함된 엔티티 내에서만 검색 범위를 제한할 수 있도록 파티션 키 기반 필터에 하나의 특정 값만 포함해야 합니다.</p>
<div class="alert note">
<p>현재 파티션 키 격리 기능은 인덱스 유형이 HNSW로 설정된 검색에만 적용됩니다.</p>
