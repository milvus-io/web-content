<div class="alert note">
<p>Nella maggior parte dei casi, la corrispondenza <strong>infissa</strong> o <strong>suffissale</strong> è significativamente più lenta rispetto a quella prefissale. Utilizzarle con cautela se le prestazioni sono fondamentali.</p>
</div>

    </button></h2><p><strong>Esiste un limite alla lunghezza dell’elenco dei valori di corrispondenza nelle condizioni di filtro (ad es., filter=’color in ["red", "green", “blue”]')? Cosa devo fare se l’elenco è troppo lungo?</strong></p>
<p>Zilliz Cloud non impone alcun limite di lunghezza all’elenco dei valori di corrispondenza nelle condizioni di filtro. Tuttavia, un elenco eccessivamente lungo può influire in modo significativo sulle prestazioni delle query.
Se la condizione di filtro include un lungo elenco di valori di corrispondenza o un’espressione complessa con molti elementi, si consiglia di utilizzare <a href="/docs/it/v2.6.x/filtering-templating.md">i modelli di filtro (Filter Templating)</a> per migliorare le prestazioni delle query.</p>
