# CompactionTaskState

This enum represents the state of a compaction task.

```csharp
public enum CompactionTaskState
{
    Unknown = 0,
    Executing = 1,
    Pipelining = 2,
    Completed = 3,
    Failed = 4,
    Timeout = 5,
    Analyzing = 6,
    Indexing = 7,
}
```

**VALUES:**

- **Unknown** (0) -

- **Executing** (1) -

- **Pipelining** (2) -

- **Completed** (3) -

- **Failed** (4) -

- **Timeout** (5) -

- **Analyzing** (6) -
