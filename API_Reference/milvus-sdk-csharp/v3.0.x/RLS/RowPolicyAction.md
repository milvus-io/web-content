# RowPolicyAction

This enum represents the row-policy action a row policy governs (query/search/insert/delete/upsert/iterators).

```csharp
public enum RowPolicyAction
{
    Unknown = -1,
    Query = 0,
    Search = 1,
    Insert = 2,
    Delete = 3,
    Upsert = 4,
    QueryIterator = 5,
    SearchIterator = 6,
}
```

**VALUES:**

- **Unknown** (-1) -

- **Query** (0) -

- **Search** (1) -

- **Insert** (2) -

- **Delete** (3) -

- **Upsert** (4) -

- **QueryIterator** (5) -

- **SearchIterator** (6) -
