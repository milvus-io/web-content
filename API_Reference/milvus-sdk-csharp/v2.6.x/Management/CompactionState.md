# CompactionState

Represents the state of a compaction task.

```csharp
public enum CompactionState
{
    UndefinedState = 0,
    Executing = 1,
    Completed = 2
}
```

**Constants:**

- **UndefinedState** (0)

    The compaction state is undefined.

- **Executing** (1)

    The compaction is currently executing.

- **Completed** (2)

    The compaction has completed.
