# FileResource

Represents a file resource in the system, returned by ListFileResources.

```go
type FileResource struct {
    ID   int64
    Name string
    Path string
}
```

**FIELDS:**

- **ID** (*int64*)

    The unique identifier of the file resource.

- **Name** (*string*)

    The name of the file resource.

- **Path** (*string*)

    The path of the file resource.
