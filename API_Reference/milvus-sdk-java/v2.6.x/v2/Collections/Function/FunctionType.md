# FunctionType

This is an enumeration that provides the following constants.

## Constants

- **UNKNOWN** (0)

    The function type is unknown.

- **BM25** (1)

    Sets the function type to **BM25**.

- **TEXTEMBEDDING** (2)

    Sets the function type to **TextEmbedding**.

- **RERANK** (3)

    Sets the function type to **Rerank**.
