# listDatabases()

This operation lists all the database names. 

```java
public ListDatabasesResp listDatabases()
```

**RETURN TYPE:**

*ListDatabasesResp*

**RETURN TYPE:**

*ListDatabasesResp*

**RETURNS:**

A **ListDatabasesResp** object contains a list of all database names.

- `getDatabaseNames()` (*List\<String\>*) -

    The names of all databases in the cluster.
